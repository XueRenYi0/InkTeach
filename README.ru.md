# InkTeach · Прозрачные аннотации для класса Windows

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md) | [Italiano](README.it.md)

**InkTeach — прозрачный слой аннотаций для Windows: пишите прямо поверх PPT / WPS / PDF / изображений / любого приложения.** Файл под ним не изменяется. Перо, маркер, лазерная указка, скриншоты, фигуры по паузе, 41 карточка математических фигур, привязка объектов, избранное, таймер и случайный выбор — с **10 языками интерфейса**.

## Язык

**Настройки → Общие → Язык**, выберите один из 10 языков и перезапустите. В командной строке: `--lang ru`.
