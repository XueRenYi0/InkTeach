在 PPT 上，直接写板书

InkTeach 是一层透明的课堂批注画布，浮在 PPT / WPS / PDF / 图片 / 任意软件之上。 手写、荧光笔、激光笔、截图、数学图形都在同一层里完成；底下的内容一点没动。 板书存在本机，不改变原文件，也不需要安装 .NET。

一块透明画布，盖在正在讲的内容上

不用把 PPT 导出成图片，也不用先切到白板。打开要讲的内容，InkTeach 就在它上面。

不改原文件

PPT、PDF、图片都不动；板书在自己的图层里，退出后原文件还是原样。

直接覆盖

PPT / WPS 放映、PDF 阅读器、图片查看器、浏览器和任意软件都能直接写。

本地保存

板书、收藏、名单存在本机；支持自动保存、历史板书和全局备份。

老师真正会用到的功能

批注、课堂工具、数学图形和效率操作，都在这一层里。

PPT / WPS 批注

放映时直接在幻灯片上写、画、圈；翻页不串页，每一页的板书单独保存。

PDF 批注

打开 PDF 一页一页讲，批注跟着页面走；支持导入、翻页和自动保存。

图片批注

试题截图、照片、地图都能直接标注；透明 PNG 保留透明背景。

白板

没有 PPT 也能上白板；独立多页、网格/横线背景，随时切换。

手写 / 荧光笔 / 激光笔

三种笔各有颜色和粗细；荧光笔每个色位独立透明度；激光笔红边白芯，指哪讲哪。

截图取景

框选屏幕区域，确认后直接贴回板书；可调整边框、复制到剪贴板。

停顿变图形

手写一个歪圆、三角形或直线，停 0.4 秒自动变规整；不用切工具。

22 种数学图形

抛物线、双曲线、正弦余弦、圆柱圆锥球、棱柱棱锥……拖顶点就能改。

对象吸附 / 编辑

图形、图片、笔迹拖动自动对齐；选中后可移动、缩放、旋转、复制、删除。

收藏 / 图库

常讲的图形、题目截图存进收藏；分类、搜索、拖到画布即用。

计时 / 随机点名

课堂计时、随机点名放在浮窗里；不打断板书，也不用来回切软件。

色带 / 贴边隐藏 / 呼出盘

主工具带只占一条，贴边自动收起；按住全局键划一下就能切工具；支持深色主题。

数学课堂：函数图像 + 立体几何

不是“能画图”，而是每个定义元素都能直接拖。

函数图像

抛物线四个开口方向、双曲线（可带渐近线）、正弦 / 余弦 / 正切 / 波浪线、坐标系；拖动参数看变化。

立体几何

圆柱、圆锥、圆台、球、棱柱、棱锥、棱台；拖动改比例，讲体积和截面更直观。

图形编辑

顶点、控制点都能拖；旋转、缩放、吸附、复制；画完还是可编辑对象，不是一张死图。

对象吸附会把图形、图片和笔迹对齐到边、中心线或同一水平/垂直方向，拖图不再靠眼估。

一堂课的流程

01 · 打开要讲的内容

PPT / WPS 放映、PDF、图片，或者直接开白板。不用先导出、也不用换软件。

02 · 直接写

手写、荧光笔、激光笔、截图、数学图形都在同一层；停顿一下还能把歪图画规整。

03 · 翻页与保存

PPT 每页批注隔离；PDF / 图片批注跟着页面走；自动保存，课后还能找回。
