在 PPT 上，直接写板书

界面与功能

为手写笔优化的书写

压感变宽（口径对齐 Windows Ink）、笔尖跟手（合成边界配速，Present 到上屏 1.0 个刷新周期）、 真笔湿墨交给系统合成器；书写期间开 GC 低延迟档，一笔不间断。

停顿变图形

手写一笔停住约 0.4 秒，自动变成规整图形（直线 / 圆 / 矩形 / 三角形…），按住还能拖到位再松手； 吸附与画直线同一套（特殊角 ±1°）。

22 种图形与学科工具

直线 / 箭头 / 矩形 / 椭圆 / 圆 / 三角形 / 平行四边形 / 坐标系； 抛物线 / 双曲线 / 正弦 / 余弦 / 波浪线 / 正切；圆柱 / 圆锥 / 圆台 / 球 / 棱柱 / 棱锥 / 棱台。 每个定义元素都能直接拖，实时显示角度 / 半径 / 长度。

选中与编辑

点选 / 框选 / 套索；8 手柄 + 旋转（90° 软吸附、Shift 15° 网格）； 操作条十格：收起 / 颜色 / 锁定 / 层级 / 导出 / 图库 / 复制 / 翻转 / 删除。 拖动旋转期间内容层一帧不重画，一次拖拽一步撤销。

截图 · 导出 · 剪贴板

截图：冻结整屏 → 拖框 → 松开调整 → 原位落 + 自动选中 + 进剪贴板； 导出透明 PNG / 白底 PNG / JPEG / BMP；剪贴板里同时放"可编辑对象"和一张图。

白板 · PPT · 课堂工具

白板（白 / 绿 / 黑 + 底纹）；PPT 放映联动（逐页隔离、自动存读、墨迹回放）； 计时器（倒计时 / 正计时 / 秒表）；随机点名（抽过不重复）。

底层与性能

自绘界面直连 Direct3D11 + Direct2D + DirectComposition；内容层按块缓存、脏矩形增量修补； 命中走空间网格；引擎与界面只通过三个契约相连。

项目实测
Present 返回 → 屏幕变色1.0 个刷新周期（未配速 3.5）
拖动一万条选中的内容内容层 0 块/帧重画；每帧记录 2.7ms
空闲帧0（有东西动才画）
冷启动约 0.27 秒（同一台机器上比空白 WPF 窗还快）
常驻内存（空闲）提交约 93MB（含全屏合成缓冲）

数字都来自开发机上的自动实测；测试方法、环境与全部数据见仓库文档。
