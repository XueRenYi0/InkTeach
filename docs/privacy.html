设备与性能统计说明

9.3.2 起，InkTeach 只在用户明确同意后，上传用于统计安装量和改进卡顿/兼容性的设备与性能信息。 不含姓名、账号、课件、作业或屏幕内容；拒绝不影响使用，之后可随时关闭。

适用范围：9.3.2 起为“首次明确同意后上传”。9.3.1 及更早版本没有同意步骤， 会在启动约 25 秒后自动上传同类匿名设备卡；如不希望上传，请升级到 9.3.2 并在弹窗中选择“暂不”， 或在设置中关闭。

上传什么

  • 随机安装 ID（不含姓名、账号）
  • InkTeach 版本
  • 首次/最近使用日期
  • 系统版本、CPU、内存、显卡、屏幕/DPI
  • 帧率、慢帧、最大帧、内存占用、软件渲染标记
  • 触摸点数与接触面积统计

不上传什么

  • 姓名、账号、手机号等身份信息
  • 课件、作业、文档内容、屏幕截图
  • 文件路径、摄像头或麦克风内容

用途

仅用于统计安装量、定位卡顿/兼容性问题、决定后续优化方向，不用于广告或出售数据。

存储与保留

设备卡上传到私有日志仓库；设备卡按天覆盖，保留首次/最近使用日期。日志仅在用户主动点击「日志」上传时发送； 日志用于排查问题，可能包含运行环境、窗口标题或文件路径等诊断信息，请在确认后上传。 用户拒绝或关闭统计后，不再上传，并会尝试删除该安装 ID 对应的旧设备卡。

用户选择

首次满足上传条件（启动约 25 秒）时弹一次说明；从旧版升级到 9.3.2 也会弹一次。 拒绝不影响软件使用。之后可以在「设置 → 书写 → 设备与性能统计」中开启或关闭。 重装、清除配置或更换 Windows 用户后，会重新询问一次。

联系

如需查询或删除数据，请通过 项目 Issue 联系开发者，并提供安装 ID 前 8 位。
