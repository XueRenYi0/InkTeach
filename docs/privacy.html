匿名设备与性能统计说明

下一版（main）起默认开启，首次启动只给一条非阻塞提示，不弹模态框。 只上传统计安装量和改进卡顿/兼容性所需的设备与性能信息；不取 IP、不取省市， 不含姓名、账号、课件、作业或屏幕内容；可在设置中随时关闭并删除。

适用范围：下一版（main）起默认开启（欧盟/英国/瑞士默认关闭，可在设置开启）； 9.3.2–9.7.x 为“首次明确同意后上传”；9.3.1 及更早没有同意步骤，启动约 25 秒后自动上传同类设备卡。

上传什么

  • 随机安装 ID（首次启动生成，不含姓名、账号；只用于去重计数）
  • InkTeach 版本、界面语言
  • 首次/最近使用日期
  • Windows 国家/地区代码、时区（只读系统设置）
  • 系统版本、CPU、内存、显卡、屏幕/DPI、刷新率
  • 帧率、慢帧、最大帧、内存占用、软件渲染标记
  • 触摸点数与接触面积统计

不上传什么

  • IP 地址、省/市/区位置（应用不读取、不存储，也不写进设备卡）
  • 姓名、账号、手机号等身份信息
  • 课件、作业、文档内容、屏幕截图
  • 文件路径、摄像头或麦克风内容

设备卡上传请求由 GitCode 接收，网络层可能记录请求 IP；InkTeach 应用本身不读取、 不存储 IP，也不会把 IP 写入设备卡。设备卡里只有系统国家/地区代码，没有省市。

用途

仅用于统计安装量、定位卡顿/兼容性问题、决定后续优化方向，不用于广告或出售数据。

存储与保留

设备卡上传到私有日志仓库；同一随机 ID 按天覆盖，保留首次/最近使用日期。 用户关闭统计后不再上传，并会尝试删除该安装 ID 对应的旧设备卡。

运行日志是另一项独立选择：只有用户主动点击「更多 → 日志 → 上传日志」时才会发送； 首次上传会单独确认，可能包含运行环境、窗口标题或文件路径等诊断信息，不含文档内容。 设备统计默认开启不等于同意上传运行日志。

用户选择

下一版（main）起默认开启（欧盟/英国/瑞士默认关闭）；首次启动只在屏幕底部给一条 6 秒提示，不弹模态框。 之后可在「设置 → 关于 → 匿名设备统计」中开关。关闭后立即停止上传，并删除本机 ID 对应的设备卡。 旧版曾明确拒绝的用户，升级后保持关闭；重装、清除配置或更换 Windows 用户后会生成新的随机 ID。

联系

如需查询或删除数据，请通过 项目 Issue 联系开发者，并提供安装 ID 前 8 位。
