## 8. 收藏弹窗（2026-10-26 定稿）

- 主入口：主条「收藏」格（有位置且已钉住时）。
- 兜底入口：极简 / 未钉住时，默认进「更多 → 收藏」；主条有收藏格时，更多里不再放同一入口。
- **点收藏不切换、不展开色带**：色带保持当前工具的笔色线（同穿透的收法），弹窗直接出现。
- **不是“收藏没有展开”**：收藏格的展开面**就是弹窗本身**，只是内容多所以比 34 高的设置条大；
  不再额外长一条收藏色带。简单设置（笔色/粗细/橡皮）用色带，内容型（收藏，未来图形库）用弹窗。
  弹窗标题栏沿用工具条的视觉语言（同圆角/同底色/贴着工具条上沿长出来），读起来仍是“这一格展开了”。
- **弹窗自带全部内容控制**：分类导航、新建分类、整理、导入 / 导出、回收站、关闭、`⋯`；
  分类和收藏动作**不再放色带**——色带只服务当前工具。
- 竖排：左列 = 全部 / 未分类 / 自定义分类 / 回收站（带数量）＋底部管理动作；右侧卡片。
- 横排：顶行 = 当前分类 ▾ / 新建 / 整理 / 导入 / 导出；下方卡片。当前分类、数量、主操作始终可见；
  分类多时竖排左列滚轮滚动、横排用「当前分类 ▾」菜单。
- 尺寸：横排默认约 760×200、竖排默认约 344×560（逻辑像素）；卡片固定 72×80。
- 拖动标题栏可移动；拖边/角可改大小并自动呈横条或竖条。卡片维持 72×80，**不缩点击目标**。
  靠底 / 顶 → 横排，靠左 / 右 → 竖排；自由摆放时保留上次方向。
- 位置、方向、尺寸跨重启记住；默认仍贴主条上沿居中。面板尺寸不跟主条长短缩。
- 弹窗默认**常驻**：点画布、换工具都不关；只有 `Esc`、关闭、再点收藏格才关。
  点卡片准备插入时先收面板，落笔后看插入结果。
- 是否常驻由一级页签行最右的 **📌 图钉**决定（见 8.1）；图钉灭 = 开始用画布时让开。
- 从「更多」打开走同一套弹窗，不产生第二套布局。

### 8.1 面板图钉 / 图形单次-连续（2026-11-10）

- 一级页签行最右：`📌` 面板常驻；**图形页另有 `单次 | ∞ 连续`**，收藏页没有连续开关。
- `📌` **两个页签各记各的，跨重启保留**：图形页默认灭（选完落笔就让开），收藏页默认亮（放完继续）。
- `📌` 灭：选卡后**先不关**，第一次真正用画布（落笔 / 点空白）时让开；`📌` 亮：画/放时都不收。
- `∞ 连续`只对**从面板选的图形**生效，默认单次；只记本次运行，重启回单次；`Esc` 结束并回原工具。
  主条上的图形工具仍是连续，不受这里影响。
- **不要给卡片加图钉/每卡状态**：41 张卡各带一个小按钮会缩小点击目标、也记不住；
  连续是“这一阵子怎么画”，不是“这个图形是什么”。

## 9. 收藏的管理入口（2026-10-25 落地，2026-10-26 迁入弹窗）

- 弹窗固定提供 `⋯`，**不再单独放 ✕**；关闭收藏也在这里。
- **整理 / 导入 / 导出**常驻在竖排左列底部、横排顶行右侧；不进 `⋯`（不重复入口）。
- `⋯` 只放低频/上下文动作：回收站（清空回收站 / 返回收藏）、移动到…、用当前选中更新收藏、
  删除选中、删除当前分类、关闭收藏。
- 「删除分类」「删除选中」「清空回收站」一律**二次确认**（第一次只把那一行文案换成「再点一次…」，不改数据）；第一下绝不能直接删。
- 整理模式：点卡片本体 = 多选/取消；点卡片右上红 ✕ = 单条删除（收藏 → 回收站；回收站 → 永久）。
- 收藏弹窗标题行：`收藏 · 分类 · 页码 · N 个`；列表**新的在前**（刚收藏的出现在第一页第一条）。
- 画布内改完 → 收藏面板里整理、选中目标卡片 → `⋯ → 用当前 N 个对象更新`（二次确认）；
  只允许一条卡片对一批画布对象，改完撞另一条收藏时拒绝（不制造重复）。
- 回收站是虚拟分类 `__trash`：不写进 `categories.txt`；点卡片恢复，红 ✕ / 清空才是永久删除。
- 收藏弹窗**不单独做导入/导出**；统一走「设置 → 墨迹 → 备份与恢复」（2026-10-26 用户定）。
- 全局备份只放「设置 → 墨迹」：收藏 / 历史板书 / 设置 / 点名名单 / PPT 与文档批注；
  **不含 PDF / PPT 原文件**；恢复后提示重启，旧数据留在 `.before-restore`。

## 10. 图形带的后续（只记方向，不在这一批做）

- 图形后期可以复用收藏弹窗这套“可拖动 / 可横竖 / 自带分类”的容器，装“全部图形 / 曲线 / 立体 / 属性”。
- 但在收藏弹窗稳定之前，**不要先拆图形带**：高频的 8 个图形有肌肉记忆，先保留现有快捷带。
- 凡是“内容多、要分类、要滚动”的，用弹窗；凡是“当下一笔的颜色 / 粗细 / 模式”，用色带。
- **直线在图形面板里是三张卡**（实线 / 虚线 / 点线，2026-11-12 用户定）：点哪张就用哪档，
  不受工具栏上次切到哪档影响；反过来工具栏切档会高亮对应卡片。**其他图形永远实线**
  （颜色/粗细跟笔走，线型不跟——虚线是辅助线语言，只属于直线；选中后仍可单独改线型）。
- **「箭头清屏」**（2026-11-12 用户定，默认关）：设置 → 书写。只在**桌面批注**生效——
  白板能翻屏、PPT/PDF 一页一存，都不动；点箭头（或全局快捷键）进入穿透前清空桌面这一屏，
  一步撤销。生效时箭头**保持原样、右上角多一个小圆点**、悬停提示同步；课堂计时/点名卡片自动穿透不清。

## 11. 收藏拖拽 / 尺寸 / 选择（2026-10-26 定稿）

- **勾选是整组**：勾了 3 张，点/拖其中任意一张都按 3 张走（插入、移分类、排序、删除）。
  点/拖**未勾选**的卡片 = 清空当前勾选，只操作那一张。要单张先取消其他勾选。
- 拖动分三种：拖到分类（整组移到目标分类最前）、拖到卡片之间（整组插入到落点）、拖到画布
  （整组按落点插入，一步撤销，弹窗不关）。
- **新收藏 / 拖入分类都排最前**；手动拖动排序后覆盖顺序，顺序落盘记住。
- 弹窗尺寸只停在整数格：横排 1/2/3 行、竖排 1/2/3 列；宽度/高度也按整卡吸附，
  **绝不出现半行/半列**。拖动时只显示最近的有效轮廓，松手才落位。
- 竖排 1 列时标题栏收成图标条；分类抽屉覆盖在卡片上，不额外占一列。
- 删除分类只删分类，内容移到「未分类」；二次确认写明数量。改名用铅笔/双击，
  `✓` 保存、`✕` 取消；删除分类用独立垃圾桶图标。
- 收藏弹窗不单独做导入/导出；统一走「设置 → 墨迹 → 备份与恢复」。
- 全屏「更多 / 说明 / 截图」时弹窗暂时隐藏，回来恢复；不销毁。**PPT 放映时不藏**（2026-11-12
  用户反馈：放映时也要能取图形/收藏；画布本来就能画，没理由只锁这两个面板）。

## 12. 图片美化（2026-11-10）

- **只在图片选中条**提供：`收起 / 复制 / ✨美化 / AI / 删除 / ⋯`；保存移进 `⋯`，核心位让给美化。
- 美化是**本地像素处理**：纸白估计 + 低分辨率背景除法去阴影 + 纸白 242 + 轻锐化；
  **不旋转、不裁边、不做透视、不做二值化**；透明图和已经够白的图跳过。
- 图标-only（星光），不塞文字；说明只放悬停提示：“去黄、提亮、白纸；不改字，不转图”。
- 点一次美化，**再点一次恢复原图**（原图只在本进程内保留，重启不占 `.ink` 双份体积）；
  一步撤销（`Ctrl+Z`）也回原图；不自动作用于导入/截图/白板图片，用户选中哪张才处理哪张。
- 参考实现：Microsoft Lens（白平衡/去阴影/保色）、CamScanner Magic Color（黑白场+光照除法）、
  pagescan.enhance、Dropbox Document Enhancement；不引 OpenCV / 大模型。

## 13. 图片识别成题卡（2026-11-10）

- **图片 AI 菜单只有两项**：`🧩 识别内容` + `📈 识别作图`（2026-11-11 改名）。
  「识别内容」自适应：像题目 → 题卡；普通文本 → 富文本卡。截图条**不放 AI**（截完就是图片，选中图片再点 AI）。
- **原图保留**，卡放图片右侧（放不下放下面，都放不下居中），一步撤销。
- **一张图多道题 = 一张卡里的“第 1 题 / 第 2 题”**；同一道题的 (1)(2)(3) **不拆卡**。
- **答案默认不生成**：卷面通常没有答案，模型顺手编的答案核对成本更高；
  每题留 `✦ 生成答案（AI）`，点了才请求，生成后展开并标“AI 答案请核对”，可一步撤销。
- `need_review=true` 的题在题干前加 `【请核对】`，不静默当对的用。
- **结构化失败不丢结果**：OCR 原文放进 `Rich=true` 的**富文本只读框**（能渲染 `$...$`）；
  **不能放普通文本框**——普通框不解析 Markdown/公式，`\frac{1}{2}` 会原样露出。
- 看图模型自动挑：当前服务商能看图就用它，否则按 `ocr > omni > vl > Qwen3.5–3.8 通用多模态` 选一条有 Key 的；
  写 JSON 优先当前选中，但跳过 `*-ocr`。两边都走既有 `ai.json`。
- 模型选型有实测记录：`reports/ai-image-test/model-ocr/`（9 个百炼模型 × 6 张中文卷面，
  原始输出全部留档）。结论：`qwen3.5-ocr` 最快最准；`qwen3.8-flash` 排版好但 7–26s；
  `qwen3.5-omni-flash` 会被红笔批改带偏（`m>16` 读成 `m<16`）——**不能只看速度**。
- 提示词/模型实测与踩坑见 `调研/AI-图片识别成题卡-2026-11-10.md`。
- 参考：Mathpix Snip（图片→LaTeX、看不清不编）、Microsoft Lens / CamScanner（先美白再 OCR、原图保留）、
  Google Lens 复制文本（结果可编辑不覆盖原图）、小猿搜题（答案解析折叠、可核对）。
- **AI 去手写 / AI 纠正：测过，但没接入**（2026-11-11）。所有出图模型都是“重新画一张”，
  实测会把 `-3` 改成 `-8`、把“则”画成“刬”；单价 0.10–0.30 元/张，是主链（≈0.01 元/张）的
  10–100 倍。记录见 `reports/ai-image-test/image-edit/`。真要做，只能进 `⋯` 当实验功能，
  出图后必须自动 OCR diff + 保留原图。
- **2026-11-11 用户拍板：页面矫正 / 去手写先不做**（“代价太大”）。
  不要加任何入口，也不要再做“AI 清理副本”；保留本地美白（`PhotoBeautify`，免费、不改字）。
- 百度「文档去手写V2」（0.13 元/次，2s）是**擦笔画、不编内容**，比生成式安全；但手写压住
  印刷体时会把字一起擦掉，之后 OCR 会脑补数字——同样必须 diff。百度通用 OCR 无 LaTeX、
  抄手写、怕拍歪，**不做图片→题卡的认字**。记录见 `reports/ai-image-test/baidu-ocr/`。
- 通用图像编辑模型第二轮（不用教育专用）：`seedream-5.0-flash` 12.8–15.6s、0.12 元，
  红笔样本数字/符号全对，是生成式里唯一可试的；`seedream-5.0-pro` 61s/0.30 元也对但太慢；
  `qwen-image-2.1-turbo` 把 `-3` 改成 `-8`，Wan2.7 把公式画坏，Gemini/GPT 图像编辑
  **403 地区受限**。全部是“重画一张”，只能做实验副本，记录见 `reports/ai-image-test/image-edit2/`。
- 合合 TextIn xParse：公式 LaTeX 最规范，但不区分手写、0.35 元/页（约 qwen 的 250 倍），
  **不做默认/备选**，只适合干净印刷页/PDF。记录见 `reports/ai-image-test/textin/`。
- PaddleOCR-VL-1.6（讯飞 `xoppaddleocrv16`）：1.8–2.8s、`m > 16` 这类符号读得比 omni 准，
  但**把红笔批注当正文**（img21 5697 字/15s），提示词让它忽略手写无效；
  **不做默认**，只适合干净印刷页。记录见 `reports/ai-image-test/paddle-16/`。
- 千帆 OCR：`qianfan-ocr` 1.5–57s 不稳定、`paddleocr-vl-0.9b`/`pp-structurev3` 240s 超时、
  `deepseek-ocr` 乱码、`qwen3-vl-30b` 无权限 → **不用**。记录见 `reports/ai-image-test/qianfan/`。
- OpenRouter：163 个视觉模型；`gemini-3.6-flash` 是唯一在红笔样本上全对的备选
  （3.4–4.9s、≈0.012 元/张），可考虑做“高质量识别”开关；主链仍 qwen3.5-ocr。
  记录见 `reports/ai-image-test/openrouter/`。
- 千问 3.8（没有 4.0；最新是 3.8）：`qwen3.8-flash` 关思考 + **原图** 2.8–4.4s、
  ≈2 元/千张、红笔样本全对，是唯一值得留的升级候选；`max` 要 30 元/千张且默认思考
  104–162s；`omni` 仍读错负号。记录见 `reports/ai-image-test/qwen38/`。
- 深挖后修正：Gemini 3.x **关不掉思考**（400 `Reasoning is mandatory`），随后全部
  **403 地区受限**（`not available in your region`），不能当产品备选；
  “符号读错”其实是**缩到 1500px 把负号缩没了**——原图 2048 下 `qwen3-vl-235b`
  能读对 `(-3,-4)`（7–17s、≈0.0065 元/张）。App 本来就走原图，所以 App 没这个问题。
  可用的高质量备选 = `qwen3-vl-235b` + 原图分辨率。
- **全平台功能/价格/推荐度一页表**：`reports/ai-image-test/功能选型总账-2026-11-11.md`
  （OCR / 去手写 / 纠偏 / 试卷切题，按 1000 张成本折算）。
- **「画圆」必须正圆**（2026-11-11 用户反馈）：模型给 `a≠b` 时，按方程 `x^2+y^2=…`
  或请求里的“圆”（且不是“椭圆”）强制 `a=b`；图例写 `圆 x^2+y^2=4`，不写椭圆标准式。
- **图片 OCR 超时自动重试一次**：DashScope 偶发排队（实测单张 113s），
  60s 超时后重试通常 2–3s 返回；用户主动取消不重试。
- **题卡字体和普通文本框共用一套**（2026-11-11）：文字操作条 `A` → 字体
  快捷格「雅黑 / 楷体 / 宋体 / 黑体」＋「更多…」系统字体下拉。
  **只列中文字体**（DirectWrite `HasCharacter('中')` 过滤；本机 150 个），
  底部可切「显示西文字体」；顶部固定「最近使用」5 个（`fontRecent`）。
  固定 10 行、**像素级连续滚动**（滚轮 / 触摸拖动 + 惯性，复用
  `UiTouchFling` 的衰减参数）；长字体名按宽度加省略号，不硬裁。
  **内嵌字体只留给“AI 手写替换”**：`assets/fonts/ZhiMangXing.ttf`
  （钟齐志莽行书，4MB，OFL；2026-11-11 删掉 25MB 的漓雨手书）——DirectWrite
  的系统集合看不到进程内注册的字体，所以题卡字体只用系统字体。
  **上次用过的字体存设置**（`textFace` / `textFaceName`），新建文本框/题卡、
  重启都沿用它；字体家族名随文本框存盘（v35），换机器缺字体时绘制自动回退。
  公式仍按数学字体渲染，不跟着换；西文/数字跟随中文字体（缺字回退 Segoe UI）。

## 14. 主条顺序与清屏垃圾桶（2026-11-15 定稿）

- **身份与位置分开**：`Cell` 枚举是永久身份，`CellOrder` 是唯一显示顺序；加格只追加身份，
  换顺序只改 `CellOrder`，不再改 `case` 下标 / 存档 key。
- 工具段顺序：`画笔 → 荧光笔 → 激光笔 → 文本 → 橡皮 → 垃圾桶`；后面是
  `选择 → 截屏 → 图形 → 收藏 → 后撤 → 重做 → 更多`。**新老用户一致**。
- 垃圾桶 = **清空当前页 / 当前幻灯片 / 当前这一屏**：单击执行、一步撤销、不换工具、
