# InkTeach · Transparente Unterrichtsanmerkungen für Windows

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md) | [Italiano](README.it.md)

**InkTeach ist eine transparente Anmerkungsebene für Windows, mit der Sie direkt auf PPT / WPS / PDF / Bildern / jeder App schreiben.** Die Datei darunter bleibt unverändert. Stift, Textmarker, Laserpointer, Screenshots, Formenerkennung, 41 Mathe-Formkarten, Objekt-Snapping, Favoriten, Timer und Zufallsauswahl – mit **10 Oberflächensprachen**.

- Windows 10 / 11 x64, kein .NET erforderlich.

## Sprache

**Einstellungen → Allgemein → Sprache**, eine der 10 Sprachen wählen und neu starten. Auf der Kommandozeile: `--lang de`.
