# InkTeach · Anotação transparente para a sala de aula Windows

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md) | [Italiano](README.it.md)

**InkTeach é uma camada transparente de anotação para Windows: escreva diretamente sobre PPT / WPS / PDF / imagens / qualquer aplicativo.** O arquivo embaixo não é alterado. Caneta, marca-texto, ponteiro laser, capturas de tela, formas ao pausar, 41 cartões de formas matemáticas, ímã de objetos, favoritos, cronômetro e sorteio, com **10 idiomas de interface**.

## Idioma

**Configurações → Geral → Idioma**, escolha um dos 10 idiomas e reinicie. Na linha de comando: `--lang pt-BR`.
