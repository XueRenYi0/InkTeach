# InkTeach · Annotazione trasparente per la classe Windows

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md) | [Italiano](README.it.md)

**InkTeach è un livello trasparente di annotazione per Windows: scrivi direttamente su PPT / WPS / PDF / immagini / qualsiasi applicazione.** Il file sotto resta intatto. Penna, evidenziatore, puntatore laser, screenshot, forme con pausa, 41 schede di forme matematiche, aggancio oggetti, preferiti, timer e sorteggio — con **10 lingue dell'interfaccia**.

## Lingua

**Impostazioni → Generale → Lingua**, scegli una delle 10 lingue e riavvia. Da riga di comando: `--lang it`.
