## 一、「更多」抽屉：可行，而且和现有的"上带"不冲突

### 1. 它和上带是两件事

| | **上带** | **更多抽屉** |
|---|---|---|
| 是什么 | **当前工具的参数**：模式 / 颜色 / 大小 | **全局的入口集合**：不常用工具 / 学科工具 / 设置 |
| 什么时候出现 | 跟着当前工具走；鼠标停上去就展开 | 常驻一个入口，**点开才出现** |
| 内容谁定 | 由工具决定（写死在界面里） | 由**配置数据**决定（用户可钉、后期可加） |

这条区分很重要：不然用户会分不清"我刚点开的到底是这个工具的设置，还是全局工具箱"。

### 2. 形态（照希沃那类白板的思路）

- 主条最后那一格：齿轮 → **更多**（点开抽屉，再点一次收起）；
- 抽屉从主条的下方（贴下边时）或上方长出来，**和主条同一套视觉**；
- 抽屉里按**分组网格**排：**不常用 / 学科工具 / 设置**；
- 每格右上角一个**图钉**：点一下钉到主条上（钉上去的就常驻了）；
- 学科工具那一组现在是**占位**（直尺、量角器、田字格……），后期往里加。

### 3. 可行性：每一项都落到已有的引擎能力上

抽屉里的东西只有三类：**换工具 / 换模式 / 开开关** —— 这三类引擎里全都有。
界面层要新增的也只有两样：

1. **抽屉这个面板**（分组网格 + 图钉 + 和主条一样的外框）；
2. **一份配置数据**：抽屉里有哪些项、哪几项钉在主条上 → 放进 `settings.json`（已有的落盘机制）。

**结论：纯界面工作，不需要引擎改造。** 工作量比"上下文设置条"小（那是四类控件的绘制 + 命中）。

### 4. 什么时候做合适

和贴边一样，**设计现在定、实现放在接引擎前后都行**。它不涉及窗口行为（就是一块自己画的浮出面板），
所以假面板里也能验个八九成。如果你想先看到它长什么样，我可以在假面板里把它做出来（半天）。

## 二、图标换不换：换

### 「更多」入口用哪个

| 候选 | 1:1 | 说明 |
|---|---|---|
| **More Horizontal（…）** ★ | `…` | Windows 11 里"还有更多"的**标准写法**。最不容易误解、最省地方 |
| Apps / Grid（宫格） | ▣ | 更像"工具箱"（希沃那种入口的味道），但要和主条上的**「图形」**图标区分开 |
| Grid（网格） | ▦ | 同上，线更细；和 Apps 二选一 |

**建议用省略号**：主条上已经有"图形"这个宫格类图标，再放一个宫格容易认错；
而且"…"在 Windows 里就是"还有更多"的通用语义，用户不用学。
后期学科工具真的多了、想突出"工具箱"的感觉，再换宫格也不迟（换图标是一行代码）。

## 三、激光笔图标：上游没有专名，但别的库有

### 查到的三件事

1. **Fluent（我们在用的库）没有"激光笔"这个专名**。相关的只有 `Flash`（闪电）、
   `Flashlight`（手电筒）、`Record`（圆点）、`Target`（靶心）—— 都是近义，不是专名。
2. **Material Symbols 有一个真正的专名图标：`stylus_laser_pointer`**（Apache-2.0）。
   它就是"笔 ＋ 落点 ＋ 一束光"的组合，正是我们要表达的语义。
3. **Excalidraw（MIT 的开源白板）的激光笔图标**是"一支笔 ＋ 笔尖周围几道短射线"——
   它的思路（**笔尖 ＋ 光**）可以直接借，然后按 Fluent 的 24 网格与 1.7 线宽自己画一个，
   这样"一个界面只用一个库"的规矩不用破。

### 候选（图稿 ①，1:1 与 3× 都画了）

| 候选 | 来源 | 1:1 下 | 评价 |
|---|---|---|---|
| **stylus_laser_pointer** ★ | Material Symbols（Apache-2.0）| 清楚 | **唯一一个"专名"**，语义不会认错 |
| stylus_laser_pointer（实心）| Material Symbols | 清楚 | 同一枚的实心变体，**选中态**可以直接用它 |
| **自绘：笔 ＋ 光束 ＋ 落点** ★ | 我们的（照 Excalidraw 思路） | 清楚 | 想守住"一个库"就用这个；线宽和 Fluent 对齐 |
| 自绘：光束锥 | 我们的 | 一般 | 锥体半透明，小尺寸下有体量，但偏"手电筒" |
| Fluent：Flash 闪电 | Fluent | **最清楚** | 现成、最省事；语义是"闪光" |
| Fluent：Record 圆点 | Fluent | 清楚 | 就是"光点"，单独用容易被当成"录制" |
| Fluent：Target 靶心 | Fluent | 清楚 | 像瞄准 / 定位 |
| 自绘：光点 ＋ 短射线 | 我们的 | 一般 | 像"亮度 / 发光" |
| 自绘：光点 ＋ 三道弧 | 我们的（第一版）| 差 | **像 Wi-Fi —— 就是你说丑的那个，假面板里已经把它降级成对比项** |

### 关于"跨库借一个图标"

第一轮我定过一条规矩：**一个界面只用一个库**（混库会让线宽、圆角、光学尺寸全对不上）。
这一枚是**唯一值得破例的情况**：上游**根本没有**这个语义，而别的库有专名图标。
破例的做法要写清楚：

- 只借**这一枚**，并用它的 **filled 变体**做选中态；
- 来源与许可证写进 `THIRD-PARTY-NOTICES.md`（Material Symbols 是 Apache-2.0）；
- 视觉上尽量对齐：Material 是实心粗线条风格，和 Fluent 的细线放在一起会略"重"——
  如果你在意这个，就用**自绘版**（我按 Fluent 的线宽画的，肉眼几乎看不出差别）。

### 已按你的选择落地（2026-09-15）

- **激光笔：用自绘的「笔 ＋ 光束 ＋ 落点」**（`LaserStyle = 2`）——照 Excalidraw 的思路、
  按 Fluent 的 24 网格与线宽画的，所以"一个界面只用一个库"这条规矩不用破。
  另外 8 个候选还留着，按 `L` 仍可一个个翻。
- **「更多」入口：用省略号（`More Horizontal`）**，主条最后那一格已经从齿轮换成它。
- **「更多」抽屉已经做进假面板**：主条上的 `…` 点开，
  抽屉从面板**右上方**长出来（贴底时下面没有空间，所以往上开），里面三组：

  | 组 | 内容 |
  |---|---|
  | **应用** | 检查更新 / 重启 / **退出**（退出是真能用的） |
  | **界面** | 深色主题 / 贴边隐藏 / 装饰带（三个开关，从原来的设置条搬进来了） |
  | **学科工具（即将加入）** | 直尺 / 量角器 / 田字格（灰着，占位） |

  开抽屉时**面板本身不动**（窗口往上长，锚的是面板下沿）；换工具会自动收起抽屉。
  截图见 `design/mock/22-更多抽屉.png`。
