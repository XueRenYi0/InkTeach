# 计划：四个窗口入口（白板 / 笔记 / PDF / 视频展台）与共享窗口层

日期：2026-11-10　　状态：**调研与路线稿 v2，等拍板；不改代码**

> **2026-11-10 用户修正（覆盖上一版）**
> 1. **白板不是 OneNote 式无限画布**：白板要“分页 + 纵向滚动 + 缩放/平移 + 图片直接拖入”，
>    对齐市面课堂白板；翻页要有。
> 2. **OneNote 式无限页面属于独立的笔记软件**，单独入口；有侧边栏/目录、手写批注、
>    图片/PDF 导入、导入导出。
> 3. **视频展台该有的功能都有**（对齐 IPEVO / HoverCam 一类产品），单独窗口。
> 4. **PDF 做窗口级批注**，按页批注。
> 5. 第一版仍然**单窗口、单文档**；多窗口并排另立项目。

## 〇、结论先行

1. **先做“窗口壳 + 白板”，不要先做笔记。**
   白板把窗口、输入、缩放/平移、分页、图片拖入、保存这些共用地基全部跑通；
   笔记、PDF、展台后面都踩在这块地基上。

2. **四个入口共享四样东西，不共享文档模型：**
   - 共享：`DocumentWindow`（窗口壳）、`ViewTransform`（缩放/平移）、`InkLayer`（笔迹/工具/选择）、
     `PdfPageRenderer`（PDF 页渲染）、`ImageDropService`（图片拖入）；
   - 不共享：白板的“页 = 纵向一段”、笔记的“Notebook/Section/Page”、PDF 的“页”、
     展台的“摄像头帧”是四种内容模型，**不要硬塞进同一个文档类**。

3. **白板 = 分页纵向画布 + 缩放/平移 + 图片拖入。**
   - 页：沿用现有“一屏一页 + 连续纵向滚动 + 页码条翻页”的模型；
   - 缩放：25%～400%，`Ctrl+滚轮` / 双指捏合 / 工具条 ± / `Ctrl+0`；
   - 放大后必须能左右/上下平移；平移只动相机，不动笔迹坐标；
   - 图片：从资源管理器/剪贴板直接拖入，落在鼠标位置，一步撤销；
   - 不做 OneNote 的无限二维画布；白板的“无限”只指**纵向可以一直往下写**。

4. **笔记 = 独立的 OneNote 式笔记本。**
   Notebook → Section → Page；左侧目录/页面列表；页面画布；手写、图片、PDF 导入；
   导出 PDF/图片。第一版建议**页面用固定 A4/Letter 纸（可横竖）**（便于打印/导出/PDF 对齐），
   “无限页面”作为后续页面类型，不要第一版就做。

5. **PDF 窗口 = 按页批注 + 自己的批注存档 + 可导出“压平 PDF”。**
   PDF 原文件不动；批注存 sidecar（`.inkb` 一类）；导出时把“页图 + 墨迹”合成新 PDF。
   这样可编辑、可回退、不会破坏原文件；标准 PDF 注释（可被 Adobe 读）后置。

6. **视频展台 = 普通窗口 + 摄像头 + 冻结/抓拍/批注。**
   MVP 对齐 IPEVO 的高频功能：选摄像头、1080p30、冻结、抓拍、批注、缩放/旋转/镜像、保存 PNG；
   录制、分屏、画中画、扫描/纠偏放 P1。先做 3～5 天 Media Foundation 技术验证。

7. **工期（1 人粗估）**：
   P0 窗口验证 3～5 天；P1 白板 MVP 3～4 周；P1b 覆盖层白板替换 1～2 周；
   P2 共享接缝 + PDF 4～5 周；P3 笔记 MVP 8～12 周；P4 展台 MVP 5～7 周。
   **顺序做约 21～30 周（5～8 个月）**；展台技术验证可以提前并行；P1b 性能不达标就跳过。
   这不是“9～13 周做完四个”，四个都要“该有的功能”，工程量必须按这个量级算。

## 二、现状：哪些能复用，哪些必须补

### 2.1 可复用的事实

| 能力 | 现状 | 对四个入口的意义 |
|---|---|---|
| D2D/DComp 画布 | 覆盖层用 DComp 交换链绑定 HWND（`Overlay.cs:1051`、`:1084`） | 普通窗口也可用 `CreateTargetForHwnd`（微软示例支持 `WS_OVERLAPPEDWINDOW`），渲染器有机会直接复用 |
| 笔迹/压感/湿墨 | 已在覆盖层跑通 | 白板/笔记/PDF/展台共用同一套 InkLayer |
| 分块缓存/脏区 | 已有 | 缩放后按可见块渲染，4 GB 机器不炸 |
| 页面/页键 | `BoardPageKey`、文档负数页键（`Model.cs:7317`、`Doc/DocStore.cs:49`） | 白板/笔记/PDF 都能按页存 |
| PDFium | 已有 PDF 打开/渲染（`Doc/Pdfium.cs`） | PDF 窗口 + 笔记 PDF 导入共用 |
| 图片对象 | 现有截图/图片/美化 | 白板/笔记的图片拖入共用 |
| PPT 页码条 | `PptBar` 几何/命中/跳页 | 白板/PDF 的页码条可复用 |
| PerMonitorV2 | `app.manifest:7` | 窗口 DPI 有基础 |

### 2.2 必须补的底层

| 缺口 | 现状 | 影响 |
|---|---|---|
| **视图缩放** | `CanvasToWindow` 只有平移（`Overlay.cs:283`） | 白板缩放、PDF fit、笔记缩放、展台 fit 都缺 |
| **二维平移** | 引擎只有 `ViewOffsetY`；`ViewOffsetX` 在 Overlay 存在但引擎置 0（`Engine.cs:4118`） | 放大后左右移、OneNote 式画布都缺 |
| **窗口模式** | 覆盖层 `TOPMOST/TOOLWINDOW/NOACTIVATE` + `WS_POPUP`（`Overlay.cs:973`、`:976`） | 没有普通窗口、任务栏、最小化/最大化 |
| **页高与视口分离** | `PageHeightCanvas = _virtualH`（`Engine.cs:12502`） | 窗口改大小会改变页边界；白板分页必须拆开 |
| **内容源抽象** | 现在白板/文档/PPT 混在 `InkEngine` 分支里 | 四个入口会互相拖累；必须先切接缝 |
| **图片拖入** | 现有导入/截图，但没有窗口级 OLE 拖放 | 白板“拖图片进来”缺 |
| **笔记本模型** | 没有 Notebook/Section/Page | 笔记软件从零建文档模型 |
| **摄像头** | 没有代码，只有计划 | 展台从零接 Media Foundation |
| **窗口级文字输入** | 现有 RichEdit 宿主按覆盖层/屏幕设计 | 窗口模式要重新锚定 owner/焦点/DPI |

> 关键判断：**四个入口不是四个独立软件，而是“一个窗口层 + 四套内容层”。**
> 先把窗口层和 `ViewTransform` 做对，后面三个才不会各写一遍。

## 四、白板：详细规格

### 4.1 定位

> **课堂白板**：分页、能翻页、能纵向一直写、能缩放/平移、能把图片直接拖进来。
> 不是 OneNote，不是无限二维画布，不是课件制作工具。

### 4.2 内容模型

```text
WhiteboardDocument
  ├─ Pages（有序）
  │    ├─ Page 1：纵向一段画布（固定页宽；页高 = 一屏）
  │    ├─ Page 2
  │    └─ ...
  ├─ Objects：笔迹 / 高亮 / 图形 / 图片 / 文本 / 截图
  └─ 每个对象带 Page 归属
```

- **页 = 纵向一段 + 对象归属标记**（沿用 `计划-白板与PPT-页逻辑.md` 的结论）；
- 连续纵向滚动可以跨页缝；页码条“上一页/下一页”整屏跳；
- “清空本页”只清当前页对象；另有“清空整块板书”（二次确认 + 一步撤销）；
- **页尺寸在文档创建时固定**：推荐 16:9（例如逻辑 1600×900）；窗口缩放/换屏/换 DPI 都不改页宽页高；
- 初始视图按“适应宽度/整页”算一个 scale；窗口比页大就留板色，窗口比页小就缩放或滚动；
- 第一版不做“页内自由 2D 无限画布”；纵向无限、横向按页宽。

#### 页与缩放的规则（回答“怎么算页 / 缩小后能不能写”）

```text
页 1：y =    0 ..  900
页 2：y =  900 .. 1800
页 3：y = 1800 .. 2700
        ↑ 三张固定 16:9 的“大纸”竖着接起来
```

| 问题 | 规则 |
|---|---|
| 支持连续纵向滚动吗？ | **支持**。滚轮可以平滑滚过页缝，像一条长纸；页码条只是把这条长纸切成固定页。 |
| 页数怎么算？ | 页边界是固定 y 区间；页数 = 最大“有内容/手动创建”的页；空白页也可以存在。 |
| 页码条显示哪一页？ | 显示当前视口所在的页（通常按视口中心/顶部算），翻页按钮一次跳一页（±900）。 |
| 缩小后同时看到好几页，能在“别的页”上写吗？ | **能**。笔落在哪一页，这一笔就归哪一页（按**起笔点**算），不是按页码条当前页算。 |
| 跨页缝写的一笔归谁？ | 归**起笔点所在页**；清空本页只删归这一页的对象，不会误删另一页。 |
| 窗口缩放会改页吗？ | **不会**。窗口只改视图（scale/translate）；页尺寸、页边界、对象归属都不变。 |
| 为什么页尺寸不跟窗口走？ | 否则窗口一拉大，页边界变了，原来第 2 页的内容会跑到第 1 页，页码/清空/存档全乱。 |

> 一句话：**页是固定的“纸”，滚动是连续的“长纸”，缩放着的是“相机”。**
> 缩小后看到三页，你在哪一页上写，就归哪一页；这正是老师想要的“看到哪写到哪”。

### 4.3 功能矩阵

| 模块 | MVP（第一版） | P1 | P2 |
|---|---|---|---|
| 页 | 新建/上一页/下一页/跳页/页码显示 | 删除/复制/拖动排序/缩略图 | 页模板/页背景/导入 PDF 页 |
| 画笔 | 笔/荧光笔/橡皮/激光/撤销/重做 | 图形/文本框/选择/移动/缩放/旋转 | 图层/锁定/组合 |
| 缩放/平移 | 25%～400%；`Ctrl+滚轮`、双指捏合、`Ctrl+0`、适应宽度/整页 | 工具条 ±、缩放百分比、滚动条 | 缩放记忆/每页独立视图 |

> 学科工具、课件生态；这些按 P1/P2 接，MVP 先把“写、翻、缩、拖图、存”做稳。
> 如果要求第一版就含图形/文本/选择，P1 工期从 3～4 周加到 5～6 周。

### 4.4 缩放/平移（必须一次做对）

```text
内容坐标（画布）
   │  ViewTransform: scale + translate
   ▼
窗口坐标（客户区）
```

- 缩放范围：0.25～4.0；默认 1.0；`Ctrl+0` 回 1.0；适应宽度/整页是“计算出的 scale”；
- 以指针为锚（Ctrl+滚轮），双指捏合以两指中点为锚；
- 放大后：空格/中键拖动、双指平移、滚动条；左右上下都要能移；
- **笔宽屏幕恒定**：书写瞬间按屏幕粗细，存画布单位时 ÷ scale；
- **命中容差屏幕恒定**：选区手柄/橡皮/按钮不被缩放放大；
- **只重渲可见块**：分块缓存按 scale 重渲可见区域，绝不整页高清；
- 覆盖层/PPT 保持 scale=1，避免回归。

> 现有 `CanvasToWindow` 只有平移（`Overlay.cs:283`）；要按
> `计划-PDF批注-老师场景与优化清单.md:288-317` 的补偿点逐项过：
> 渲染矩阵、脏区、页窗口、分块缓存、笔宽、选中框、命中容差、滚轮步长、截图/导出。

### 4.5 图片拖入（用户点名要的功能）

- 实现：普通窗口注册 OLE `IDropTarget`（拖入高亮/预览）；兜底 `WM_DROPFILES`；
  覆盖层不适合 OLE 拖放，窗口模式正好是它的强项；
- 入口：资源管理器拖文件、浏览器拖图、剪贴板粘贴、现有“插入图片”；
- 支持：PNG/JPG/BMP/GIF/TIFF/WebP（WebP 视解码库而定）；
- 交互：拖到窗口 → 显示落点高亮/预览 → 松手插入；多文件按网格/层叠放置；
- 位置：以落点为中心；默认最大边不超过页宽的 80%；保持比例；
- 解码：异步；大图先降采样（4 GB 机器不爆）；失败只提示，不动当前状态；
- 撤销：整次插入一步撤销；插入后自动选中，方便移动/缩放；
- 层级：图片在板底之上、墨迹之下（或按插入顺序）；第一版**图片移动不带动已有墨迹**，
  “墨迹跟图”作为 P2 的 anchor 能力；
- 旧图/大图：按需释放位图；分块缓存只保留可见。

### 4.6 参考与差异

- 照搬希沃/OpenBoard：**分页 + 拖图片进页面 + 翻页**；
- 照搬 Xournal++：**页集合 + 缩放/翻页 + 导出**；
- 不照搬：OneNote 无限页面、Microsoft Whiteboard 无限画布、希沃云课件/学科生态；
- 我们的差异：原生 D2D 墨迹、4 GB 优化、与现有覆盖层/PPT 批注共存、单窗口单文档先跑通。

## 五、笔记：详细规格（独立入口）

### 5.1 定位

> **OneNote 式笔记本**：Notebook → Section → Page；左侧目录/页面列表；
> 手写为主，能导入图片/PDF，能导出 PDF/图片。不是白板，不是 PDF 阅读器。

### 5.2 内容模型

```text
Notebook（笔记本）
  └─ Section（分区）
       └─ Page（页）
            ├─ Background：空白 / 横线 / 网格 / 点阵 / PDF 页
            ├─ InkLayer：笔迹/高亮
            ├─ Images：图片
            └─ TextBlocks：文本（P1）
```

- 第一版建议**页 = 固定 A4/Letter 纸**（可切横/竖），便于打印、导出、PDF 对齐；
- “OneNote 式无限页面”作为后续**页面类型**（P1/P2），不要第一版全做；
- 页面列表在左侧，显示缩略图/标题/日期；支持新建/删除/重命名/拖动排序；
- 分区/笔记本可折叠；第一版可以只做“一个笔记本 + 多分区 + 多页”，
  但数据结构按 Notebook/Section/Page 建，避免以后迁移。

#### 固定 A4 的缩放规则（回答“A4 放大缩小怎么处理”）

| 问题 | 规则 |
|---|---|
| A4 页会跟着缩放变大变小吗？ | **不会**。A4 是纸的尺寸（210×297mm 映射成固定页坐标）；缩放只改“看它的相机”。 |
| 放大/缩小怎么操作？ | `Ctrl+滚轮`、双指捏合、工具条 ±、`Ctrl+0`；默认“适应宽度/整页”。 |
| 放大后写，字会变粗吗？ | 笔宽按**页面单位**存（类似 0.5mm）；放大只是看得更清楚，导出/打印粗细不变。 |
| 缩小后能写吗？ | 能，在 A4 页范围内任意位置写；只是屏幕上看变小了，落在纸上的位置/大小不变。 |
| 缩小后线看起来太细？ | 正常，和看一张缩小的纸一样；要写小字时放大再写。若实测觉得手感差，可加“屏幕恒定笔宽”选项（默认不开）。 |
| 能写到 A4 页外面吗？ | 不能，超出页边会被裁掉/限制；要“随便写多大”就用后续的“无限页面”类型。 |
| 导出/打印会变吗？ | 不会；导出按 A4 页坐标合成，和屏幕上缩放无关。 |

> 一句话：**A4 是纸，缩放是相机；纸不变，字的位置和粗细（按纸算）不变。**

### 5.3 功能矩阵

| 模块 | MVP（第一版） | P1 | P2 |
|---|---|---|---|
| 目录 | 笔记本/分区/页面树；页面缩略图；当前页高亮 | 拖拽排序/复制/搜索 | 多笔记本/收藏/最近 |
| 页面 | 新建/删除/重命名/翻页；A4 纸；横竖切换 | 模板/页背景/页面尺寸 | 无限页面/分栏 |
| 手写 | 笔/荧光笔/橡皮/激光/撤销/重做 | 选择/移动/缩放/旋转/图形 | 图层/组合/压感笔刷 |
| 图片 | 拖入/粘贴/插入；移动/缩放 | 裁剪/旋转/层级/美化 | 墨迹跟图/anchor |
| PDF | 导入 PDF → 每页变成笔记页背景 | 多 PDF/页范围/旋转/裁边 | 搜索/目录/链接 |
| 文本 | 画布文本框（现有） | 富文本/列表/表格 | 公式/OCR |
| 导出 | 整本 PDF（压平） | 单页 PNG/页范围/打印 | 导出带书签/原 PDF 叠加 |
| 保存 | 本地笔记本 + 自动保存 | 备份/恢复/最近 | 同步/云（后置） |
| 搜索 | 不做 | 页码/标题搜索 | 手写/全文搜索 |

### 5.4 导入/导出细节

- **导入图片**：拖入当前页；多图按网格；大图降采样；一步撤销；
- **导入 PDF**：选择 PDF → 每页变成一页笔记，PDF 页图作为背景；
  批注存自己的页键；原 PDF 可选择“复制进笔记本目录”或“引用原路径”；
  第一版建议**复制进笔记本目录**，换机器/发学生不丢；
- **导出 PDF**：逐页“背景 + 墨迹 + 图片”离屏合层 → 新 PDF；不覆盖原文件；
- **导出图片**：当前页/选中页 PNG；
- **备份**：整个笔记本目录打包；恢复时校验版本。

### 5.5 参考与差异

- 照搬 OneNote：**Notebook/Section/Page + 左侧目录 + 页面画布**；
- 照搬 GoodNotes：**笔记本/页面缩略图 + 模板 + PDF 批注 + 导出**；
- 照搬 Xournal++：**PDF 页作为背景 + 批注独立存**；
- 不照搬：OneNote 云同步/协作/搜索索引、GoodNotes AI/学习卡、Notability 录音同步；
- 我们的差异：本地优先、Windows 原生、与白板/PDF/展台共享墨迹引擎和窗口层；
  第一版不做云、不做账号、不做 AI 笔记。

### 5.6 工期

- MVP（目录/页面/手写/图片/PDF 导入/导出/保存）：**8～12 周**；
- 模板/缩略图/文本/搜索/备份：再加 **4～6 周**；
- 无限页面/图层/OCR/同步：另立阶段。

## 六、PDF 窗口：详细规格

### 6.1 定位

> 打开一份 PDF，在普通窗口里按页批注；不改原文件；可导出带批注的新 PDF。
> 不是笔记软件，不建 Notebook/Section；一份 PDF 一个文档。

### 6.2 内容模型

```text
PdfDocument
  ├─ Page 1：PDF 页图 + 该页 InkLayer（页键）
  ├─ Page 2
  └─ ...
批注存储：sidecar（按 PDF 哈希/路径），不写回原 PDF
```

- 每页一个页键；切页 = `Doc.SwitchPage(pageKey)`；
- 页图由 PDFium 渲染；只渲可见块/当前页附近；
- 批注存页坐标；窗口缩放/DPI 只改 ViewTransform；
- 导出：页图 + 墨迹离屏合层 → 新 PDF；原文件不动。

### 6.3 功能矩阵

| 模块 | MVP | P1 | P2 |
|---|---|---|---|
| 打开 | 文件对话框/拖入/最近 | 多标签/多窗口 | 加密 PDF/书签/目录 |
| 浏览 | 页码条/翻页/跳页/滚轮 | 页面缩略图/双页/连续 | 搜索/大纲/链接 |
| 缩放 | 25%～400%；适应宽/页；`Ctrl+0` | 缩放记忆/旋转 | 双页缩放同步 |
| 批注 | 笔/荧光/橡皮/激光/撤销/重做 | 文本框/图形/高亮文字 | 标准 PDF 注释/签章 |
| 保存 | sidecar 自动保存/读回 | 备份/最近 | 跨机器同步 |
| 导出 | 压平 PDF（光栅） | 矢量叠加/页范围 | 打印/水印 |
| 页面 | 旋转/页面信息 | 删除/插入/重排 | 合并/拆分 |

### 6.4 参考与差异

- 照搬 Drawboard：**页面面板 + 每窗口完整工具集 + 多窗口“在新窗口打开”**（后置）；
- 照搬 Xournal++：**PDF 页作为背景 + 批注独立存**；
- 照搬 PDF-XChange：**“压平注释”导出**；
- 不照搬：标签页/多窗口第一版不做；云/协作不做；表单/OCR/400+ 编辑不做；
- 我们的差异：按页批注、原生墨迹、与笔记共享 PDF 渲染器、本地 sidecar、4 GB 优化。

## 七、视频展台：详细规格

### 7.1 定位

> 普通窗口里的书展台：看摄像头、冻结、抓拍、在画面上批注；对齐 IPEVO/HoverCam 的高频功能。
> 第一版单摄像头；录制/分屏/画中画后置。

### 7.2 状态机

```text
Live ──冻结──> Frozen ──解冻──> Live
  │               │
  │               ├─抓拍→ Snapshot（可批注/保存/插入白板）
  │               └─多页→ Gallery（P1）
  └─落笔（可选）→ Frozen（默认“落笔自动冻结”，可关）
```

### 7.3 功能矩阵

| 模块 | MVP | P1 | P2 |
|---|---|---|---|
| 摄像头 | 枚举/选择/热插拔/占用提示 | 分辨率/帧率选择 | 无线/手机摄像头 |
| 预览 | 窗口；适应/铺满；1080p30 | 4K（设备支持） | 多摄像头 |
| 冻结 | 空格冻结/解冻 | 冻结帧美化 | 实时冻结缓冲 |
| 抓拍 | F 抓拍；保存 PNG | 画廊/多页/插入白板 | 连拍/延时 |
| 批注 | 笔/荧光/橡皮/激光；冻结帧批注 | 文本/图形/选择 | 实时批注（GPU） |
| 视图 | 缩放/平移/复位；旋转 0/90/180/270；镜像 | 网格/参考线/放大镜 | 聚光灯/幕布 |
| 录制 | 不做 | MP4 录制/暂停/截图 | 慢动作/延时/直播 |
| 分屏 | 不做 | 2 路并排 | 4/16 路多分屏 |
| 画中画 | 不做 | PiP | 多 PiP |
| 扫描 | 不做 | 文档边缘/四点透视/去阴影 | 自动扫描/OCR |
| 保存 | PNG；关闭释放摄像头 | 画廊/最近 | 云/分享 |

> 如果“该有的功能都有”要求第一版就含**录制、分屏、画中画、扫描**，
> 展台 MVP 从 5～7 周加到 **9～12 周**；建议先把“看/冻/拍/写”四件事做稳，
> 这四件是课堂每天用的，录制/分屏是加分项。

### 7.4 技术路线

- **Media Foundation `IMFSourceReader`**：枚举 UVC、打开 1080p30、拿 BGRA；
- 上屏：D3D11 纹理（优先）或 D2D 位图；只取最新帧、丢旧帧，目标延迟 <100 ms；
- AOT：MF 的 COM 接口要像 PDFium/PptCom 一样手写 vtable（`publish.ps1` 默认 NativeAOT）；
- 冻结：复制当前帧到稳定位图；批注存帧坐标；窗口缩放只改 fit；
- 抓拍：保存 PNG；P1 加画廊/插入白板；
- 异常：设备被拔/被占用/权限拒绝，明确提示，不崩。

### 7.5 参考与差异

- 照搬 IPEVO：**选摄像头/冻结/抓拍/批注/缩放/旋转/镜像**；
- 照搬 HoverCam：**并排/多分屏/多页扫描/对焦曝光**（P1）；
- 不照搬：录制全家桶/慢动作/延时/无线第一版不做；不做硬件绑定；
- 我们的差异：与白板/笔记/PDF 共用墨迹和窗口层；抓拍可插入白板/笔记。

## 八、共享架构（四个入口怎么不互相拖累）

```text
EntryPoint（whiteboard / pdf / notes / visualizer）
  └─ WindowManager（入口表；单实例；一次一个文档窗口）
       └─ DocumentWindow（普通 HWND + 系统标题栏 + 任务栏 + 位置/DPI）
            ├─ CanvasHost（交换链 + Present + 输入坐标）
            ├─ ViewTransform（scale + translate；白板缩放/PDF fit/笔记缩放/展台 fit）
            ├─ InkLayer（笔迹/工具/选择/撤销；按页键）
            ├─ ContentSession
            │    ├─ WhiteboardSession（分页纵向画布）
            │    ├─ PdfSession（PDF 页 + 按页批注）
            │    ├─ NotesSession（Notebook/Section/Page + 侧边栏）
            │    └─ CameraSession（摄像头 + 冻结/抓拍）
            ├─ Chrome（窗口内工具条 / 页码条 / 侧边栏 / 菜单）
            └─ SavePolicy（自动保存 / 关闭确认）
```

### 8.1 共享与不共享

| 组件 | 共享 | 说明 |
|---|---|---|
| `DocumentWindow` | ✅ | 窗口壳、系统 chrome、任务栏、DPI、位置记忆 |
| `ViewTransform` | ✅ | 白板缩放、PDF fit/zoom、笔记缩放、展台 fit |
| `InkLayer` | ✅ | 笔迹/高亮/橡皮/激光/选择/撤销；按内容坐标 |
| `PdfPageRenderer` | ✅ | PDF 窗口 + 笔记 PDF 导入 |
| `ImageDropService` | ✅ | 白板 + 笔记的图片拖入/粘贴 |
| `TextEditService` | ✅ | 窗口内文字输入；owner=窗口 |
| `WhiteboardDocument` | ❌ | 白板分页模型，不给笔记用 |
| `NotebookDocument` | ❌ | 笔记层级模型，不给白板用 |
| `PdfDocument` | ❌ | PDF 窗口模型；笔记只借用“PDF 页 → 背景” |
| `CameraSession` | ❌ | 展台独有 |

### 8.2 坐标纪律

- 白板：画布坐标；页归属在对象上；
- 笔记：页坐标；页内对象坐标；页间不共享；
- PDF：页坐标；每页一个页键；
- 展台：帧坐标（0..1 或固定 1920×1080）；
- 窗口缩放/DPI/最大化只改 `ViewTransform`；**批注永远不存窗口坐标**。

### 8.3 单窗口单文档的边界

- 第一版：一个进程、一个文档窗口；切换入口 = 换当前文档；
- 多窗口并排（白板 + PDF、笔记 + PDF）需要拆 `Doc` 与 `View`，约 4～8 周；
- 不要用“每个窗口 new 一个 InkEngine”硬凑：设备/缓存/输入定时器翻倍，4 GB 机器先炸。

## 九、路线与工期

> 顺序原则：先地基（窗口/缩放/图片拖入）→ 先白板 → PDF → 笔记 → 展台。
> 展台技术验证可以提前并行，避免 Media Foundation 最后爆雷。

|---|---|---|---|
| **P0** | 普通窗口 + 现有 D2D/DComp 画布 + 笔 + 缩放/平移探针 | 3～5 天 | 笔迹延迟/窗口缩放/DPI/中文输入通过 |

| **P2b** | PDF 窗口：打开/翻页/缩放/按页批注/保存/压平导出 | 3～4 周 | 大 PDF/缩放/批注重建/导出 |

**总计**：
- 白板 + PDF ≈ **8～10 周**；
- 再加笔记 ≈ **16～22 周**；
- 再加展台 ≈ **20～28 周**（约 5～7 个月）。
- 如果四个都要“该有的功能”，这是合理量级；不要按“9～13 周”估。

**建议的第一条提交**：
P0 探针通过后，P1 只做“普通窗口 + 白板底色 + 笔 + 分页 + 缩放/平移 + 保存”，
图片拖入作为 P1 的第二条提交，不把 PDF/笔记/展台混进来。

## 十、自检建议

| 层级 | 自检 | 内容 |
|---|---|---|
| 窗口 | `--winboardtest` | 窗口样式/任务栏/客户区/最小化/最大化/位置记忆 |
| 白板 | `--winboardtest` | 写/擦/撤销/翻页/清页/缩放/平移/拖图/保存往返 |
| PDF | `--pdfwintest` | 打开/翻页/缩放/按页批注/重建/导出 |
| 笔记 | `--notestest` | 建本/建分区/建页/写/导入图片/导入 PDF/导出/重开 |
| 展台 | `--camtest`（现有）+ `--visualizertest` | 枚举/打开/冻结/抓拍/批注/热插拔/释放 |
| 共享 | `--viewtest` | ViewTransform 往返不漂；缩放后命中准；DPI 切换 |

规则：
- 每阶段只跑相关自检（项目最高原则）；全量只在发布前；
- 自检优先无窗口/离屏；真窗口用隐藏窗口或截图；
- 每个自检 ≤10 条关键断言，最好带一张截图；
- 断言“不变量”，不只挑例子：
  - 缩放 100%→200%→100% 后，笔迹坐标/命中/截图位置不变；
  - 翻页/清页/撤销后，对象页归属不变；
  - 图片拖入失败不改变文档版本；
  - 关窗/重开，批注页键和页图对齐。

## 十一、风险清单

| # | 风险 | 表现 | 缓解 |
|---|---|---|---|
| 1 | 渲染器与覆盖层耦合 | 普通窗口闪烁/残影/笔迹偏移 | P0 先验证；不行抽最小 CanvasHost |
| 2 | 缩放漏改 | 缩放后命中偏、笔迹错位、截图/导出错 | 以 `CanvasToWindow`/`ScreenToCanvas` 为唯一入口；逐项过 scale |
| 3 | 二维平移 | 放大后左右移不动/滚动条错 | 引擎级 ViewOffsetX；白板页宽固定；自检钉住 |
| 4 | 页高与视口混用 | 窗口改大小后页码/清空/存档乱 | 页高独立；窗口缩放不改页数据 |
| 5 | 混合 DPI | 副屏字变小/错位/最大化越界 | PerMonitorV2；当前窗口 DPI；三档实测 |
| 6 | 输入/焦点 | 窗口不激活、按钮误画、笔捕获丢失 | 普通窗口 + SetCapture；输入优先级表 |
| 7 | 文字/IME | 窗口里丢字/候选窗飘 | 复用 TextEditService；owner=窗口；三种输入法手测 |
| 8 | 图片拖入 | 大图卡死/解码失败/落点错 | 异步解码/降采样/失败当没有/一步撤销 |
| 9 | 覆盖层共存 | 两套工具条/两层板/抢笔 | 一次只让一个演示面；窗口激活覆盖层让开 |
| 10 | 保存/关闭 | 关窗丢板书、重开位置错 | 自动保存 + 关闭确认 + PlacementStore |
| 11 | 笔记范围失控 | 做成 OneNote 全功能，拖 6 个月 | MVP 只做目录/页/手写/图片/PDF/导出；搜索/云/无限页后置 |
| 12 | PDF 内存 | 大 PDF 放大整页高清，4 GB 爆 | 只渲可见块；页位图 LRU；预算封顶 |
| 13 | 展台 COM/AOT | MF 接口在 AOT 下不可用 | 手写 vtable；先 3～5 天验证 |
| 14 | 摄像头异常 | 拔插/占用/权限/分辨率不支持 | 明确提示；重新枚举；不崩 |
| 15 | 多窗口诱惑 | 中途改并排，拖 4～8 周 | 第一版单文档；要并排另立项目 |
| 16 | 范围蔓延 | 四个入口长成四个软件 | 共享窗口/墨迹/PDF；内容模型各自独立；MVP 封死 |

## 十二、拍板与待确认

### 已拍板（2026-11-10）

1. **单窗口、单文档**；多窗口并排另立项目。
2. **白板 = 分页 + 纵向滚动 + 缩放/平移 + 图片拖入**；不是 OneNote 无限画布。
   页 = 固定 16:9（如 1600×900）；连续纵向滚动；翻页整屏跳；窗口缩放不改页尺寸；
   一笔归**起笔点所在页**（2026-11-10 用户同意）。
3. **笔记 = 独立 OneNote 式入口**；有侧边栏/目录、手写、图片/PDF 导入导出；
   第一版页面用**固定 A4/Letter 纸（可横竖）**（2026-11-10 用户同意）。
4. **PDF = 窗口级按页批注**。
5. **视频展台 = 普通窗口 + “看/冻/拍/写”四件事**；录制/分屏/画中画/扫描后置
   （2026-11-10 用户选定第一版先做看/冻/拍/写）。
6. 白板保存第一版先沿用现有全局板书；新建/打开/另存为后置。

### 还需要确认（不影响先做 P0 探针）

1. **默认视图**：白板/笔记打开时默认“适应宽度”（推荐，正常使用左右不留白）
   还是“适应整页”（总览，四周可能留白）？
2. **最小缩放**：默认限制为“适应整页”（推荐，避免满屏空白；设置里可放开到 25%）
   还是直接允许 25%？
3. **图片拖入后墨迹是否跟图走**：第一版建议“不跟”（图片和墨迹独立；移动图片不带走墨迹），
   “墨迹跟图（anchor）”放 P2；还是第一版就必须跟？
4. **标题栏**：系统标题栏（推荐）还是必须自绘/内缩按钮？
5. **笔记 PDF 导入**：PDF 复制进笔记本目录（推荐，便携）还是引用原路径（省空间）？
6. **PDF 批注存储**：sidecar + 压平导出（推荐）还是直接写标准 PDF 注释？
