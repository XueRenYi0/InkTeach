# 设计：统一动作表与“更多”面板（桌面批注 ↔ 窗口白板）

日期：2026-11-10　　状态：**设计稿，P0 前定；不改代码**

> 用户 2026-11-10 定调：
> **桌面批注和窗口白板是合作协作关系，不是谁多余。**
> 同一套工具、同一套图标、同一个动作，在哪个宿主出现由能力决定；
> 不能各写一套“更多”，也不能一边有、一边重复。

---

## 〇、结论先行

1. **只做一张动作表（ActionCatalog），不做两套菜单。**
   每个动作有稳定 ID、图标、名称、分组、处理函数、可用宿主（Overlay / Whiteboard / PDF / Notes / Visualizer）。
   “更多”面板只是这张表的一个视图；桌面批注和窗口白板读同一份。
2. **桌面批注 = 覆盖层宿主；窗口白板 = 文档窗口宿主。**
   两者共享：笔/荧光/橡皮/激光、文本/选择/图形/截图/收藏、保存/打开/导出/回放、计时/点名、设置/帮助/日志、色带、快捷键、图片处理。
   各自独有：覆盖层的穿透/白板/PPT/鼠标模式；窗口的页面管理/窗口全屏/置顶/关闭窗口。
3. **“更多”只放低频、溢出和设置，不重复主 dock。**
   主 dock 常显：页码、笔/荧光/橡皮/激光/手、撤销/重做、图片、更多、缩放。
   放不下的主 dock 动作（1.5 档的激光/重做/图片/适应）**自动进“更多”**，不另写名单。
4. **同一动作两边同文案、同图标、同顺序、同处理。**
   桌面批注里叫“图形”，窗口白板也叫“图形”；桌面批注里“保存…”的图标/行为，窗口白板直接复用。
5. **设置也共用一套键。**
   通用：界面大小、主题、色带常开、笔默认、图片最大尺寸、自动保存、减少动画。
   宿主专属：覆盖层的穿透/PPT；窗口的置顶/全屏/位置记忆。设置页按宿主显示，不复制值。

## 一、两个宿主的角色

| 宿主 | 是什么 | 独有能力 | 不该做什么 |
|---|---|---|---|
| **桌面批注（Overlay）** | 透明置顶覆盖层，在桌面/PPT/任何程序上批注 | 穿透、白板盖屏、PPT 放映联动、鼠标/点击模式、屏幕截图 | 不要做页面文件管理、窗口标题栏、窗口全屏 |
| **窗口白板（Whiteboard）** | 普通文档窗口，分页纵向白板 | 页面管理、文件保存/打开/另存、窗口全屏、置顶、任务栏、图片拖入 | 不要做穿透/PPT 联动/覆盖层鼠标模式 |

> 两个入口都保留：老师在 PPT 上批注用覆盖层；要一块自己的白板、能翻页/保存/拖图，用窗口白板。
> 它们共用引擎和工具，所以老师不用学两套。

### 1.1 目标：先并存，性能达标后“无缝替换”覆盖层白板

用户 2026-11-10 追加：
**如果窗口白板性能好，就用它无缝替换掉原来的覆盖层白板。**

这里的“替换”定义清楚：

- **替换的是实现和入口**：最终老师只看到一个“白板”入口；
- **不替换高频动作**：按一下仍然**瞬间盖住当前画面**，写完再按一下/`Esc`/“退出白板”回 PPT；
- **不引入**文件对话框、标题栏、任务栏、加载等待；
- 性能不达标就**不替换**，继续用旧覆盖层白板，不硬上。

| | 现在的覆盖层白板 | 将来的统一白板（窗口白板实现） |
|---|---|---|
| 入口 | 覆盖层“白板”按钮 | **同一个“白板”按钮**（内部切到新实现） |
| 形态 | 覆盖层白底模式 | 临时全屏白板窗口（无标题栏、无任务栏） |
| 高频动作 | 按一下盖住 PPT、再按回 PPT | **保持一模一样** |
| 页面 | 整屏翻页 + 页码条 | 分页纵向白板 + 缩放/平移 + 页码条 |
| 文件 | 临时，自动存档 | 可保存/打开/另存；临时模式不强制文件 |
| 工具 | 现有笔/色带/图形… | **同一套动作表/图标/色带/设置** |

**替换的性能门槛（先定，避免“感觉差不多”）：**

| 指标 | 门槛 |
|---|---|
| 笔迹延迟 | p50 不退化 >1 ms、p95 不退化 >2 ms（与现有覆盖层同机对比） |
| 帧率 | 书写/翻页/缩放稳定 60 fps；不出现可感知掉帧 |
| 切换速度 | 按“白板”到可写 ≤300 ms；退出回 PPT ≤150 ms |
| 内存 | 比现有覆盖层白板增加 ≤40 MB；4 GB 目标机不换页 |
| 输入 | 笔/手指/鼠标/手写板、掌拒、中文输入与现有覆盖层一致 |
| 稳定性 | 连续开关 50 次、翻页 100 次、睡眠唤醒/切显卡不崩 |

**替换步骤（性能达标才做）：**

1. P1 先做独立窗口白板，旧覆盖层白板保持不动（可回退）；
2. 同机对比性能，过门槛；
3. 加一个**临时全屏模式**：从覆盖层“白板”按钮进入，无标题栏/无任务栏，
   底部 dock 保留；`Esc`/“退出白板”回 PPT；
4. 旧白板内容**一次性迁移 + 备份**到新页模型；迁移失败就回退，不丢数据；
5. 旧覆盖层白板代码保留**一个过渡版本**（项目规矩），然后删除；
6. 最终用户只看到一个“白板”入口；过渡期新入口只在开发开关里出现，不做两个并列按钮。

**暂时没达标时：**

- 两个白板并存，但**用户只看到旧入口**；窗口白板作为独立“白板窗口”入口先给测试/自愿使用；
- 不把“未达标的新白板”推给全体老师；
- 数据先各存各的；达标后再迁移/合并。

**“更多”在临时全屏模式下的差异：**

- “关闭窗口”变成“**退出白板 / 回 PPT**”（危险项，放最后一组）；
- “置顶/任务栏/窗口位置”不适用，隐藏；
- 其余动作与窗口白板一致；`Esc` 也能退出。

## 三、窗口白板“更多”面板：MVP 放什么

> 目标：一屏放得下、年老教师不迷路；低频才进来，高频留在主 dock。
> 分组顺序 = 使用频率，不按字母。

### 3.1 MVP（建议 6 组，约 17～18 格）

```text
更多
├─ 工具        图形    文本    选择    截图    收藏    图片*
├─ 页面        新建页   删除页   页面缩略图
├─ 文件        保存…    打开…    导出…
├─ 视图        全屏     板色/底纹
├─ 帮助        使用说明  日志与反馈
└─ 窗口        关闭窗口
```

`* 图片`：如果 1.5 档主 dock 把“图片”收起来了，这里必须自动出现；不能两边都没有。
`* 激光/重做/适应`：1.5 档主 dock 收起时，也自动出现在“工具/视图”组，不另写名单。

**临时全屏模式（从覆盖层“白板”进入）下的差异：**

- “关闭窗口”换成“**退出白板 / 回 PPT**”，放最后一组危险项；
- “置顶/任务栏/窗口位置”隐藏；
- 其余动作不变；`Esc` 同样退出。

**不放**：笔/荧光/橡皮/手/撤销/重做/页码/缩放——这些主 dock 常显，不在“更多”重复。

### 3.2 P1 再加

- 页面：复制页、清空本页、清空整块、页面缩略图拖排；
- 文件：另存为、最近文件、历史板书；
- 视图：适应宽度/整页、置顶；
- 课堂：计时器、点名、随机一人（复用现有课堂卡）；
- 帮助：检查更新、关于。

### 3.3 0 / 1 / 多 / 溢出

| 状态 | 规则 |
|---|---|
| 0 个 | 不出现空分组；至少保留设置/帮助 |
| 1 个 | 不拉伸、不居中到奇怪位置；按格排 |
| 很多 | 面板内部滚动；分组标题吸顶；不缩格子 |
| 溢出 | 当前项始终可见；分组不静默隐藏；滚动条/翻页 |

## 四、桌面批注“更多”面板：现有内容怎么对齐

现有桌面批注“更多”首页（`FullUi.cs`）是：

```text
课堂：计时器 / 点名 / 随机一人
文档：保存… / 打开… / 墨迹回放 / 关闭文档 / 历史板书
其他：AI 出题 / 使用说明
底栏：设置 / 日志 / 检查更新 / 重启软件 / 退出
```

对齐规则：

- **不删现有项**；把它们的 `ActionId` 接进同一张动作表；
- 窗口白板能用的项（保存/打开/回放/关闭文档/历史/使用说明/设置/日志/更新/退出）用同一 ID、同一图标、同一处理；
- 桌面批注独有的项（鼠标/穿透/白板/PPT）标成 `OverlayOnly`，窗口白板不显示；
- 窗口独有项（新建页/删除页/缩略图/全屏/置顶/关闭窗口）标成 `WindowOnly`，桌面批注不显示；
- 桌面批注的主条工具（文本/选择/截图/图形/收藏）**不搬进“更多”**，避免重复；窗口白板因为主 dock 空间有限，把它们放“更多”；
  这是**同一动作在不同宿主的排布差异**，不是两套功能。

## 五、面板形态：两边都用“全屏模态”

用户 2026-11-10 选定：窗口白板的“更多”用**全屏模态**，不用底部大面板。

- **定义清楚**：窗口里的“全屏模态”= 盖住**整个窗口客户区**（画布暂时消失），
  不是另开一个全屏显示器窗口；它仍然在文档窗口里面。
- 桌面批注的“更多”本来就是覆盖层全屏模态；
- 两边直接复用同一个 `MorePage` 全屏模态组件：
  - 同样的标题栏/返回/关闭/分组标题/格子；
  - 同样的 0/1/多/溢出规则和滚动；
  - 只是动作表按宿主过滤，格子数不同；
  - 窗口里按窗口客户区算宽高/DPI；桌面批注按覆盖层屏幕算。
- 网格：4 列（1.0）/ 3 列（1.3）/ 2 列（1.5）；格子 76 / 90 / 108；
  触摸目标 ≥48/60/72；内容多时面板内滚动，不缩格子。
- 关闭：`Esc` / 左上返回 / 右上 ✕ / 再点“更多”；
- 危险项（清空/删除/关闭/退出）放最后一组，红色文字，二次确认。

> 这样“更多”在两边是**同一套组件、同一张动作表**，只换宿主尺寸和过滤；
> 不再讨论“底部面板 vs 全屏模态”，也不再各写一套。

## 六、设置怎么联动

### 6.1 共用键（只存一份）

- 界面大小：共用 `UiScalePresets`（0.8/0.9/1.0/1.15/1.3/1.5）；
- 主题/高对比/减少动画；
- 色带常开；
- 笔默认颜色/粗细、荧光默认；
- 图片插入最大尺寸；
- 自动保存；
- 快捷键。

### 6.2 宿主专属（不复制值）

- 覆盖层：穿透、白板、PPT、鼠标模式、点击穿透；
- 窗口：置顶、启动最大化、全屏记忆、位置记忆；
- 白板内容：页尺寸 16:9、默认视图（适应宽度/整页）、最小缩放。

设置页按宿主显示对应分组；通用项只有一份，切换宿主不丢。

## 七、实现边界（防止长成两套）

1. **一张 `ActionCatalog`**：`ActionId / Group / Label / Icon / HostMask / Handler / Enabled(ctx)`；
2. **主 dock 和“更多”都从这张表取**：主 dock 取 `Primary` 且放得下的；放不下的自动进“更多”；
3. **不写第二份“窗口版更多名单”**；窗口只是 `HostMask` 不同；
4. **图标只用现有 `Icons.Paths.cs` / `Icons.g.cs` / `PenIcons.g.cs`**；新增动作加进同一表；
5. **处理函数走现有 `IEngineCommands` / 服务**；窗口只换宿主，不复制业务；
6. **自检**：加一个动作时，断言“它在至少一个宿主出现、且不重复”；两个宿主的 More 覆盖测试从表里算，不手写名单。

## 八、拍板与待确认

### 已拍板（2026-11-10 用户）

1. **目标：窗口白板性能达标后，无缝替换覆盖层白板。**
   替换实现/入口，不替换高频动作；按“白板”仍瞬间盖屏、再按/`Esc` 回 PPT；性能不达标不替换。
2. 窗口白板“更多”用**全屏模态**（盖住窗口客户区），和桌面批注复用同一个 `MorePage` 组件。
3. 图形/文本/选择**先放“更多”**，主 dock 保持 8 格高频。
4. 窗口白板“更多”MVP 先按 **6 组 17 项**；全屏模态空间够，P0 用假面板试触摸，再删。
5. **性能门槛**：同机笔迹延迟 p50 退化 ≤1ms、p95 ≤2ms；按“白板”到可写 ≤300ms；
   退出回 PPT ≤150ms；稳定 60fps；内存增加 ≤40MB；4GB 不卡；连续开关/翻页/唤醒不崩。
6. **最终入口**：替换完成后只保留一个“白板”；过渡期新入口只在开发开关里，不做两个并列按钮。
7. **旧数据**：性能达标后一次性迁移 + 备份；迁移失败回退旧白板；旧代码保留一个过渡版本再删。

### 仍按默认执行（不再单独拍板）

- 课堂工具（计时/点名/随机）放 P1，先把白板核心跑通；
- 危险项（清空/删除/关闭/退出）统一放最后一组 + 二次确认；
- 临时全屏模式下“关闭窗口”改为“退出白板 / 回 PPT”，`Esc` 同效。
