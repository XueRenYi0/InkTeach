## 一、先说"为什么现在丑"（修的时候一条条对着改）

现行实现（`Overlay.DrawRadialPalette`，直径 140）的问题是四条，**全是"没照主界面的语言画"**：

| # | 现在 | 主界面是 |
|---|---|---|
| 1 | 图标是临时手画的细线，和主条那套 24px 线性图标不是一个笔法 | 24px 网格、描边 1.9、圆头圆角（Fluent 一套） |
| 2 | 选中 = 半透明蓝块 | **强调色 `#0067C0` 实心填充 + 白图标**（主条激活态） |
| 3 | 盘子小（直径 140），标签挤在扇区里 | 面板按钮 40、图标 24、色片 26——"大一号、留呼吸" |
| 4 | 投影是一层硬偏移（+2.5px 的 10% 黑） | `Tokens.ShadowLight` 的**层叠胀法**（5 层、往外胀 1→16） |

另外一条不是"丑"、但顺手记下：**颜色扇区不能套蓝底**（红/蓝色块压蓝底会发闷），
应该像色带那样"**色片 + 一圈强调色描边**"。

## 三、三个方案（浅色/深色各一张，见设计图）

### 方案 A · 面板盘（推荐）

- 底盘：圆，半径 96（直径 **192**），`Tokens.PanelLight/Dark` + 1px 边框 + `ShadowLight/Dark` 层叠投影；
- 8 个 **46×46 圆角 12 的方块按钮**，摆在半径 60 的环上（和主条按钮同一语言）；
- 工具选中 = **`Tokens.Accent` 填充 + 白图标**；颜色选中 = **色片 + 强调色描边**；
- 名字在**盘外一圈**（11.5px 静音色；选中那格变大变蓝）；
- 中央圆（半径 34）显示当前动作名；
- 指针 → 盘心的虚线 + 落点小圆（拖动时出现）。

**优点**：和主界面最像；图标大、看得清；8 个方向仍然是"划"（标迹菜单的熟手路不变）。
**缺点**：盘子最大（遮挡多一点）。

### 方案 B · 分隔扇盘（保留扇区结构）

- 底盘半径 100；8 个 45° 扇区；选中扇区 = 强调色实心（工具）/ 淡强调色（颜色）；
- 图标（24px）在半径 74、名字（12.5px）在半径 51；
- 中央圆（半径 32）显示动作名；扇区之间留 2.5px 缝。

**优点**：最接近现在的结构（改起来最小）；"扇区"的语义最直白。
**缺点**：名字挤在盘里（不如 A 透气）；浅色主题下扇区边界要克制才不乱。

### 方案 C · 双环盘（工具外圈 / 颜色内圈）

- 外圈 5 个工具按钮（半径 76）；内圈 3 个色片（半径 40，正立）——
  颜色"离中心近"，伸手距离短；中央读数在中间。
- 方向仍然是 8 个（工具 5 个方向 + 颜色 3 个方向）。

**优点**：把"工具"和"颜色"分成两圈，一类一眼看完。
**缺点**：内圈色片和外圈按钮的视觉重量不平衡（左半边空）；**实现时要重新想"内圈怎么划"**
（离中心太近会和死区打架）——留作备选。

## 四、推荐 A + 落地规格（对着 Tokens 抄，不许自创数字）

| 项 | 值 | 出处/理由 |
|---|---|---|
| 盘半径 | 96（直径 192） | 比现在 140 大一圈；名字放得下 |
| 按钮 | 46 × 46，圆角 12 | 主条按钮 40 + 图标 24；46 是"环上放得下 8 个"的最大值 |
| 按钮环半径 | 60 | 46 按钮 + 盘心 34 之间留 8 的呼吸 |
| 图标 | 24px 网格，描边 1.9，圆头 | 照主条（`Tokens.Icon = 24`） |
| 工具选中 | `Accent #0067C0` 实心 + 白图标 | `Tokens.Accent` / `AccentInk` |
| 颜色选中 | 色片 + 2.5px 强调色描边（不压蓝底） | 照色带的高亮语言 |
| 色片 | 26 × 26，圆角 8，顶部一道白 16% 高光 | `Tokens.Swatch`；和上带色片同一画法 |
| 名字 | 11.5px（选中 12.5 / 700 / Accent） | `InkMuted`；主条没有文字先例时用"浮层角标"字号 |
| 中央读数 | 17px / 700 / `Ink` | 保留（新手的"我选了什么"） |
| 投影 | `ShadowLight`（5 层）/ `ShadowDark`（2 层） | 和面板/操作条同一套 |
| 动效 | 出盘 120ms 延迟不变；按 `HoverMs=80` 做选中过渡 | `Tokens.HoverMs` |

**交互一个都不改**：按住 `Ctrl+Q` → 划向扇区 → 松手；死区/划回/落笔取消；穿透不响应；
写字中不响应；放映走临时全局键——全部维持 8.5.0 已验收的行为。

## 七、v4 扇面化（2026-09-30 用户拍板，已实现）

> 调研与尺寸测算见《调研-呼出盘-扇面与比例.md》；定稿对比图
> `design/呼出盘-设计稿v4-定稿方向.html`。

- **形状：方案 S「全扇面」**——8 个 45° 扇格（环带 40→96、图标 24 居中在 R68、缝 2°）；
  选中 = 扇面实心强调色；颜色格 = 淡强调色 + 彩笔保持原色（红/蓝不压蓝底）。
- **图标：改用主条同一套 Fluent 路径**——`tools/gen-icons.ps1` 支持 filled 变体，
  `src/InkEngine/Icons.Paths.cs` 新加 `pen / highlighter / laser(Flash) / eraser / select`
  及各自 filled；呼出盘直接引用 `IconPaths.*`（和主条逐点一致，不再手画近似）。
- **颜色格：色片 → 实心彩笔**（`penFilled` 上色：黑/红/蓝）。
- **排序 V-a**：上下左右＝前四高频（北笔 / 东红 / 南橡皮 / 西荧光笔），
  四角＝次频（东北黑 / 东南蓝 / 西南框选 / 西北激光）。
- **判位一个没动**（死区 24 / 锁定 36 / 滞回 9°）；`--radialtest` 24 → **26 项**全过
  （新增：排序 V-a、扇面几何自洽两条）。
