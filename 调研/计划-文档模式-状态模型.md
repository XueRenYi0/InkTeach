# 方案：文档模式的"状态"怎么定（文档 ÷ 白板 ÷ 穿透 ÷ 草稿）

> 2026-10-07。由用户实测反馈引发（"PDF 是另选一个状态吗？""要打草稿怎么办？"）。
> 本文是**讨论稿**：先给同行参考与事实，再给完整方案与分期。

---

## 0. 先摆事实：现在到底是什么行为（探针实测，`--docstates`）

| 操作 | 现在的行为 | 用户感受 |
|---|---|---|
| 打开文档 | 文档页画在**透明层**上（桌面从页缘透出） | 接受，但"漂在桌面上" |
| 开白板 | 板色铺开，**文档页还在**（画在板上） | 用户以为"PDF 不见了"（未复现，疑点错「关闭文档」） |
| **开穿透** | 板自动关（既有规则），**文档页还画着** ✗ | **"穿透没用"**（挡着看不见下面） |
| 关穿透 | 板自动恢复 ✓ | ✓ |

**根因**：文档页是"我们的不透明内容"，但**没有任何开关管它**——穿透只管白板 ✗。

## 1. 同行怎么解的（铁律一：先看先进经验）

| 产品 | 模型 | 关键做法 |
|---|---|---|
| **希沃白板 5**（课堂主流） | 课件 + **板中板** | 授课中**下拉出一面新白板盖在课件上**随便写、可保存、关掉回课件；"白板/黑板/课件"切换时**自动保存当前页笔迹**（= 按纸分墨迹） |
| **Xournal++**（开源批注标杆） | PDF 是**页的背景** | 要打草稿就**插一张空白页**（页背景可切：PDF 页 / 空白 / 线格 / 方格）；用户日常就是"在 PDF 页间夹空白页记笔记" |
| **OneNote** | 打印输出 + 无限纸 | 不区分"模式"，直接在打印输出**旁边的空白纸**上写 |
| **本仓库的 PPT 模式** | 每张幻灯片**一套墨迹**（PageSlot） | 用户已接受并在用（README 特色 ⑦"逐页隔离"） |

**共同结论**：没有人做"PDF 模式"这种状态机 ✗；都是
**"纸（背景/内容）"可以有多种，"墨迹按纸分组"，"切换纸别丢墨"** ✓。

## 2. 本项目的模型（把名词先说清）

画布从下到上：

```
① 桌面 / 下层程序      （不是我们的）
② 板底：透 / 白 / 绿 / 黑      ← 「白板」开关管它
③ 底纹 + 页界线          （白板开着时画在板底上）
④ 文档页图（一叠页）      ← 「打开文档」管它
⑤ 墨迹（笔 / 图形 / 图像）    ← 永远最上
⑥ 浮动 / 界面
```

**关键**：文档 = 第 ④ 层（页图）＋ **一块独立的"墨迹页空间"**（第 ⑤ 层里按纸分组）——
**不是"模式"**；与"白板（②）""穿透（交互）"**正交**。

## 3. 完整方案（规则逐条 + 回答的场景）

| # | 规则 | 回答的场景 / 理由 |
|---|---|---|
| **R1** | **打开文档 → 自动开板底（白）**；板底与文档此后互不干扰（板底只影响页外区域） | 页缘有"纸边"，不再漂在桌面上；也杜绝"点白板把 PDF 弄没"的误会（**点白板只是换页外底色**） |
| **R2** | **进穿透 → 文档页图收起**（不画；文档本身不动、墨迹留着）；**退出穿透 → 自动回来** | 解决"穿透没用"；零新增状态（和"进穿透关板、退出恢复"同一套机制） |
| **R3** | **文档页锚在固定画布位置**（从画布约定原点向下铺），不再"锚在当前视口" | 关掉再打开、切走再回来，**位置稳定、批注对得上**（这是当前实现的隐患：现在重开会挪位置） |
| **R4** | **文档墨迹独立成"页空间"**（第三种页空间：桌面批注 / PPT 页 / **文档**），与桌面板书互不污染；切空间时**相机位置各自记忆** | 现在文档墨迹和桌面板书混在一个槽里 ✗；也是"草稿"能成立的前提（见 R5） |
| **R5** | **「草稿」= 一键切到"桌面批注空间"＋ 白板底**：得到一整屏干净白纸，随便写；再按一下**切回文档**（页图、批注、视口全都回来） | **希沃「板中板」同款**；草稿的字存在桌面空间里，**和试卷完全隔离**（不会"留在卷子上"） |
| **R6** | **关闭文档**（真关闭、释放内存）：页图收走、回到桌面批注空间；**板底保持它当时的状态**（不强行开/关） | 关闭=释放（大 PDF 的内存要还）；草稿/桌面板书本来就独立（R4）不受影响 |

**穿透时墨迹为什么留着？** 和 PPT 模式一致（穿透不藏墨，老师要指着刚写的字说话）✓；
文档页图收起是因为**它是我们唯一"不透明的自带内容"**——让开它，下面才看得见 ✓。

**"打开 PPT 时 PDF 让不让开？"** 不联动：各开各的（用户 2026-10-07：打不打开看老师自己）✓。

| 期 | 内容 | 工作量 | 验收 |

| **第一步（小）** | R1 + R2 + R3（自动板底、穿透收页、位置锚定） | 半天；渲染/状态各几行 | 探针 `--docstates` 出图：穿透收页、退出回来；关开文档位置一致 |
