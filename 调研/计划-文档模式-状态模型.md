# 方案：文档模式 = "像打开 PPT 一样"（v2，2026-10-07 用户定方向）

> v1（"文档是白板名下的一层"）被用户推翻 ✗；用户给出更好的方向：
> **"让它像打开 PPT 一样：左下角配 PPT 那样的左右翻页和页码跳转，点页码也出同样的操作——
> 这样它的操作可以直接类比 PPT，不需要我们再管其他的。"**
> 本文 = 把 v1 里仍然成立的部分（状态/穿透/草稿的事实与结论）并进 v2。

## 0. 一句话

**文档模式 = PPT 模式的外壳 ＋ 我们自己的一叠页。**
老师**不用学任何新操作**：底部 `[◀][页码][▶]`、点页码出菜单、`PageUp/Down` 翻页、跳页小键盘、
167ms 翻页动画……全是 PPT 那一套；只是"内容"从"放映中的 PPT"换成"我们铺的 PDF / 图片页"。

> 出处：10-03 调研里早就埋了这条线索——"实现一个'本地页源'（Next/Prev/Goto 只改自己的页号）
> 就能把翻页 / 页号面板 / 菜单全接上"（`调研-文件导入与PDF批注.md` 的代码勘探结论）。

## 1. 复用清单（PPT 那套家当 → 文档模式逐项对表）

| PPT 模式现成的东西 | 文档模式怎么用 |
|---|---|
| 底部条 `[◀][页码][▶]`（`PptBar`，贴屏幕底） | **同一条**：位置 / 样子 / 命中 / 悬停全一样 |
| 点页码 → 菜单（`PptMenuItems` 5 项） | **同一套菜单**，五项按文档换名（见 §2） |
| 页号面板（小键盘跳页，`DrawPptPagePanel`） | 完全复用（663 页的 PDF 就靠它跳） |
| `PageUp/PageDown`、`←→` 翻页 | 复用；文档里"翻页" = 跳到上/下一页**页顶**（连续滚仍用滚轮） |
| 翻页动画（167ms、快出缓停） | 复用 |
| 菜单里的状态显示（回放项右侧"N 笔"、没笔迹时置灰） | 复用 |
| 菜单的"再点确认"（清空） | 复用 |

## 2. 菜单（同一套壳、五项换名）

| # | PPT 版 | **文档版** | 说明 |
|---|---|---|---|
| 1 | 指定页码跳转 | 指定页码跳转 | 完全一样（小键盘） |
| 2 | 自动保存墨迹（开/关） | **自动保存墨迹（开/关）** | **一字不差，而且真做**：文档批注存到 `%LOCALAPPDATA%\InkTeach\Doc\{文档哈希}.inkb`，**打开同一份 PDF 自动读回**（= 10-03 P2 的"按文件+页存档"验收项，2026-10-07 用户点名拉进本期） |
| 3 | 回放本页墨迹 | 回放**这一屏**墨迹 | 同一个功能；粒度按文档改（§3） |
| 4 | 清空所有墨迹 | 清空**文档**墨迹 | 明确范围：只清文档这套，**不碰桌面板书**（要求文档墨迹独立成页空间，见 §3） |
| 5 | 结束本次放映 | **关闭文档** | 真关闭、释放内存（大 PDF 要还）；**先保存再释放** |

分组节奏照旧：`[跳转] | [自动保存] | [回放] | [清空] | [关闭]`。

> **"收起文档"不做**（用户 2026-10-07 定）：穿透已经给了"让开"的路，白板给了"白纸"，文档照在——
> 三个开关各自独立就好 ✓。真需要整屏白纸时：关闭文档 → 白板 → 再打开（**自动保存让"关-开"不丢批注**）。

## 3. 内容与墨迹

- **内容**：文档页图（连续页叠、fit width）——已经有了 ✓
- **墨迹：整个文档一套**（不按页）：
  - 连续滚动、跨页写都自然；"回放/清空"的粒度 = **一屏 / 整份**（所以文案改掉"本页/所有"的歧义）；
  - **为什么不"每页一套"**（虽然 PPT 是）：文档是**连续滚动**的，页缝处两页同时在屏上 ✗，
    按页隔离会让"另一页的墨迹突然看不见" ✗ 视觉矛盾。
    （等将来做"按页存档 / 按页清空"时再解这个矛盾——记在案。）
- **墨迹独立于桌面批注**：文档批注自成一个"页空间"，和桌面板书 / PPT 批注**互不污染** ✓
  （顺便把"打开文档时旧的桌面板书飘在卷子上"这个隐患治了）。

## 4. 状态（类比 PPT 之后，只剩三条）

| # | 规则 | 类比的依据 |
|---|---|---|
| **S1 打开文档** | 页铺在当前视口 ＋ 底部条出现（像"开始放映"）；在 PPT 放映中则先提示"退出放映再开文档"（已有判断）；**白板/文档互不联动**（用户 2026-10-07 定：三个开关各自独立） | "开始放映" |
| **S2 穿透** | 文档页图**收起**（露出下面）、底部条同时收走；退出穿透自动回来 | PPT 模式下穿透时内容在**下层**、墨迹留着所以不挡；文档的内容是**我们的页图**，必须让开 ✓ |
| **S3 关闭文档** | 菜单第 5 项 = 真关闭：**先保存批注** → 释放页位图/PDF → 回桌面批注页空间 | "结束本次放映" |

**打草稿的答案**：
不需要专门功能——**穿透**已经能让开一切；要白纸就点**白板**；
真要"整屏白纸 + 不丢批注"：**关闭文档 → 白板 → 再打开**（自动保存让这一路无损 ✓）。
