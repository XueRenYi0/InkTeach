# 调研：图形与收藏统一面板（2026-11-02）

## 0. 结论

**推荐：界面一个，入口两个。**

- `图形` 格 → 打开同一个面板，默认选中 **图形** 页。
- `收藏` 星格 → 打开同一个面板，默认选中 **我的收藏** 页。
- 面板内部有 `图形 | 我的收藏` 两个页签，随时可以切。
- 不是两个窗口，也不是两个面板；两个入口只是“同一面板的两个默认页”。

这样既解决“图形色带展开太高”，又不删掉用户已经形成的两个肌肉记忆入口。

---

## 1. 现状（代码事实）

| 项 | 现状 |
|---|---|
| 图形入口 | 主条第 9 格 `shapes`；点开后是**上带内联展开** |
| 图形数量 | 3 行：高频 8 + 曲线 7 + 立体 7 = **22 个** |
| 图形带高度 | `34 + 2 × (26 + 6) = 98` 逻辑像素（普通带 34） |
| 收藏入口 | 主条第 11 格 `star`；打开的是独立收藏面板 |
| 收藏面板 | 可拖动 / 可缩放 / 横竖排 / 卡片 72×80 / 分类 / 管理 / 回收站 |
| 收藏面板位置 | 独立持久化，不跟主条长短缩 |

所以“图形带很高”不是错觉：它比普通色带高 **64 逻辑像素**，而且三行都挤在一个格子里。

## 2. 同行参考

| 产品 | 做法 | 对我们的意义 |
|---|---|---|
| Canva | 一个 `Elements` 面板，内部 `Graphics / Shapes / Photos…` 分类；收藏是星标后的筛选 | 一个面板 + 内部分类，是成熟做法 |
| Figma | 一个 `Assets` 面板，内部切文件库 / 团队库 | 一个容器装多类资源，不用开两个窗口 |
| Excalidraw | 图形在顶部工具栏，Library 是另一个独立面板 | 反例：两套入口/两套面板，状态容易分家 |
| PowerPoint | `Insert → Shapes` 一个形状库，按类别分组；没有收藏入口 | 形状库本身可以是一个独立 gallery |
| 我们的收藏 | 独立面板，已经解决拖动/缩放/横竖/分类/管理 | 图形面板可以直接复用这套容器 |

结论：**“一个面板 + 内部页签/分类”比“两个独立面板”更稳**；两个入口只要都指向同一个面板，就不算重复功能。

---

## 3. 三个方案

### 方案 A：一个界面，一个入口

- 只保留 `图形` 格；`收藏` 星格去掉，收藏变成面板里的一个页签。
- 优点：主条少一个图标，概念最简单。
- 缺点：老用户找不到收藏星格；收藏是高频动作，多一步；删入口要迁移，违背“旧入口只保留一个过渡版本”的稳妥做法。

### 方案 B：一个界面，两个入口（推荐）

```
┌ 图形与收藏 ─────────────────────────────┐
│  [图形]  [我的收藏]                 ✕   │
│  常用 / 曲线 / 立体                      │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐ …          │
│  │ 直线│ │矩形│ │椭圆│ │箭头│            │
│  └────┘ └────┘ └────┘ └────┘            │
└─────────────────────────────────────────┘
```

- `图形` 格 → 面板 + 图形页；`收藏` 星格 → 同一面板 + 收藏页。
- 面板内部页签可切；两个入口不产生第二套窗口/状态。
- 优点：保留两个肌肉记忆；一个容器；图形不再撑高主条。
- 缺点：两个图标看起来像“重复入口”，需要用 tooltip/页签明确“同一面板的两个默认页”。

### 方案 C：两个界面，两个入口

- 图形面板、收藏面板各自独立，各自拖动/缩放/记忆。
- 优点：各自可以做得更专用。
- 缺点：两个窗口会互相挡；位置/尺寸/层级/关闭逻辑两套；用户会问“为什么两个收藏/图形窗口不一样”。不推荐。

## 4. 推荐方案 B 的细节

### 4.1 入口与页签

- 主条保留现有两个格子，不新增图标：
  - `shapes`：提示“图形（默认打开图形页）”
  - `star`：提示“收藏（默认打开我的收藏页）”
- **把“没有自己色带”的四格放一起**：`… 选择 / 截屏 / 图形 / 收藏 / 后撤 / 重做 / 更多`。
  - 截屏有自带色带（两种截法），放在图形前面；图形/收藏/后撤/重做四格都没有色带，连在一起。
  - 图形和收藏挨着，蓝色互斥，用户一眼能看出“只能选一个”。
  - 旧规则“收藏固定在截屏之后”这次按用户要求改掉；`CellKeys` 稳定 key 不变，`unpinned` 仍按 key 迁移，不按数字。
  - `Cells` / `CellKeys` 顺序改成 `… select, capture, shapes, star, undo, redo, more`；`LegacyCellKeysV2` 保持旧顺序只用于老配置翻译；`CellsVersion` 加 1，避免老版本按旧下标解释。
  - 分隔线建议改成 `{0, 2, 7, 9, 13, 14}`：选择/截屏一组（都有色带），图形/收藏/后撤/重做一组（都没色带），更多单独一组。最终以实际视觉为准。
- 面板标题：`图形与收藏`；页签：`图形` / `我的收藏`。
- 点当前入口：
  - 面板没开 → 打开并切到对应页；
  - 面板已开且在同一页 → 关闭面板（和现在点收藏格收起一致）；
  - 面板已开但在另一页 → 切到对应页，不关闭。
- 页签切换只改内容，不重置面板位置/大小/横竖。

### 4.2 图形页

- 分类沿用现有三行，但改成页签/分类条：
  - `常用`：直线、矩形、椭圆、圆、三角形、平行四边形、箭头、坐标系
  - `曲线`：椭圆（带焦点）、双曲线、抛物线、正弦、余弦、波浪线、正切
  - `立体`：圆柱、圆锥、圆台、球、棱柱、棱锥、棱台
- 卡片 72×80，和收藏一致；图标 24 或 28。
- 点卡片 = `SetTool(shape)`，**面板常驻**（和收藏面板一样），老师可以接着换下一个图形，或直接去画布画。
- 保留现有“同格再点换档”的快捷键/键盘行为，不因为换面板而丢。
- 22 个暂时不需要搜索；以后超过 30 个再加搜索框。

### 4.2.1 变体不再藏在“再点一次”里（2026-11-02 用户定）

用户原话（整理）：以前空间不够，一个有好多档的图形只能塞进一格、再点换档；
现在面板空间够了，**每个档位各占一张卡**，不要一个图形占好几档。

按现有档位展开后的总数：

| 图形 | 档位 | 卡数 |
|---|---|---:|
| 直线 | 实线 / 虚线 / 点划线 | 3（+2） |
| 抛物线 | 开口上 / 开口右 | 2（+1） |
| 双曲线 | 带渐近线 / 不带 | 2（+1） |
| 焦点椭圆 | 带焦点 / 不带 | 2（+1） |
| 坐标系 | 带网格 / 不带 | 2（+1） |
| 棱柱 / 棱锥 / 棱台 | 三 / 四 / 五 / 六 | 各 4（每个 +3） |
| 其余基础图形 | 1 档 | 22 里其余 15 个 |
| **合计** | | **37 张卡** |

排法（2026-11-02 用户定：**必须有「全部」**）：

- 分类按顺序：**全部 / 常用 / 曲线 / 立体**；默认落在 **全部**。
  - **全部**：37 张，完整目录。
  - **常用**：基础 8 + 直线 2 个变体 + 坐标系 1 个变体 = 11 张。
  - **曲线**：7 个曲线 + 焦点椭圆 1 + 双曲线 1 + 抛物线 1 = 10 张。
  - **立体**：7 个立体 + 棱柱/棱锥/棱台各 3 个变体 = 16 张。
- 图形页固定按 **5 行卡**做高度（8 列 × 5 行 = 40 格，37 张刚好放完）；
  切分类不变高，避免面板上下跳，分类少时留白。
- 卡片标签必须写清档位：`实线 / 虚线 / 点划线`、`开口上 / 开口右`、
  `带渐近线 / 不带`、`带焦点 / 不带`、`带网格 / 不带`、
  `三棱柱 / 四棱柱 / 五棱柱 / 六棱柱`……
- 点卡片 = `SetTool` + **设该档位**；当前卡高亮按“工具 + 档位”判断，不再只看工具。
- 面板里不再用“同一张卡再点一次换档”；键盘上的旧循环快捷键可以保留给熟手，
  但面板卡是直接选档，不隐藏。
- 图标如果不好画成正式 Fluent 图标，就用**墨迹预览**（按该档位画一条小样），
  和收藏缩略图同一套，不硬凑两套图标。

### 4.2.2 卡片尺寸（2026-11-02 讨论）

先澄清数量：展开档位后是 **37 张**，不是 40 张。

收藏卡现在是 84×92；图形卡可以小一档，不必一样大：

| 方案 | 卡片 | 列×行 | 面板内容高 | 评价 |
|---|---|---:|---:|---|
| A（推荐） | **72×82** | 9×5 | 5×82+4×8=442 | 比收藏小约 14%，37 张刚好放 5 行；标签仍放得下 |
| B | 76×84 | 8×5 | 452 | 更接近收藏，但只 8 列，横向空一点 |
| C | 64×76 | 10×4 | 328 | 最矮，4 行放完；但“平行四边形”这类 5 字标签会挤 |

建议 **A：72×82，9 列 × 5 行**：
- 图形页默认内容 442 高，加一级页签/二级顶栏/边距约 **532 逻辑高**；
- 7 列 9 列都能放下，面板宽度仍跟收藏共用（752），不用再分一套宽度；
- 图标 22，标签 11.5，卡片内边距 8；“平行四边形 / 带渐近线 / 六棱柱”都放得下；
- 收藏页仍是 84×92，不受影响；图形页单独一套 `ShapeCellW/H`。

> 如果实测 72 宽仍然挤，退回 B（76×84，8 列）；不建议 C，标签会太小。

### 4.3 我的收藏页

- 完全复用现有收藏面板：分类、管理、导入/导出、回收站、拖动排序、多选。
- 页签切到收藏时，顶部动作条从“图形分类”换成“收藏动作”，不混在一起。
- 现有“点卡片准备插入，插入时收面板”的行为不变。

### 4.4 位置 / 尺寸：位置统一，高度各记各的

- **位置统一**：一个面板只有一份 `x/y` 和一份横竖方向；切页签不搬家。
- **宽度 / 横竖统一**：拖动左右边或换横竖，两个页签一起变。
- **高度按页签各记各的**：
  - 图形页默认约 `760×360`（3 行卡片 + 分类条）；
  - 收藏页沿用现在的 `760×200`（横排）或 `344×560`（竖排）。
- 切换页签时只做高度动画，**贴主条的那条边不动**（贴底就底边不动，贴顶就顶边不动），所以标题栏不会上下跳。
- 手动拖高度只改当前页签记住的高度；手动拖宽度 / 换横竖改的是全局。
- 落盘：`x/y + width + orientation + heightShapes + heightFavorites`。
- 不建议“每个页签记一份完整矩形”：那样切页签会连位置一起跳，用户会以为面板跑了。

### 4.5 两个入口怎么互斥（重点）

**一个面板，两个页签，所以“同时显示”在物理上就不存在。**
不是两个窗口，也不是两个面板；只有一个面板 + 一个当前页签。

状态机：

| 当前状态 | 点 `图形` 格 | 点 `收藏` 星格 |
|---|---|---|
| 面板关着 | 打开面板 → 图形页 | 打开面板 → 收藏页 |
| 面板开着，图形页 | 关闭面板 | 切到收藏页（不关） |
| 面板开着，收藏页 | 切到图形页（不关） | 关闭面板 |
| 面板开着，点页签 | 切到图形页 | 切到收藏页 |

- 任何时候只有一个页签可见；另一个页签的内容只是隐藏状态，不是“也开着”。
- 两个入口各自可点、各自可开可关，但它们操作的是**同一个 `panelOpen + activeTab` 状态**，所以不会出现两个面板。
- 不建议给两个入口各存一个 `open` 布尔值；那会诱导出“两个都开”的状态，正是要避免的。

**选中态（按用户 2026-11-02 定，就按这个做）：**

- `图形` 格蓝色 = 面板开着，且当前是图形页。
- `收藏` 星格蓝色 = 面板开着，且当前是收藏页。
- **两格永远最多一个蓝色**：收藏变蓝时，图形立刻取消蓝色；反过来也一样。
- 面板关着时：两格都不蓝。
- 在面板里点 `我的收藏` 页签，主条同步变成“收藏蓝、图形不蓝”；点 `图形` 页签反过来。
- 这样主条的两格本身就是“当前页”的指示器，不用再分实心/小圆点两套语言。
- 如果当前工具是图形但面板关着，主条不再用蓝色表示工具态；当前工具由画布上的工具状态/图标承担，避免“工具蓝”和“面板蓝”打架。

### 4.6 我的收藏先不动

- 收藏页完全按现有逻辑：分类、管理、导入/导出、回收站、拖动排序、多选、插入。
- 参数化图形收进收藏后，是否保留“拖顶点”的可编辑性，这次不专门改；按现有 `ShapeLibrary` 存/取逻辑走。
- 图形页只是复用同一个容器，不改收藏的数据格式和行为。

### 4.7 键盘 / 触摸

- 现有图形快捷键不变；面板只是鼠标/触摸入口。
- 面板内卡片点击目标不小于 44；触摸可拖动面板标题栏。
- `Esc`：先关面板；面板没开时保持现有行为。
