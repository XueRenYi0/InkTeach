## 一、穿透模式下翻页起不起作用？

### 结论：**起**（我们现在的代码就是这么排的），但**没测过**。

我们这条路的两个关卡都放行了：

| 关卡 | 现在怎么做的 | 在哪 |
|---|---|---|
| 系统层（`WM_NCHITTEST`） | 条那一块回 **`HTCLIENT`**（不是 `HTTRANSPARENT`）→ 系统把输入交给我们 | [Engine.cs](../src/InkEngine/Engine.cs) 的 NCHITTEST 分支：`UiContains(...) \|\| PptBarContains(...)` |
| 引擎层（`OnPointerDown`） | `PptBarPointerDown` **排在 `if (PassThrough) return;` 之前** → 点在条上不会被"让给下层"吃掉 | 同文件，那两句的注释写着"必须在穿透之前" |

⚠ **它现在是一条"没被自检钉住"的性质**——只要以后有人把调用顺序调一下（或者加一条新的穿透判断在前面），
它就悄悄失效，而**教室里开着穿透是常态**（穿透正是老师"讲 PPT 时能点下层"的开关）。
所以这一轮必须补一条自检：**穿透开着 → 点条仍然翻页**。

### 其他家是怎么设计的

| 产品 | 做法 | 穿透时 PPT 控件能用吗 |
|---|---|---|
| **Inkeys / 智绘教** | PPT 控件在**另一个窗口**（`Inkeys2 PptWindow`），和画板窗口分开 | **能**（画板穿透不影响那个窗口） |
| **ICC 社区版** | PPT 导航按钮是**独立的 WPF 面板**（`PPTNavigationBottomLeft` / `SidesLeft` 四块），独立于 InkCanvas 的命中层 | **能** |
| **InkClass** | 穿透 = "**鼠标模式（隐藏画板，点击穿透）**"（`MainWindow.xaml` 里那句 ToolTip 的原文）——它穿的是**画板那一层**，工具条是另一层 | **能** |

**三家一个套路**：把"穿透"限制在**画布层**，工具条/PPT 控件在它之外。
我们和他们等价（只是我们靠"区域豁免"而不是"另一个窗口"——少一层窗口，代价是 NCHITTEST 里要判一下）。
所以这条路**方向是对的**，只差一条自检把它钉住。

## 二、长按菜单要长成什么样

现在只有 1 项（结束放映）。按你说的加两项之后是 **4 项 + 一条分隔线**：

```
┌──────────────────────────┐
│ 自动保存墨迹        开 ▸ │      ← 开关（点一下切）
│──────────────────────────│
│ 清空本页批注             │      ← 安全（可撤销）
│ 清空这份 PPT 的批注      │      ← 危险（连盘删，两段确认）
│──────────────────────────│
│ 结束放映                 │
└──────────────────────────┘
```

尺寸：宽 176（不变），高 4×40 ＋ 内边距 ≈ **184**（现在 1 项时是 52）。
菜单从条的上方往上长（现在就是这么长的），屏幕左下角的条 → 菜单顶到 y ≈ 1480（屏幕 1800 高），放得下。

## 三、你那个逻辑里的**三个问题**（这条最要紧）

### ⚠ 问题 1：「关掉自动保存」≠「不再有墨迹」

这是最容易踩的一条。盘上的旧文件**还在**，所以：

- 老师"第二次用不需要墨迹"→ 只是关掉自动保存的话，**旧墨迹照样在下次进放映时冒出来**（如果哪天又打开）；
- 真正让"不再有"的只有**清空**。

→ 所以：「自动保存」和「清空」**不是二选一，是两件事**，两个都要有（你列的两项正好互补，这点是对的）。

### ⚠ 问题 2：「清空」必须**连盘一起删**，不能只清内存

我们的墨迹是**进放映时从盘读进内存**的。所以：

- 只清内存 → 若「自动保存」开着，退出放映时会把**空内容**写盘（等于删了，碰巧对）；
- 只清内存 + 「自动保存」**关着** → 盘上原样留着 → **下次又冒出来**（老师：我清了啊？）

→ 「清空」要**显式删盘上的文件**，不能依赖"保存空内容"这条间接路径（那条路依赖另一个开关的状态，太脆）。

### ⚠ 问题 3：「清空整份」不可撤销，需要**不弹窗的确认**

- 清当前页可以撤销（走现有的撤销栈）；
- **清整份不行**：它跨页、还把盘上的文件删了——那是**真丢东西**。
- 可我们的产品规范是"**屏幕上一个字都不留**"（不弹对话框，用户 2026-09-16 定的）。

→ 用**就地两段确认**（不弹窗、也不新增手势）：

```
第一次点：清空这份 PPT 的批注
第二次点：再点一次确认        ← 文字变红/变强调，3 秒内有效，超时复原
```

点一下没反应、文字却变了 —— 老师立刻明白"这是要我确认"，而且**误点不会丢东西**。

## 四、我的补充建议（4 条）

### 1. 「清空本页批注」也要进菜单

工具条上已经有一个「清空」，但**放映时它未必在眼前**（可能被收起成球、被贴边隐藏、
或者老师把工具条拖到别处去了）。菜单里再放一个"清空本页"，
是"我人就在这块屏上、随手就能清"的那条路。它**可撤销**，所以放前面、不要确认。

### 2. 「自动保存」我用**一个开关管两头**（读 + 写），不拆成两个

拆成"加载本地墨迹"和"自动保存"两个开关看着更灵活，但有一个**会丢东西的组合**：

> 加载 **关**（干净开始）＋ 保存 **开** → 这节课写的会**按页覆盖**上节课的笔记
> （我们的键是 SlideID，同一页就覆盖同一页）→ **老师上节课的板书没了**。

一个开关管两头，语义就一条：**关 = 这次放映完全不碰盘上的东西**（不读也不写，盘上原样）。
想"永久清掉"用「清空」那一项——**各管各的，不会出现"以为安全其实在覆盖"**。

> 以后真要做"另存一份/多套板书"，要先有"导出/导入"（见第 3 条），再谈拆开关。

### 3. 导出 / 导入批注包 —— 建议**第二批**做

你问的"墨迹要不要保存本地、或者加载本地墨迹"——**已经在做了**（这是上一轮就落地的）：

| 已经在做的 | 在哪 |
|---|---|
| 退出放映自动写盘、进放映自动读回 | `PptStore`：`%LOCALAPPDATA%\InkTeach\Ppt\{课件名_路径哈希}\{SlideID}.inkb` |
| 记"上次播到第几页" | 同目录的 `Position` 文件 |

**还缺的是"显式"的那一半**：导出一个文件带走（换电脑 / 备份 / 一课一存）、从文件导入。
这个要动"**多页存档格式** + 系统另存为对话框"，是独立的一批活，建议**第二批**。
先把菜单这四项落地——它们解决的是老师**每天都会遇到**的问题。

### 4. 一个真实风险：同一个课件文件 = 共用一份批注

我们的存盘键是「**文件名 + 完整路径的哈希**」。所以：

- **换 Windows 账户**（不同老师各登各的）→ 目录天然分开，**不串** ✓
- **同一个账户、同一个课件文件**（同一路径）→ **共用**（换老师上同一节课，会看到上一位的批注）→ **「清空」就是解法** ✓
- 同一个课件但**拷到别的目录**（路径变了）→ 哈希不同 → 不共用（也意味着"拷走课件不会带走批注"——这正是第 3 条那个导出功能要解决的）

这条不用改代码，但要写进文档（知道了就不会当成 bug）。

## 五、落地计划（分两批）

| 批 | 做什么 | 验收要点 |
|---|---|---|
| **1** | 菜单扩成 4 项（开关 + 清空本页 + 清空整份 + 结束放映）＋「自动保存」开关（存偏好、默认开）＋「清空」连盘删 | 开关关掉后**不读也不写**；清空本页**可撤销**；清空整份**内存和盘都空**、两段确认、**退出放映后不复活** |
| **2** | 穿透下点条的自检（补上这条"没被钉住的性质"）| 穿透开着，点 ▶ 仍然翻页、点页码仍然出面板 |

第 2 批看着小，但它是你问的第一个问题的**答案**——答"起不起作用"不能靠读代码，
得有一条会红的断言。**建议和批 1 一起做**（反正都在同一个文件里）。

### 自检要加什么（`--ppttest` 现在 49 项 → 预计 60 项上下）

- 菜单 4 项**都在**、每项都能点中（**逐项点一遍**，不是抽查——"加一项漏一处"是这个仓库的老毛病）
- 自动保存开关：关掉 → 退出放映**盘上没有新文件**；打开 → 恢复正常
- 清空本页：只清本页、**撤销能要回来**、别的页没动
- 清空整份：内存全空 + **盘上文件真的没了** + 再进放映**不会复活**
- 两段确认：第一次点**不执行**、第二次点才执行、**超时不点**复原
- **穿透开着**：点 ▶ 翻页、点页码出面板（这条就是第一节的答案）

## 六、要你拍板的三件事

1. **「清空」放几项**：
   - A（我推荐）**两项都放**：「清空本页批注」（可撤销）+「清空这份 PPT 的批注」（两段确认）；
   - B 只放「清空这份 PPT 的批注」（菜单更短，但"只想清这一页"时得先翻到别处、或者用工具条上的清空）。
2. **两段确认的措辞与超时**：我拟的是"再点一次确认"+ 3 秒超时复原。你觉得 3 秒够不够（还是一直等到点别处）？
3. **「清空这份 PPT」要不要顺带把"上次播到第几页"也清掉**：
   - 我倾向**不清**（那是"播放位置"，不是墨迹，老师下次接着讲还有用）；
   - 但如果你觉得"清空 = 这份 PPT 回到没来过的状态"，那就一起清。
