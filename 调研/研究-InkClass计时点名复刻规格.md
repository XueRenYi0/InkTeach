# 研究：InkClass 计时器 / 点名 —— 行为与视觉复刻规格

> 2026-10-02 · 依据：本机 InkClass 源码逐文件实录
> 位置：`D:\文件集中\code\画布测试\Ink-Canvas-Dev`（`XueRenYi0/InkClass`，GPL-3.0，最后发版 v6.6.3）
> 目标：在 InkTeach（不引入 WPF/Avalonia，引擎自绘）复刻它的入口逻辑、窗口版式与主题色。

---

## 0. 先回答三个问题

1. **"点击图标后调出一个面板"对不对？**
   对。入口在**「更多」面板 → 工具组**里（图标 20×24 + 10px 标签）：`计时器` / `随机点名（全名单）` / `随机一人（抽过的不重复）`。点任一个 → **更多面板立即收起** → 弹出**居中的独立置顶窗**（不是挂在按钮旁边的浮层）。
2. **能不能完全复刻？**
   逻辑/版式/配色都能，数值都在本文件里；只有 5 处"实现层"建议不照抄（见 §2.4），行为不变、内脏换稳的。
3. **主题色能不能复刻？**
   能，InkClass 的深浅两套色值是现成的。而且你说的"黑色透明框太透、看不清"，它去年就踩过并量化修好了：**工具栏 85% 黑；内容密集面板（它就是"更多"）用 97% 黑**，再加 1px `#BFcccccc` 描边（见 §1.4）。

## 1. InkClass 实录

### 1.1 入口与逻辑（MW_FloatBar.cs / MW_MiscFunctions.cs）

| 入口 | 代码 | 行为 |
| --- | --- | --- |
| 计时器 | `new CountdownTimerWindow().Show()` | 每次点击都新开一个窗（可多开，无单例） |
| 随机点名（全名单） | `new RandWindow().Show()` | 900×500 点名窗，手动点「抽奖」 |
| 随机一人（抽过的不重复） | `new RandWindow(true).ShowDialog()` | 自动滚一次出结果，**1.5 秒后自动关窗** |

- 三者都在「更多」面板里；点完先 `BorderTools.Visibility = Collapsed`（收起面板）再开窗。
- 主条图标本身不直接开窗；主条只有「更多」三滑杆入口。

### 1.2 计时器窗 CountdownTimerWindow（1100×700 居中置顶）

**外观**
- 窗口无边框、透明底；可见卡片 = 四周内缩 60px 的圆角面板。
- 面板：底色 `#F0F3F9`、圆角 10、1px 描边 `#0066BF`（浅色主题窗口，即 App 深色时它也是浅色）。

**版面**（设计稿 200×180，Viewbox 等比放大到窗口；实际约 3 倍）
- 环形进度条（自定义 `CycleProcessBar`，`CurrentValue = 1 - 已过比例`，暂停时 `IsPaused`）。
- 大字 `HH:MM:SS`（Segoe UI，设计字号 26）：运行时黑 `#000000`，待机/结束 `#5B5D5F`。
- **时/分/秒三段各自带一对 ± 按钮**：上 `+5 / +1`，下 `-1 / -5`（仅在"改时长"态出现，字号 8）。
- 完成时刻药丸：`#E8EAF0`、高 18、圆角 9、时钟图标 + "12:30 PM"（字号 9），跑动/暂停时显示。
- 底部三颗圆钮（设计 20×20，圆角 100）：
  - 开始/暂停：`#0066BF` 蓝底白图标（Play ↔ Pause）
  - 重置：`#FBFBFD` 白底黑图标（带 0.15 透明阴影）；不可用时盖一层 `#F3F5F9`、图标 `#9D9D9E`
  - 最小化 / 全屏 / 关闭（关闭 = `#E32A34` 红底白叉）
  - 开始按钮在"已结束"时盖 `#BFBFBF` 灰罩。

**状态机**
- 初始 `01:00`，显示进度环；**点时间区进入"改时长"态**（环隐藏、±按钮出现、数字变黑），再点时间区或点 ✓ 返回。
- 开始：从当前 HH:MM:SS 起倒计时；运行中开始键变暂停。
- 暂停/继续：暂停记录 `pauseTime`，继续时 `startTime += DateTime.Now - pauseTime` → **继续不跳秒**。
- 重置：未跑 = 空操作；暂停 = 清零复位；跑动中 = 以当前时长为准**重新开始**。
- 到 0：停表 → 数字回 00:00:00 变灰 → 播 `TimerDownNotice.wav` → 重置钮点亮。
- 最小化：窗口缩成 **400×250**，只显示 56pt 剩余时间 + 底部灰色拖动条；点击大字恢复原窗。
- 全屏：`WindowState = Maximized`（卡片仍是内缩 60px 的大面板）。
- 关闭：`Window_Closing` 里 `isTimerRunning = false`（**关窗即停表**）。
- 拖动：按住时间行（或最小化时的拖动条）。

**实现细节**：`DateTime.Now` 墙上时钟；定时器间隔按剩余时长自适应 20/30/50/100ms（只影响进度环流畅度）。

### 1.3 点名窗 RandWindow（900×500 居中置顶）

**外观**：同款浅色面板（`#F0F3F9` / 圆角 10 / 1px `#0066BF` 描边），左 `1.8*` : 右 `1*` 两栏。

- 左栏：结果大字（FontSize 70）。人数 ≤5 一列；6–10 两列；>10 三列（Label 多行堆叠）。
- 右栏：`[-] 1 [+]` —— 圆形白钮 70×70（`#FBFBFD` + 阴影），数字 55；「抽奖」大按钮 **200×70**、`#0066BF`、圆角 10、白字 35 + 图标；滚动中盖 `#BFBFBF` 灰罩。
- 底部：`#FBFBFD` 药丸（高 40、圆角 20、People 图标 + 16px 文字）——没名单时显示"点击此处以导入名单"，有名单时显示人数；点它打开 `NamesInputWindow`（程序内多行文本框编辑器，保存到 `Names.txt`）；右侧红关闭钮 `#E32A34` 40×40。

**抽取逻辑**
1. 先滚 5 次：每 **150ms** 换一个随机号（这 5 次内不重复）；
2. 再按 `TotalCount` 抽最终结果（**单次内不重复**；号码用尽则重置池子）；
3. 随机范围 `1..PeopleCount`；无名单时 `PeopleCount = 60`。

**名单文件**（程序目录）
- `Names.txt`：一行一名，空行忽略；人数 = 名单行数。
- `Replace.txt`（可选）：`原名-->新名` 替换映射。
- ⚠ 实测：快捷入口 tooltip 写"抽过的不重复"，但代码**没有跨次记忆**（每次新窗口都是全新随机）——"不重复"只保证单次抽取内。这是它的一个"假承诺"，见 §2.4。

### 1.4 「更多」面板的配色体系（Dark.xaml / Light.xaml）

**深色（我们主要抄这套）**

| 键 | 值 | 用途 |
| --- | --- | --- |
| `FloatBarBackground` | `#D9000000`（黑 85%） | 工具栏、浮条等 25 处容器 |
| **`FloatBarBackgroundOpaque`** | **`#F7000000`（黑 97%）** | **内容密集弹层——只有「更多」面板用** |
| `FloatBarBorderBrush` | `#BFcccccc` | 描边（1px） |
| `FloatBarForeground` | `#cccccc` | 图标/文字 |

**浅色**：`#D9FFFFFF` / `#F7FFFFFF` / `#BF666666` / `#666666`（一一对应）。

**InkClass 自己的数值依据（源码注释原文意思）**
- 85% 版：让背后课件内容透出对比度降到 **1.31:1（看不见）**；浅色版原 62% 时透出到 2.12:1，"背景残留物压过面板内容"。
- 97% 版：85% 时"面板内 15 个条目的文字与背后窗口内容重影，视觉上文字叠文字"→ 单独为「更多」面板开高不透明度键。
- 面板细节：圆角 5，padding `10,8,10,10`，组标题 12px 透明度 0.6，条目 = 图标 20×24 + 10px 标签（0.85 透明），列宽 52，组间距 10。

## 2. InkTeach 复刻方案（无框架、引擎自绘）

### 2.1 交互映射

- 现有「更多」面板里的 `[计时器] [点名]` 格子 → 行为改为：**点格子 → 收起面板 → 打开居中窗口**（与 InkClass 一致）。
- 三个入口都复刻：`计时器` / `随机点名` / `随机一人`（自动抽 + 1.5s 自动关）。
- 窗口模型（引擎自绘）：居中卡片、可拖动、最小化（计时器为"只剩剩余时间的小条"）、全屏（卡片放大到工作区-60）、关闭（计时器关窗即停表）。
- 尺寸建议：计时器设计稿 1100×700、点名 900×500；按 `min(1, 工作宽/1200, 工作高/800)` 等比缩放，保持居中。自检机 1440×900 可 1:1。

### 2.2 视觉映射（照抄数值）

| InkClass | 用途 | 我们落地 |
| --- | --- | --- |
| `#F0F3F9` | 窗面板底 | 同值（计时/点名窗口保持浅色，App 深色时也一样） |
| `#0066BF` | 强调蓝（描边/开始/抽奖/✓） | 同值 |
| `#E32A34` | 关闭红 | 同值 |
| `#FBFBFD` / `#F3F5F9` / `#9D9D9E` | 次级按钮 / 禁用底 / 禁用图标 | 同值 |
| `#E8EAF0` | 完成时刻药丸 | 同值 |
| `#5B5D5F` / `#000000` | 数字待机 / 运行 | 同值 |
| `#BFBFBF` | 滚动/结束灰罩 | 同值 |
| 圆角 10 / 1px 描边 | 面板 | 同值 |

字号按设计稿等比缩放（InkClass 用 Viewbox 整体缩放到窗口，我们按同一比例算即可）。

### 2.3 面板与主题（"太透"的修法）

- **「更多」面板改为 `#F7000000`（97%）+ 1px `#BFcccccc` 描边**；这是 InkClass 对"文字重影"的解法，直接抄数值。
- 主条/其它稀疏浮条保持 `#D9000000`（85%）。
- 文字 `#cccccc`；图标/标签同上（标签 0.85、组标题 0.6 透明度）。
- 结果：在黑背景的课件/桌面上，面板边界清晰（描边）+ 内容不再与背景重影（97%）。

### 2.4 不照抄的实现细节（保行为、换内脏）

1. **计时用单调时钟**（`Stopwatch`/QPC），不用 `DateTime.Now`：改系统时间/对时不影响已运行的计时；暂停补偿逻辑保留。
2. 走引擎现有帧循环刷新，不另起 WPF 定时器池。
3. **每窗单实例**：目标窗已开则置前/重置焦点，不学 InkClass 无脑多开。
4. 到点提示音只触发一次；音效可直接搬 `TimerDownNotice.wav`（GPL-3 兼容，记 NOTICE）。
5. "抽过的不重复"二选一：**真做记忆池**（我们原规范的"去重默认开"）或**改掉文案**——不继承假承诺。
6. 名单读取容错：BOM、空行、重名、`Replace.txt` 编码。

### 2.5 与现有 InkTeach 规范的冲突点（待拍板，见 §3）

- InkClass 只有**倒计时**，没有正计时/秒表；且调整粒度是每段 `±1/±5`（不是我们之前定的"±1 分钟"）。
- InkClass 人数上限 = 名单人数（可 >5，三列显示）；我们之前定"一次最多 5 人"。
- InkClass 没有"随机分组"。
- 名字编辑：InkClass 是程序内文本框对话框；我们若不想做文本输入控件，可先用"打开 Names.txt 编辑器"替代。

## 4. 建议

1. 计时/点名窗口 **1:1 复刻**（这是你看中且被课堂验证过的部分）；
2. 「更多」面板**先只换配色规则**（改动小、马上解决"看不清"），版式要不要跟进等第 4 点拍板；
3. 内部实现按 §2.4 换成稳的；
4. 下一步：按本规格先出**两张 D2D 对照图**（计时窗 / 点名窗，含窗口态与浅色数值），你确认后再动代码。
