## 一、总原则

> **「更多」= 纯启动器；点到谁，谁自己负责。**
> **运行型功能 = 引擎侧独立卡片（设置态 ↔ 运行态、可拖、可全屏、关掉「更多」不消失）；**
> **参数类 = 设置子页；命令类 = 点了就执行。**

三条老规矩照旧：一份表管绘制/命中/执行；新功能必配自检；隐藏手势只能是加速器，必须有可见入口
（设置入口 = 常驻 ⚙；长按只准当捷径）。

## 二、启动器（「更多」主页）

- 形态：屏幕中央模态（锚点不变）。宽 = **min(640, 55% 工作宽)**；高按内容算并夹进工作区。
- 结构，从上到下：
  1. 标题行「更多」＋右上 ✕；
  2. 分区与格子（tile **76×76**，图标 26 ＋ 标签 11.5，行距 10、组距 16）：
     - `课堂`：计时器 / 点名 / 随机分组（预留，压暗）
     - `墨迹`：保存 / 打开 / 回放（可用性同旧墨迹页：放映中/空板书置灰，点置灰写状态）
  3. **状态行** 18px：命令反馈（"检查中… / 已是最新 / 下载 42% / 已保存 / 这个文件打不开"）。
  4. **底栏固定四格**：设置 / 检查更新 / 重启 / 退出——位置永不随内容变化。
- 列数自适应：`clamp(floor((内容宽+10)/(76+10)), 3, 6)`；加功能只往下长。
- 进设置子页 = 就地换页（左上返回箭头）；子页内容见《计划》§九（外观/书写/墨迹/工具条）。
- 工具条档位：**钉住宫格只在"自定义"档显示**；极简/完整档给一行提示。

### 分辨率规范化

- 主条档位按**逻辑屏宽**首次自动定一次：**<1300 → 极简；≥1300 → 完整**（1366/1440 的常见教室屏
  保持完整，1280/1024 的老机器自动极简）。用户显式改过（`ui.profile` 有值）就永远听用户的。
- 面板宽按上面 min 规则；高度夹在工作区内。**不做整界面等比缩放**（触摸目标/图标/自检全会被拖下水）。

## 三、功能卡（运行型工具的统一形态）

### 3.1 状态机

| 状态 | 长什么样 | 入口 | 出口 |
|---|---|---|---|
| **设置态** | 该功能的全部可调项 ＋ [开始/重新开始] ＋ ⚙(收起) ＋ ✕ | 启动器点该功能；运行态点 ⚙ | 开始 → 运行态；⚙/开始 → 收起；✕ → 停止并关卡 |
| **运行态** | 大字读数（＋该功能的即时操作）＋ [⏸/▶] ＋ ⚙ ＋ ✕ | 设置态开始 | ⚙ → 设置态（不停）；✕ → 停止并关卡 |
| **放大态** | 屏幕中央大字，**点任意处还原** | 双击卡片 | 任意点击 |

- **同一时刻只允许一张卡处于放大态**；开第二张时先还原第一张。
- ✕ 的语义**唯一**：停止并关卡（v1 不做"隐藏继续跑"）。
- 卡上按钮热区 **≥44×44**；读数区也可点（计时：点数字暂停/继续；到点后点数字从头重开）。

### 3.2 槽位与层叠

| 卡 | 默认槽位 | 位置记忆 |
|---|---|---|
| 计时卡 | 屏幕**顶部居中** | `ui.timerPos`（逻辑偏移） |
| 点名卡 | 屏幕**中央偏上** | `ui.rollPos` |
| 回放条 | 屏幕底中（与主条重叠时抬到上方） | 固定 |
| PPT 条 | 屏幕左下（现有规则） | `ui.pptBar*` |

- 拖动只改位置、不改尺寸；松手夹进屏幕并落盘。
- 到点闪烁 / 滚动中 = 该卡临时参与脏区与置顶，但不抢别的卡的输入。

### 3.3 输入优先级（按此顺序写，进自检）

```
图库面板 → 回放条 → 界面（启动器/设置）→ 计时卡 → 点名卡 → PPT 条 → 穿透放行 → 画布
```

- 点任何引擎卡（计时/点名/PPT 条）都算"要接管"：**先退出回放**，这一下照常归卡。
- 穿透模式下：UI 面板有自己的接输入小窗；**每张功能卡也各配一块**（同 PPT 条那套，
  1/255 透明小窗 ＋ 自己的 WndProc）。放大态的小窗铺到整屏（点任意处还原）。
- 卡片与卡片、卡片与界面之间不许"吞点击"：小窗矩形只按卡自己的矩形算。

### 3.4 尺寸 token（逻辑像素）

| 东西 | 值 | 说明 |
|---|---|---|
| 触摸目标 | ≥44×44 | 卡上按钮、tab、格子 |
| 启动器 tile | 76×76 | 图标 26、标签 11.5 |
| 主条按钮 | 40（现有） | 不动 |
| 卡运行态高 | 56（倒计时/正计时）；秒表同高、宽一点 | |
| 卡设置态 | 高 170~210（按行） | 行高 44、行距 8 |
| 放大态 | 字号按屏宽算（92 逻辑起，上限 = 屏宽/6） | 点名结果按人数自适应 |

## 四、计时卡细则

- **设置态**：模式 [倒计时][正计时][秒表]（三格）、预设 [1][3][5][10][15] 分、`− 分钟 +` 步进、
  到点提示音开关、主按钮 [开始计时]（运行中打开设置时显示 [重新开始]）、⚙(收起)、✕。
- **运行态**：[模式小字] 大字时间、**−1分 / +1分**（仅倒计时且未到点）、[⏸/▶]、⚙、✕。
- **到点**：响一声（提示音开关，默认开）＋闪三下（1.5s）＋**继续正计时显示超时** `+00:27`；
  点数字 = 从头重开；再点 ▶ = 从头重开。
- 秒表跑着连续出帧（0.01 秒）；倒计时/正计时 1 秒一变（借 250ms 的 WM_TIMER 置脏）；
  暂停/停止不要帧。
- 时间只用单调钟；暂停 = 已过时间累进，继续 = 重新找锚点。

## 五、点名卡细则

- **设置态**：范围 `− 起始 + ～ − 结束 +`（1–200；有名单时显示"名单 N 人"并禁用范围）、
  一次抽 `− 1..5 +` 人、抽过不重复开关、[重读名单]、[开始点名]、⚙(收起)、✕。
- **运行态**：滚动 1.2 秒（80ms 一跳）后定格；结果大字（≤5 人、"、"分隔、字号自适应）；
  [再抽一次][重置][⚙][✕]；"本轮已抽 N 人 / 剩 M 人"小字。
- **池子**：不重复时抽一个少一个；池空自动开新一轮并在小字提示；重开范围/开关/重读名单都重置本轮。
- **名单**：`%APPDATA%\InkTeach\Names.txt`（一行一个，`#` 注释）；没有名单就用学号。
- 随机数可注入种子（自检用）；滚动动画期间要帧，定格后停帧。

## 六、自检要求

- `--timertest`：状态机（设置态/运行态/⚙ 往返）、±1 分钟、到点只响一次、**超时正计时**、
  重开、停止、帧口径、格式、接输入小窗=卡片、UiState 一致。
- `--rolltest`：范围夹取、去重与池子（固定种子）、一次多人不重复、滚动 1.2 秒自定格、
  重置、Names.txt 读取、偏好往返、接输入小窗。
- `--paneltest`：启动器格子逐格点一遍（含置灰仍会写状态）、底栏四格、设置子页进出、
  状态行、档位/钉住、"自定义档才显示宫格"、面板宽 = min(640, 55%)、列数自适应、
  分辨率 A（首启小屏自动极简）。
- 每加一个启动器条目 = 自检自动要求"点得通、状态对"；加一张卡 = 补齐上面那套卡的用例。
