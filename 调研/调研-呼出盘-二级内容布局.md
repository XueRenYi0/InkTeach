# 调研：呼出盘（轮盘）二级内容布局

> **2026-10-25 后续**：用户更倾向“双层同心圆”（内圈工具、外圈选项、不用长按），
> 见 `调研-呼出盘-双层同心圆.md`。本文的“长按二级盘”作为备选方案保留。

- 日期：2026-10-25
- 状态：**只做内容/布局设计，不改代码**
- 用户方向：**长按某个扇区，把同一个轮盘变成该功能的二级选项**；这样 3 个固定颜色格可以去掉，同一个盘能装很多功能。
- 关联：`调研-呼出盘-优化建议.md`（边缘/进度/开关等体验问题先不做）、`调研-呼出盘-扇面与比例.md`

---

## 0. 结论

1. **方向成立，而且比“双环”更好**：不增加盘的面积，不换位置，只把 8 个格子从“功能清单”变成“功能入口”。
2. **一级盘只放 8 个核心入口**：笔、橡皮、荧光笔、框选、撤销、重做、激光、更多。
   - 3 个固定颜色格去掉；
   - 颜色、粗细、擦法、选择方式、清空/截图/翻页都进二级盘；
   - 一级盘保留原来的 5 个工具位置，只把黑/红/蓝三个位置换成撤销/更多/重做，肌肉记忆尽量少动。
3. **长按 300ms 进入二级盘；短按仍执行一级动作**。
   - 按住不放 → 当前扇区变成“返回”，其余 7 格变成该功能的选项；
   - 松手在选项上 = 执行；松手在“返回” = 回一级；移出盘外/Esc = 全取消；
   - 短按（<300ms）= 原来的动作，不改变现有习惯。
4. **笔的二级盘 = 7 个常用色 + 返回，中央 5 档粗细**。
   - 一级盘点笔：不在笔上就切笔；已经是笔就循环下一个颜色（保留现在的快速换色）。
   - 长按笔：进二级盘选具体颜色/粗细。
5. **橡皮的二级盘 = 整笔擦 / 面积擦 / 5 档大小 / 返回**；清空不放这里，放“更多”里按住 0.8 秒。
6. **“更多”是二级动作盘**：清空当前页、截图、白板、穿透、上一页、下一页、全选。
7. 代价要说清楚：**换色从“一次划动”变成“长按笔→划到颜色→松手”，大约多 300ms**。用“一级盘点笔循环颜色”来补快速换色；如果老师仍嫌慢，可以保留 1 个常用色格。

## 1. 一级盘：8 个核心入口

保留原来的 5 个工具位置（笔北、橡皮南、荧光西、框选西南、激光西北），把黑/红/蓝三个颜色位换成撤销/更多/重做：

```
                笔
          激光        撤销
      荧光笔            更多
          框选        重做
                橡皮
```

| 位置 | 入口 | 短按 | 长按 300ms |
|---|---|---|---|
| 北 | 笔 | 切笔；已经是笔 → 下一色 | 颜色 + 粗细二级盘 |
| 东北 | 撤销 | 撤销一步 | 无 |
| 东 | 更多 | 打开动作二级盘 | 无（点一下就开） |
| 东南 | 重做 | 重做一步 | 无 |
| 南 | 橡皮 | 切橡皮；已经是橡皮 → 整笔/面积切换 | 擦法 + 大小二级盘 |
| 西南 | 框选 | 切框选；已经是框选 → 矩形/套索切换 | 选择方式二级盘 |
| 西 | 荧光笔 | 切荧光；已经是荧光 → 下一色 | 颜色 + 粗细二级盘 |
| 西北 | 激光 | 切激光 | 颜色/粗细二级盘（可选） |

**为什么“更多”放正东**：

- 正东是原来“红”的位置，最顺手；
- 撤销/重做放两个角，避免老师习惯性划到正东找红色时误触撤销；
- 清空不在主盘，减少误触。

> 如果老师更想要“撤销”在正东，也可以把“更多”挪到东北；这是一行数据的事，先按安全优先排。

## 2. 二级盘通用规则

### 2.1 进入/退出

```
一级盘：划到“笔”→ 按住 300ms
        ↓
二级盘：北=返回，其余=颜色；中央=粗细
        ↓
划到红色 → 松手 = 红笔
划到“返回” → 松手 = 回一级盘
移出盘外 / Esc = 全部取消
```

- **短按 <300ms**：执行一级动作，不进二级；
- **按住 300ms**：扇区外沿画一圈进度；满了之后二级盘原地淡入；
- **按住期间移动 >8px**：取消长按进度，按普通划选处理（避免“想划走却被判定长按”）；
- **二级盘里再长按**：不继续下钻（最多两级），避免“三级菜单迷宫”。
- **粘滞模式**：二级盘如果没划动就松手，保留 8s，可抬手点选；点空白/Esc 取消。

### 2.2 返回键 = 刚才按住的扇区

二级盘里，**你长按的那个扇区原位置变成“返回”**。手指不用去找返回键，松开就是回一级；想选选项就往外划。

### 2.3 标签

- **一级盘不常显文字**，保持现在的图标 + 中央读数 + 盘下提示；
- **二级盘显示文字标签**（颜色格除外）：45° 扇格在 R68 处弧长约 53px，4 个汉字（11.5px）放得下；
- 中央读数：一级显示当前工具/颜色；二级显示“笔 · 颜色”“橡皮”“更多”；
- 盘下提示：一级悬停时写“按住看颜色/粗细”，让人知道有二级。

### 2.4 粗细

- 二级盘中央画 **5 个小圆点**（1~5 档），当前档高亮；
- 粘滞模式下直接点圆点；
- 按住划选时，把手指移进中央区域可左右拖动调粗细；在中央松手 = 保留二级盘（不取消），再点颜色；
- 中央显示“粗细 3/5”，避免只靠点的大小猜。

> 不建议把粗细做成第三个环：45° × 5 档太密，手指选不准。

## 3. 各二级盘的内容

### 3.1 笔（北）

```
        返回
   白         黑
 橙             红
   黄         蓝
        绿
```

| 位置 | 内容 |
|---|---|
| 北 | 返回 |
| 东北 | 黑 |
| 东 | 红 |
| 东南 | 蓝 |
| 南 | 绿 |
| 西南 | 黄 |
| 西 | 橙 |
| 西北 | 白 |

- 7 个常用色；紫色/自定义回主条色带（或以后加“更多颜色”）。
- 中央：5 档粗细。
- 选颜色 = 切到笔 + 设颜色；选“返回”不切工具。
- 一级盘点笔时，如果已经是笔，仍然循环下一色（快速换色）。

### 3.2 橡皮（南）

```
        细
   中         特细
 粗             整笔
   特粗       面积
        返回
```

| 位置 | 内容 |
|---|---|
| 南 | 返回 |
| 西南 | 整笔擦 |
| 西 | 面积擦 |
| 西北 | 特细 |
| 北 | 细 |
| 东北 | 中 |
| 东 | 粗 |
| 东南 | 特粗 |

- 5 档大小直接对应 `EraserWidthGrades` / `PixelEraserWidthGrades`；
- 选大小 = 设当前橡皮大小 + 切到橡皮（默认面积擦，若当前是整笔则保持整笔）；
- **清空不在这里**，避免在二级盘里误触；清空放“更多”，且要按住 0.8 秒。

### 3.3 荧光笔（西）

```
        返回
   黄         绿
 橙             青
   粉          （空）
         （空）
```

- 5 个荧光色 + 返回；中央 3 档粗细（荧光笔的档位比笔少）。
- 一级盘点荧光笔时，已经是荧光笔就循环下一色。

### 3.4 框选（西南）

```
        返回
   矩形        套索
 全选            取消选择
   （空）       （空）
        （空）
```

- 只放 4 个选项 + 返回，其余留空/灰；
- 删除/复制等选中操作以后再加，避免二级盘变成大杂烩。

### 3.5 激光（西北，可选）

```
        返回
   红          绿
 蓝              黄
   白          （空）
         （空）
```

- 5 个激光色 + 返回；中央 3 档粗细。
- 如果嫌二级盘太多，激光可以先不做长按，保持“点一下切激光”。

### 3.6 更多（东）

```
        截图
   清空        白板
 全选            穿透
   下一页      上一页
        返回
```

| 位置 | 内容 | 说明 |
|---|---|---|
| 东 | 返回 | 回一级 |
| 东北 | 清空当前页 | **红色；按住 0.8 秒**才执行，带进度 |
| 北 | 截图 | 进截图模式 |
| 西北 | 白板 | 开/关白板 |
| 西 | 穿透 | 开/关穿透 |
| 西南 | 上一页 | PPT/文档/白板上一屏 |
| 南 | 下一页 | 下一屏 |
| 东南 | 全选 | 全选当前墨迹 |

- 不适用的动作显示灰/不响应（例如没有 PPT 时翻页 no-op）；
- 清空的 0.8 秒是“二级里的再确认”，和橡皮带里的清空同一套语义：只清当前页。

## 4. 速度账：换色会不会变慢？

| 动作 | 现在 | 新方案（快速路径） | 新方案（二级盘） |
|---|---|---|---|
| 切笔/切橡皮 | 一次划动 | 一次划动 | 同左 |
| 黑→红 | 一次划到红 | 一级盘点笔：已经在笔 → 下一色（红） | 长按笔→划红→松手 |
| 红→绿 | 一次划到绿（但绿不在盘里） | 点笔循环 2 次 | 长按笔→划绿→松手 |
| 调粗细 | 主条滑条/`Ctrl+6` | 不变 | 二级盘中央 5 点 |
| 清空 | 橡皮带按住 0.8s | 不变 | 更多→清空按住 0.8s |

- 快速换色靠“一级盘点笔循环”，**常用黑/红/蓝仍然最多 1~2 次点击**；
- 精确换色/换粗细才进二级，约多 300ms；
- 如果老师强烈反对，可以保留 **1 个“常用色”格**（例如红），其余进二级；但先按“去掉 3 个”做。

## 5. 视觉与反馈

- 一级盘：图标 + 中央读数 + 盘下提示；不加大段文字。
- 二级盘：图标换成文字标签（颜色格用色片/彩笔），中央读数显示当前选项。
- 长按进度：扇区外沿一圈 300ms 进度；满后二级盘 120ms 淡入/交叉渐变。
- 返回：按住的那个扇区变成“返回”，图标 `↩` 或“返回”二字。
- 清空：红色扇格 + 0.8s 进度；未满松手不执行，二级盘保留。
- 中央粗细：5 个小圆点，当前档放大/实心；拖动时实时显示“3/5”。
- 粘滞：中央/盘下写“点选”；8s 后淡出。

## 6. 代码落点（只列，不改）

| 内容 | 现在 | 需要变成 |
|---|---|---|
| 扇区名/排序 | `RadialSectorNames` 静态 8 个 | 一级页 + 二级页数据 |
| 颜色判断 | `RadialSectorIsColor` 静态 bool[8] | 槽位 Kind |
| 提交 | `CommitRadialPalette` 的 `switch(sec)` | 按当前页/槽位执行 |
| 提示 | `RadialHintFor` 的 `switch` | 按槽位生成 |
| 图标 | `RadialIconFor` 的 `switch` | 槽位 Icon/色片/文字 |
| 绘制 | `DrawRadialPalette` 固定 8 格 | 按当前页画 8 格；文字/色片/图标三种 |
| 长按 | 无 | 扇区按住 300ms → 进二级 |
| 返回 | 无 | 当前扇区 = 返回 |
| 中央粗细 | 只有读数 | 二级盘 5 点 + 拖动/点选 |

建议的数据模型：

```csharp
enum RadialSlotKind { Tool, Color, Action, Back, Empty }

sealed record RadialSlot(
    RadialSlotKind Kind,
    KeyAction Action,     // Tool/Action
    int ColorIndex,       // Color
    string Label,         // 二级标签
    string Icon);         // 一级图标

sealed class RadialPage
{
    public string Title;          // “工具” / “笔 · 颜色” / “更多”
    public RadialSlot[] Slots;    // 8
    public bool HasWidth;         // 中央 5 点
}
```

- `_radialPage`：0 = 一级，1 = 当前二级；
- `_radialLongPressFromMs` / `_radialLongPressSlot`：300ms 判定；
- `_radialStickyUntilMs`：粘滞 8s；
- 二级盘返回：`_radialPage = 0`，不清空工具状态；
- 颜色格画色片/彩笔；文字格画 11.5px 标签；图标格沿用 `IconPaths`。

## 8. 风险与需要拍板

### 风险

1. **换色变慢**：从一次划动变成两级；靠“点笔循环”补快速路径。
2. **长按误进二级**：300ms 太短会误触，太长会等；需要真机调，建议 300~350ms。
3. **二级标签挤**：45° 扇格最多 4 个汉字；“清空当前页”要缩成“清空”，提示里写全。
4. **清空误触**：必须 0.8s 按住；放在“更多”的角落，不放主盘。
5. **肌肉记忆**：一级盘 3 个位置变了；可以出“经典布局/新布局”开关过渡，但先按新布局做。

### 拍板

1. 一级盘 8 格按“笔 / 撤销 / 更多 / 重做 / 橡皮 / 框选 / 荧光 / 激光”排，可以吗？
2. 3 个颜色格全部去掉，还是保留 1 个常用色（比如红）？
3. 长按阈值 **300ms** 可以吗？（还是 350/400ms）
4. 笔的二级盘用 **7 色 + 返回**，还是 **6 色 + 更多颜色 + 返回**？
5. 粗细放中央 5 点，按住时可拖、粘滞时可点，可以吗？
6. 橡皮的清空放“更多”，不放橡皮二级盘，可以吗？
7. “更多”里的 7 个动作，先要哪些？（清空/截图/白板/穿透/上一页/下一页/全选）
