# 调研：呼出盘（轮盘）双层同心圆布局

- 日期：2026-10-25
- 状态：**只做内容/布局设计，不改代码**
- **2026-10-25 内圈重排 v2**：用户定了“红笔居中、左右上一色/下一色、四角常用”，
  见 `调研-呼出盘-内圈重排-v2.md`；本文第 2/3 节的内圈顺序以 v2 为准，双圈几何/交互仍按本文。
- 用户方向：不要“长按出二级”，改成**中间一层 + 外面第二层**；选中笔，外面就出颜色/粗细；选中橡皮，外面出几种橡皮；激光可以先不做。
- 关联/前案：`调研-呼出盘-二级内容布局.md`（长按二级盘，作为备选保留）

---

## 0. 结论

1. **双层同心圆更适合“内容多、要直观”的诉求**：
   - 内圈 = 8 个核心工具/动作；
   - 外圈 = 当前工具的具体选项（颜色/粗细/擦法/选择方式/动作）；
   - **不需要长按**：划到内圈工具，外圈就出现；继续往外划选具体项，松手执行。
2. **“点击”也能用**：两指点一下打开粘滞盘 → 点内圈工具 → 外圈保留 → 点颜色/粗细 → 点空白关闭。
   一套盘同时支持“按住划”和“点两下”。
3. **3 个固定颜色格可以去掉**：笔的外圈正好放 8 个颜色，比现在多；颜色不再占一级盘。
4. **一级盘变成 8 个入口**：笔、撤销、更多、重做、橡皮、框选、荧光笔、激光。
5. **代价**：盘变大（约 232px 直径，现在 192），遮挡更多，边缘更容易出屏；**边缘夹取必须一起做**，否则两层盘会经常被裁掉。
6. **粗细**：笔/荧光笔的外圈放颜色，中央放 5 个粗细点；粘滞/点击模式下直接点，按住划选时中央仍是取消（避免误改）。橡皮的外圈直接放“整笔/面积 + 5 档大小”，不需要中央粗细。

## 1. 形状：内圈 + 外圈 + 中心

```
                 ┌───────────────┐
                 │   外圈：选项   │
                 │  ┌─────────┐  │
                 │  │ 内圈：工具│  │
                 │  │  ┌───┐  │  │
                 │  │  │中心│  │  │
                 │  │  └───┘  │  │
                 │  └─────────┘  │
                 └───────────────┘
```

| 区域 | 半径（逻辑像素） | 内容 |
|---|---|---|
| 中心 | 0~34 | 当前工具/颜色/粗细；粘滞时的 5 个粗细点 |
| 内圈 | 40~68 | 8 个核心工具/动作，图标 22~24 |
| 间隙 | 68~78 | 分隔带，不选东西 |
| 外圈 | 78~116 | 当前工具的选项：颜色/文字/动作 |
| 整体 | R116（直径 232） | 比现在 R96 大 21% |

- 内圈图标环 R54；45° 弧长约 42px，24px 图标放得下；
- 外圈文字/色片环 R97；45° 弧长约 76px，4 个汉字（11.5px）放得下；
- 外圈只有需要时出现；不需要时收回到内圈，整体看起来仍是小盘。
- 可按屏幕高度整体缩到 0.85~1.0；不建议再小，否则外圈文字挤。

## 2. 内圈：8 个核心入口

保留原来的 5 个工具方向（笔北、橡皮南、荧光西、框选西南、激光西北），把黑/红/蓝三个颜色位换成撤销/更多/重做：

```
                笔
          激光        撤销
      荧光笔            更多
          框选        重做
                橡皮
```

| 位置 | 入口 | 短按/松手在内圈 | 外圈 |
|---|---|---|---|
| 北 | 笔 | 切笔；已经是笔 → 下一色 | 8 个颜色 + 中央粗细 |
| 东北 | 撤销 | 撤销一步 | 无（外圈收起） |
| 东 | 更多 | 打开动作外圈 | 清空/截图/白板/穿透/翻页/全选 |
| 东南 | 重做 | 重做一步 | 无 |
| 南 | 橡皮 | 切橡皮；已经是橡皮 → 整笔/面积切换 | 整笔/面积 + 5 档大小 |
| 西南 | 框选 | 切框选；已经是框选 → 矩形/套索切换 | 矩形/套索/全选/取消 |
| 西 | 荧光笔 | 切荧光；已经是荧光 → 下一色 | 5 个荧光色 + 中央粗细 |
| 西北 | 激光 | 切激光 | 可先不做（外圈收起） |

**为什么“更多”在正东**：

- 正东是原来红色位，最顺手；
- 撤销/重做放两个角，避免老师习惯性划到正东找红色时误触撤销；
- 清空不在内圈，减少误触。

## 3. 外圈：按工具出内容

### 3.1 笔（北）

```
        红
   白         黑
 紫             蓝
   橙         绿
        黄
```

| 位置 | 内容 |
|---|---|
| 北 | 红（默认色） |
| 东北 | 黑 |
| 东 | 蓝 |
| 东南 | 绿 |
| 南 | 黄 |
| 西南 | 橙 |
| 西 | 紫 |
| 西北 | 白 |

- 8 个颜色正好一圈，不用“更多颜色”；
- 中央 5 个点 = 粗细（粘滞/点击时可点）；
- 选颜色 = 切到笔 + 设颜色；
- 内圈松手 = 只切笔，不选颜色；外圈松手 = 切笔 + 选颜色。

### 3.2 橡皮（南）

```
        中
   粗         细
特粗              特细
   空         整笔
        面积
```

| 位置 | 内容 |
|---|---|
| 南 | 面积擦（默认；从内圈往外划就是它） |
| 东南 | 整笔擦 |
| 东 | 特细 |
| 东北 | 细 |
| 北 | 中 |
| 西北 | 粗 |
| 西 | 特粗 |
| 西南 | 空 |

- 5 档大小直接对应 `EraserWidthGrades` / `PixelEraserWidthGrades`；
- 选大小 = 设大小 + 切到橡皮（保持当前整笔/面积；没有则面积擦）；
- 清空不在这里，放“更多”，按住 0.8s。

### 3.3 荧光笔（西）

```
        青
   绿         粉
黄                 橙
   空         空
        空
```

| 位置 | 内容 |
|---|---|
| 西 | 荧光黄（默认；从内圈往外划就是它） |
| 西北 | 荧光绿 |
| 北 | 荧光青 |
| 东北 | 荧光粉 |
| 东 | 荧光橙 |
| 其余 | 空 |

- 中央 3 档粗细（荧光笔档位比笔少）；
- 选色 = 切荧光 + 设色。

### 3.4 框选（西南）

```
        取消选择
   全选         空
套索              空
   矩形         空
        空
```

| 位置 | 内容 |
|---|---|
| 西南 | 矩形（默认；从内圈往外划就是它） |
| 西 | 套索 |
| 西北 | 全选 |
| 北 | 取消选择 |
| 其余 | 空 |

- 删除/复制等选中操作以后再加，避免外圈变杂。

### 3.5 更多（东）

```
        白板
   穿透         清空
上一页             截图
   下一页         空
        全选
```

| 位置 | 内容 | 说明 |
|---|---|---|
| 东 | 截图（默认；从内圈往外划就是它） | 进截图模式 |
| 东北 | 清空当前页 | 红色；按住 0.8s；未满松手不执行 |
| 北 | 白板 | 开/关白板 |
| 西北 | 穿透 | 开/关穿透 |
| 西 | 上一页 | PPT/文档/白板上一屏 |
| 西南 | 下一页 | 下一屏 |
| 南 | 全选 | 全选当前墨迹 |
| 东南 | 空 | |

- 不适用的动作灰/不响应；
- 动作执行后盘关闭（或按设置保留）。

### 3.6 激光（西北）

- 第一版可以不做外圈：内圈点一下切激光，外圈收起；
- 以后要加，就放 5 个颜色 + 中央粗细。

## 4. 交互：按住划 + 点两下，两种都支持

### 4.1 按住划（marking menu，快）

```
按住呼出键 / 两指长按
        ↓
内圈出现
        ↓
划到“笔” → 外圈立即出现（约 100ms 展开）
        ↓
继续往外划到“红” → 松手 = 红笔
```

- **松手在内圈** = 只执行内圈动作（切笔/撤销/切橡皮）；
- **松手在外圈** = 执行内圈工具 + 外圈选项；
- **松手在间隙** = 保留上一次的选择（不跳）；
- **移出最外圈 / Esc** = 取消；
- **外圈没选项**（撤销/重做/激光）→ 外圈收起，内圈松手直接执行。

### 4.2 点两下（粘滞，稳）

```
两指点一下 → 内圈粘滞
        ↓
点“笔” → 切笔，外圈保留
        ↓
点“红” → 红笔；外圈保留
        ↓
点中央 5 点 → 调粗细
        ↓
点空白 / Esc → 关闭
```

- 粘滞 8s；超时淡出；
- 外圈保留时，再点内圈别的工具，外圈立即换成那个工具的选项；
- 中央 5 点只在笔/荧光笔的外圈出现；点一下直接设档，拖动可连续调。

> 两种方式共用同一套盘：按住划是“快手”，点两下是“看清楚再点”。老师可以各取所需。

## 5. 判位：用半径分内外圈

| 指针半径 r | 选中 |
|---|---|
| 0~34 | 中心（粘滞时调粗细；按住划时=取消） |
| 34~40 | 间隙，不选 |
| 40~68 | 内圈工具 |
| 68~78 | 间隙，保持上一次 |
| 78~116 | 外圈选项 |
| >116 | 取消 |

- 内圈→外圈：r > 82 才切；外圈→内圈：r < 64 才切（滞回，避免边界抖）；
- 角度仍然 8 等分（45°），和外圈选项共用同一套 `SectorIndexFromDeg`；
- 外圈空位 = 不响应，松手不执行；
- 当前选中项用实心/强调色；内圈工具和外圈选项分别高亮。

## 6. 视觉

- 打开时只画内圈（R68），中心读数；外圈按需从 0.9 缩放到 1、120ms 淡入；
- 外圈出现时整体背景从 R68 扩到 R116（或只画外环，不铺满大圆）；
- 内圈图标 only；外圈文字/色片；层次清楚；
- 选中的内圈工具：实心强调色 + 白图标；外圈选项：颜色格淡强调 + 色片，文字格实心强调；
- 中央：当前工具/颜色；外圈悬停时显示选项名；
- 盘下提示：
  - 内圈工具：“松开=切笔；向外划=选颜色”；
  - 外圈选项：“松手=红笔”；
- 清空：红色扇格 + 0.8s 进度；
- 动画尊重系统“显示动画”开关。

## 7. 和“长按二级盘”的对比

| | 单环 + 长按二级 | **双层同心圆** |
|---|---|---|
| 换色速度 | 多 300ms 长按 | 划到工具后直接外划，几乎不额外等 |
| 发现性 | 隐藏，需要提示 | 外圈直接出现，直观 |
| 颜色数量 | 7（要留返回） | **8 个全放** |
| 占用面积 | 192 | **232** |
| 实现复杂度 | 中（计时/返回） | 中高（双环判位/展开） |
| 误触点 | 长按误进 | 内外圈边界误选 |
| 肌肉记忆 | 主盘少动 | 工具内移、颜色外移，改动更大 |
| 适合 | 极简、少遮挡 | 内容多、要直观 |

**结论**：按你的偏好，**双层同心圆更合适**；代价是盘更大、判位更复杂。把外圈做成“按需出现”，简单切工具时仍然只看到内圈，不会一直挡屏幕。

| **合计** | | **3.5~5 周** |

## 9. 风险与前置条件

1. **盘变大**：R116、直径 232；小屏/笔记本遮挡更明显。需要按屏幕高度缩到 0.85~1.0。
2. **边缘出屏更严重**：两层盘必须做**盘心夹取**；否则屏幕边缘呼出会被裁掉。这是布局的前置条件，不是可选项。
3. **内外圈误选**：靠半径滞回（64/82）和间隙带解决；真机要调。
4. **外圈文字挤**：45° 外圈约 76px，4 个汉字放得下；“清空当前页”缩成“清空”，提示里写全。
5. **清空误触**：放“更多”外圈，红色 + 0.8s 按住。
6. **肌肉记忆**：内圈工具从 R68 移到 R54，颜色从主盘移到外圈；老用户需要适应。可以先出“经典布局/双层布局”开关过渡。
7. **宽度只在粘滞时调**：按住划选时中央仍是取消，避免误改；要调粗细用两指点一下再点中央。
