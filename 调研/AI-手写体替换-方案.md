# 手写体替换 · 方案与决策（2026-11-05）

> 目标：识别板书后，**在原位置**把字换成“像手写、但每个学生都认识”的字体。
> 不覆盖原板书，结果可撤销。

---

## 1. 已定的决策

| 项 | 结论 | 依据 |
|---|---|---|
| 中文手写字体 | **志莽行书（Zhi Mang Xing）** | OFL 授权，可商用、可随软件分发；用户看效果认可 |
| 拉丁字母 | 手写拉丁字体（演示用 Ink Free，上线换 OFL 拉丁手写体） | 用户确认“英文也跟手写” |
| 公式 | 印刷体（KaTeX 渲染） | 用户确认“公式没有手写字体就转印刷，后期再说” |
| 位置 / 大小 / 颜色 | **沿用原行框**，不重排版 | 用户要求“原位置、差不多大小” |
| 图形 / 箭头 / 圈注 | **保留原笔迹**，不替换 | 替换会破坏版面 |

> **只能本地测试，不能进安装包**。

## 2. 混排规则

```
一行文字 = [中文段][公式段][中文段]…
  中文段 → 志莽行书，按原行高定字号
  公式段 → KaTeX 渲染成矢量，按正文 x-height 缩放、基线对齐
  英文段 → 手写拉丁字体（或随中文）
```

- 行框来源：**用自己的笔画数据算**（投影切行 + 列范围），不用 OCR 的 bbox。
- 宽度不够时**缩字号重排**，不横向拉伸（拉伸会让字距变宽、笔画变细）。
- 颜色取该行原墨迹的中位色（红/蓝分开处理）。

---

## 3. 交互

```
选中板书（或整页）
  → AI →「转手写体」
  → 预览：左原文 / 右替换，逐行可勾选
  → 应用：生成新的一页（原页保留）
  → 可撤销（一步）
```

默认只换“中文 + 英文”，公式保持原笔迹；用户可在预览里勾“公式也换”。

---

## 4. 明确不做

- **不做“美化原笔迹”作为主打**：实测平滑 + 笔宽统一后，肉眼几乎看不出差别
  （见 `调研/AI-板书识别-基准-2026-11-05.md` 与 `--inkbeautify` 的实现）。
  代码保留为隐藏项，不做宣传。
- **不做整页自动排版**：会破坏老师原有的版面结构。
- **不覆盖原笔迹**。

---

## 5. 二期（等用户提供字体后）

1. **更多手写字体**：清松手写体、沐瑶随心、演示悠然小楷（用户下载后接入）。
2. **个人字库**：从历史板书里切单字，挑写得好的实例复用，没写过的字用通用字体补。
   难点：连笔切字。
3. **公式手写化**：目前公式是 KaTeX 印刷体；二期可换手写数学字体或自绘笔画。
