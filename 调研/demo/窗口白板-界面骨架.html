界面 / 老年教师

  • 界面大小：0.8 / 0.9 / 1.0 / 1.15 / 1.3 / 1.5 特大
  • 与桌面批注共用同一套缩放档，不单独做窗口版
  • 大/特大默认显示文字标签；标准只显示图标
  • 主题：浅色 / 深色 / 高对比；减少动画

白板

  • 默认视图：适应宽度 / 适应整页
  • 最小缩放：适应整页 / 25%
  • 页尺寸 16:9；板色/底纹
  • 自动保存；图片插入最大尺寸
  • 贴边隐藏；置顶；启动最大化

输入

  • 手指默认：写字；两指平移/缩放
  • 手工具：手指/鼠标平移；笔永远写
  • 压感：开；掌拒：标准/强
  • 笔按键：橡皮 / 手 / 撤销（后续）
