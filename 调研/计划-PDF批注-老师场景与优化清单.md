日期：2026-10-08　　状态：**方案稿，等用户拍板（勾形态、排优先级）**，先不写码。

> **家底**：v8.10.0 已发——「打开文档…」→ 图片/PDF 铺页 → 页码条（仿 PPT）→ 批注 → 自动保存/读回 → 纸底；PDF 连续滚、页位图"视口窗口"驻留/回收。
> 原调研（形态/导出/内存/展台）与实现细节见 `调研-文件导入与PDF批注.md`、`计划-文档模式-状态模型.md`。

## 〇、一句话

文档模式现在"能看能写"✓ 但按老师日常，**最缺的是四件一看就知道的事**：
**放大（看小字/细节）· 裁白边（扫描件字大一圈）· 形态补全（横版页上下撑满）· 带批注导出 PDF（发学生/存档）**。
其余（缩略图/拖拽导入/密码/目录）是边角，排后。

## 一、老师 PDF 的"大部分形态"（我们该关心的维度）

### 1.1 类型清单

| 类型 | 长什么样 | 对我们的挑战 |
|---|---|---|
| **课件**（PPT 导出 PDF） | 横版满幅、字大、几乎每页一屏 | 现在 fit-width 会把横版页缩得**两侧大留白**（应该 fitting-height 一页一屏） |
| **试卷** | A4 纵、双栏、小字多、常带"原卷+答案解析" | 小字/图表细节要**放大**；答案页来回对 |
| **教材 / 课本扫描** | 含 **A3 对开摊开扫描**（一页=书的两面）、装订阴影、大白边、轻微歪斜 | **对开 = 每半页只有一半大小**，小字立刻不可读 → 放大/裁边是刚需 |
| **练习册 / 学案 / 答题卡** | A4、留白多、表格多 | 基本够用；答题卡可能要放大看小框 |
| **资料 / 复习书** | 几十~几百页、常有目录 | 跳页已有；**目录/缩略图**更省事 |
| **图片型（扫描） vs 文字型（原生矢量）** | 扫描=位图；矢量=可无限清晰 | 放大时：矢量页**重渲更清楚**；扫描页放大只到原分辨率（不糊过头就行） |
| 横竖混排 / 单页旋转 / 加密 / 超大文件 | 都会遇到 | 形态要**逐页算**；旋转页按 PDF 元数据；加密目前**明确报"暂不支持"**；663 页/122MB 实测 OK |

### 1.2 老师的动作清单（讲评 / 备课 / 收发）

| 动作 | 现状 | 缺口 |
|---|---|---|
| 翻页 / 跳页 | ✅ 页码条＋PageUp/Down＋小键盘跳页 | — |
| 连续滚着看 | ✅ | — |
| **放大看小字 / 细节** | ❌ 完全没有（当时有意不做） | **P0** |
| **扫描件"字大一点"** | ❌ 只有 fit-width，白边白白占地方 | **P0（裁边）** |
| 横版页一页一屏 | ❌ fit-width 缩两边 | **P0（形态）** |
| 圈画 / 荧光 / 擦改 / 回放 / 清空 | ✅ | — |
| **把批注发学生 / 存档** | ⚠️ 只能一页页导图片 | **P1（导出 PDF）** |
| 找页（资料书） | 页码跳页 | 缩略图/目录（P1/P2） |
| 打开文件 | 菜单→文件对话框 | 拖拽导入＋最近文档（P1） |
| 加密 PDF | ❌ 报错 | P2 |

## 二、优化清单（按"老师痛不痛 × 成本"分档）

### P0（建议先做；三条都别拖）

**1. 放大 / 缩小（zoom）＋拖动**
- 场景：试卷小字、答案页、图表细节、**对开扫描书的每一半**。
- 操作候选（**真机各试一次再定主操作**）：`Ctrl+滚轮` ／ 双指捏合（学校触摸屏）／ 工具条 ± 两颗。
- 行为：**以指针为锚**放大（像地图）；放大后按住空白拖＝平移。
- 技术要点（**这条决定成败**）：
  - PDF 用**矩阵渲染**按需重渲——矢量页放大=真清晰；
  - **只渲屏幕可见的那一块**（窗口化/瓦片）；**绝不做"整页高清"**——300dpi A4 一页 ≈ 2480×3508×4 ≈ **34.8MB**，4G 学校机必爆；
  - 现有 `Pdfium.MaxPagePixels = 24MP` 的封顶口径要改：从"按整页"改成"**按可见块**"算预算；
  - 扫描页放大到源分辨率为止（再放大只是放大像素，不糊但也无增益）。
- 与批注的关系：墨迹存**画布坐标**，页面缩放/平移天然带着走 ✓ 不用动存档格式。

**2. 裁白边（auto-crop）**
- 场景：扫描书/卷四边大白边——裁掉后同样屏宽下**字大约 15~25%**，成本低、收益立竿见影。
- 做法：渲一张**低分采样** → 扫四边非白边界 → 每页记 crop box（进存档）→ 渲染按 crop 撑满。
- 兜底：检测失败的页**退回不裁**（失败当没有）；给老师一个"裁边 开/关"。

**3. 显示形态补全（10-03 已定、没实现完）**
- **自动**：竖版页 fit-width、**横版页 fit-height**（PPT 导出的一页正好一屏，不用滚）；
- 另给"**整页适应**"一档（看排版/对答案）；
- 形态**逐页算**（横竖混排）；按"工作区高度"算（工具条别遮页脚——10-03 已记）。
- ⚠ 别挤牙膏：把档位一次定完、一次做完。

### P1（明显增益）

**4. 带批注导出 PDF（先光栅版）**
- 做法：逐页"页位图＋该页墨迹"离屏合层 → 一页一图写成**新 PDF**（流式，不全驻留内存）。
- 两条实现路：**优先用 PDFium 自己建文档**（`FPDF_CreateNewDocument`/`FPDFImageObj_*`/`FPDF_SaveAsCopy`——**零新依赖**）；不行再退 PDFsharp（MIT，10-03 调研里列过）。
- 取舍：观感 1:1、**文字不可搜**（发给学生够用）；"保留原矢量、批注叠上去"的矢量版放后续。
- 铁律：**绝不覆盖原文件**，默认另存新文件。

**5. 缩略图导航 / 最近文档 / 拖拽导入**
- 缩略图：按需渲小图＋LRU，点图跳页（资料书神器；先问老师真实使用频率再定 P1/P2）。
- 最近文档：菜单里列 3~5 条——现在每次都要重走文件对话框。
- 拖拽导入：把 PDF/图片从资源管理器拖进窗口即打开；⚠ 要在**分层＋穿透**窗口上单独验（10-03 已标记风险）。

### P2（边角，先不急）

6. **密码 PDF**：`FPDF_LoadDocument` 带 password ＋ 弹一次输入框（现在明确报"暂不支持"）。
7. **目录/书签跳转**：PDFium 的 bookmark API（资料书用）。
8. 页面旋转（歪页）：低优先；PDF 自带旋转元数据先"自动照做"即可（10-03 结论）。
9. 展台抓拍：另一条线，等型号/现象（`调研-文件导入与PDF批注.md` §十）。

## 三、技术要点与坑（这一轮特别盯）

1. **放大必须窗口化渲染**（见 P0-1）；对开扫描不急着做"双页并排"模式——**裁边＋放大**已经够用（10-03"双页并排对批注反而糟"的结论仍成立）。
2. **内存账**（4G 学校机）：页位图现在"视口窗口 ±屏"驻留＋立即回收 ✓；加了 zoom 后要保证"**放大态下也只是一两块**"。
3. 工具条遮页脚 → 一律按"工作区高度"算（10-03 已记，别忘）。
4. 导出走**我们自己的离屏渲染**（截图/出图那条链复用），黑白/彩色、清晰度（dpi）让老师可调不？
5. **验收基线**：学校 1080p@150%（逻辑仅 1280×720，小字压力最大）＋ 663 页大文件回归 ＋ 4G 内存。
6. 自检：`--doctest` 已 96 项——每做一条都往里加断言（形态/裁边/zoom 可见块/导出页数）。

## 五、专题 A：放大 / 缩小（＋拖动）—— 详细设计与风险

### 5.1 缩放模型（先定这两条，后面都从这来）
- **锚点＝指针**（像地图）：放大时"指针压住的那个字"不动、周围摊开；复位时回"形态档"的画面。
- **档位**：**连续**（Ctrl+滚轮每格 ×1.1 级进；捏合连续）＋ 两个标准复位点：
  - `Ctrl+0` = **回到形态档**（自动/适合宽度/高度/整页——见 §六），
  - `Ctrl+1` = **100%**（一逻辑像素=一页点，Adobe 习惯；后期可加）。
  - 范围：下限=形态档（比它更小没意义）、上限=**800%**（再大没内容）。
- **状态记忆**：**不跨文档记**（关文档即丢，重开回形态档）——比"记住某份文档上次放大多大"简单可预期；将来要记再说。

### 5.2 渲染管线（这条决定成败，不是"加个缩放系数"）
现在是"**整页 fit-width 渲一次 + 视口窗口驻留**"；放大后必须改成"**可见块渲染**"：
1. 屏幕可见区 → 换算出**页内矩形**（含预取边距，建议上下左右各预取 25% 屏）；
2. 只对这块矩形调 PDFium **矩阵渲染**（矢量页：真清晰）；
3. **块位图预算**：驻留总量封顶（建议先按 **64MB** 定，4G 机实测再调）——超了按"离屏幕远近"回收；
4. **低清占位**：块没渲好时，用**现有的整页 fit 位图放大垫底**（不是空白！）→ 块到位逐块替换，无白屏、无跳动；
5. 扫描页放大到**源分辨率**为止（再放大只是放大像素）；矢量页无此限。
6. 现有 `Pdfium.MaxPagePixels = 24MP` 的口径要改：整页封顶 → **按"可见块"算预算**（别再有"整页高清"这条路）。

### 5.3 交互（鼠标 / 手写板 / 触摸屏 三通道）
| 通道 | 缩放 | 平移 |
|---|---|---|
| 鼠标 | **Ctrl+滚轮**（主）✗`Ctrl+0` 复位 | **空格+左键拖**（Acrobat 惯例）；**中键拖**；`Shift+滚轮`=左右滚 |
| 触摸屏 | **双指捏合**（新增） | 双指同向滑=漫游（**已有**，保留） |
| 手写板（无滚轮/无键盘时） | **页码条上 ± 两颗按钮**（兜底；或条上一个"⤢"弹出小面板） | 同上空格/中键（若老师有键盘）；否则条上"抓手"？——**先靠 ± 缩放＋自动跟随，把抓手放后面** |
| 键盘（批注键盘模式） | `Ctrl+= / Ctrl+-`：**没选中对象时＝视图缩放**（有选中照旧=缩放对象——现状零回归） | `↑↓←→` 滚，`PgUp/PgDn` 翻页 |

> **推荐主操作＝三个都要、分主次**：鼠标**Ctrl+滚轮**、触摸**捏合**、笔+无键盘**条上 ±**。
> 理由：三种输入环境各缺一块（鼠标没触屏、触屏没 Ctrl、笔板没滚轮），只做一种必然有人够不着。
> 双指手势的**仲裁**（新增捏合 vs 已有漫游/翻页/对象变换）要真机调：两指**间距变化**为主→缩放；**中点同向平移**为主→漫游/翻页；有选中对象时照旧→对象变换（先到先得+方向锁，已有同款机制）。

### 5.4 风险与对策（逐条）
| 风险 | 对策 |
|---|---|
| **4G 内存爆**（整页 300dpi ≈ 34.8MB/页） | 可见块渲染＋64MB 预算＋离屏远近回收；学校机实测封板 |
| 放大糊 | 矢量重渲；扫描止步于源分辨率；低清占位只在"块未好"的瞬间出现 |
| 卡顿/白块 | 后台 worker（已有）＋可见块优先＋预取 25%＋低清垫底 |
| 书写受影响 | 页图与墨迹分层（已有）；渲染全在 worker，主线程不阻塞；缩放中不停笔 |
| 手势打架（触摸） | 见 5.3 仲裁规则；`--touchtest` 补"捏合缩放"用例 |
| 快捷键打架 | `Ctrl+=/-` 用"有无选中"上下文消歧；`Ctrl+0/1` 现无占用；空格不注册全局、仅在批注键盘模式生效 |
| 坐标系乱 | 墨迹存**画布坐标**不动；缩放=相机变换（现成）；存档格式零改动 |
| 与形态/裁边互作 | 参数链固定为 **裁边 crop → 形态 fit → 手动 zoom**（三层各管一段，别互算）；动形态＝zoom 复位 |
| 误触 | **不做双击缩放**（讲评里双击太常见） |

### 5.5 自检（`--doctest` 加）
- 缩放后**渲染请求只覆盖可见块**（不整页）；驻留预算 ≤ 上限；
- fit ↔ zoom 往返位置不漂；批注坐标不动；低清占位→块替换无空白帧（出图对比）。

## 六、专题 B：显示形态补全（"显示形态四档"）

### 6.1 档位定稿建议（就用 Adobe/Edge 的现成词，老师不陌生）
| 档 | 规则 | 什么时候用 |
|---|---|---|
| **自动**（默认） | **逐页**算：竖版页=适合宽度、横版页=适合高度 | 一份 PDF 横竖混排也不管 |
| **适合宽度** | 页宽=工作区宽 | 竖版文档/试卷（**当前行为**） |
| **适合高度** | 页高=工作区高（一页一屏） | 课件（PPT 导出）/横版页 |
| **整页适应** | 整页都进屏（长宽各缩到放得下） | 看排版/对答案 |

- 工作区高度 = 屏高 **− 工具条高**（10-03 已记：别让工具条遮页脚；固定按工作区算，别玩"隐藏后才全屏"那套——画面会跳）。
- **入口**：页码条**菜单加第 6 项**"显示形态：自动/适合宽度/适合高度/整页适应"（点击循环，菜单项右侧显示当前档）——同一套壳、PPT 类比成立。
- **记忆**：不分文档（关文档丢）＋ 默认自动（同 zoom 的策略，简单可预期）。

### 6.2 风险与对策
| 风险 | 对策 |
|---|---|
| 切换时画面跳/丢位置 | 切换保持"**视野中心对应的文档位置**"（缩放/平移同一套锚定）；翻页动画不受影响 |
| 横竖混排页缝不齐 | 逐页算（已定）；页缝值不变，仅页宽高变 |
| 长图切片在窄宽下重切 | 切片按"缩放后像素"重算（现有逻辑就是"切片的源矩形按缩放前算"——照同一条改口径） |
| 页缝/纸底露桌面 | 见 §七：板底在页图之下、必垫色 |
| 切换成本 | 页小=快；一屏最多两三页，可接受；切档不清缓存（同尺寸页缓存命中） |

## 七、专题 C：白板与文档的层序（"白板盖 PDF"）＋ 白底不漏桌面

### 7.1 现状（10-07 定过一版）
层序（上→下）：`界面 → 墨迹 → 文档页图 → 底纹/页界线 → 板底（白板） → 桌面/PPT`。
所以现在**白板盖得住桌面，盖不住文档页图**——白板开＋文档开＝只是"页缝/四周变成板色"。
你这次要的是"**白板要在上面（把 PDF 盖掉）**"——重提当年搁置的"白板盖 PDF"。

### 7.2 建议方案："让位"而不是"盖"
**白板开 → 文档（页图＋该文档墨迹＋页码条）整体暂时收起；白板关 → 原样回来。**
- 理由：和**穿透**是同一件事的两面（让位），实现可以**直接复用穿透那条链**（页图不画、位图释放或停绘、条收走、退出恢复）——成本低、行为一致；
- **白板上的字写到哪？**（关键语义，二选一，**请拍板**）：
  - **方案甲（推荐）：白板=另一张纸**——让位期间写入**白板自己的页空间**（就是现有白板页），与 PDF 墨迹**互不污染**；关白板整张收起，再开白板还在。语义干净，和"文档墨迹独立"同一条原则。
  - 方案乙：让位期间写入**文档空间**——关白板后字会**叠在 PDF 上**（"透明纸"效果：先遮着写、再揭示）。适合"写提示再揭开"的讲法，但容易和"不想留痕"的预期打架。
- **页码条**：让位时**收走**（和白板/穿透的表现一致，少误触）；白板关后回来。
- **是不是默认行为**：建议做成**选项**（默认开=新行为；关=老行为"白板只是垫色"），老师在设置里可切——因为"白板只是垫色"也有人用（把绿板垫在 PDF 四周好看）。

### 7.3 "原来的底层添加白色背景，不漏桌面"——细化
现状：**打开文档自动开纸底（板底，默认白）**⇒ 页缝/页边是纸色不是桌面；关文档恢复原板态 ✓（已有自检）。
补强细节（把"漏"的口子全堵上）：
1. **打开文档时板底若关着** → 自动开（默认白）；
2. 老师**手动改过板色**（比如绿）→ 尊重，不强制白（"要白"的默认路径本来就是白）；
3. **页位图被回收/未渲染**的瞬间，页矩形的垫色＝板色（不是黑/透明）——渲染顺序已保证（板底在页图之下），自检补一条"页图卸载瞬间页区=板色"；
4. **形态/缩放的留白**（整页适应时左右、适合高度时四周）＝板色；
5. **让位（白板盖文档）时**：桌面被白板页盖住＝不漏桌面 ✓（白板页本身是实底）；
6. **关文档**回原板态（原来关→透明见桌面、原来开→保持），与穿透互不联动（三开关独立原则不变——"白板盖文档"只是**显示开关**：白板状态驱动的页图层可见性，不改变"开关独立"）。

### 7.4 状态矩阵（白板 × 穿透 × 文档都开着时）
| 白板 | 穿透 | 文档页图 | 页码条 | 白板墨迹 | 说明 |
|---|---|---|---|---|---|
| 关 | 关 | 显示 | 显示 | — | 正常看 PDF |
| 开（盖文档=开） | 关 | **收起** | 收起 | 在白板页上写 | 讲白板 |
| 开（盖文档=关） | 关 | 显示 | 显示 | — | 老行为：板色垫底 |
| × | **开** | 收起 | 收起 | — | 让路给下层（现状） |
> 穿遇到优先级最高（它管输入与显示都让），白板盖文档次之——两把"收起"的条件取或即可。

## 八、快捷键对标（Adobe Acrobat / Edge / 福昕 / Chrome）＝我们怎么接

### 8.1 对标表
| 动作 | 通行惯例（阅读器们） | 我们的现状/占用 | **建议** |
|---|---|---|---|
| 放大/缩小（视图） | `Ctrl+=` / `Ctrl+-`；`Ctrl+滚轮`；触摸板捏合 | `Ctrl+=/-` 被"**选中对象缩放**"占用 | `Ctrl+=/-`：**没选中=视图缩放**、有选中=对象缩放（上下文消歧，零回归）；**Ctrl+滚轮=主操作**（现无占用） |
| 复位 | Adobe：`Ctrl+0`=适合页面、`Ctrl+1`=100%；浏览器：`Ctrl+0`=100% | 未占用 | `Ctrl+0`=回形态档（"适合"语义）✗`Ctrl+1`=100%（第二期） |
| 拖动/平移 | 空格+拖（抓手）；中键拖；`Shift+滚轮`=左右 | 空格未占用；中键未占用 | 照抄（**空格+左键拖**/中键拖/Shift+滚轮）；⚠ 空格只在本程序键盘模式内生效，不注册全局 |
| 滚动 | 滚轮＝细滚 | ✓ 已有 | 不变 |
| 翻页 | `PgUp/PgDn`✗`←→` | ✓ 已有 | 不变 |
| 首页/末页 | `Ctrl+Home` / `Ctrl+End` | 未占用 | 加上（便宜、老师会） |
| 手势 | 捏合缩放、双指滚动、双击缩放 | 双指=漫游/翻页；**双击不做** | 双指加"捏合=缩放"（仲裁见 §5.3）；双击**不做**（误触） |
| 旋转视图 | Adobe 有（`Shift+Ctrl+=/-`），老师基本不用 | — | 不做（10-03 已定） |

### 8.2 冲突检查（全部扫过一遍）
- `Ctrl+=` / `Ctrl+-`：**唯一硬冲突** → 用"有无选中"上下文解决（文档模式没选中时按它，本来就是个空操作）；
- `Ctrl+0` / `Ctrl+1` / `Ctrl+Home` / `Ctrl+End` / 空格+拖 / 中键 / Shift+滚轮 / Ctrl+滚轮：**全部空闲** ✓；
- 触摸捏合：与"双指漫游/翻页/对象变换"共用两根指头 → 仲裁规则（§5.3）＋ `--touchtest` 补用例；
- 新动作一律进**键位系统**（`KeyAction` + 默认键 + 帮助 + 设置界面自动带出），教室机冲突可视可改（已有那套机制直接吃）。

### 8.3 给"动手做"的顺序建议（一旦拍板）
1. **先做"适合高度/整页适应"两档形态**（最小、立刻治好 PPT 导出 PDF 的两侧大留白）；
2. **再做放大（含可见块渲染这台发动机）**——它是大头，做完裁边/对开/小字全部受益；
3. **裁边**（依赖 2 的"可见块"渲染口径，一起收）；
4. **快捷键/手势**（Ctrl+滚轮、空格拖、捏合、Ctrl+0）在 2 里顺带入。
