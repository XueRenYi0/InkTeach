# 调研：呼出盘内圈重排 v2（红笔居中 + 四角常用）

- 日期：2026-10-25
- 状态：**只做布局设计，不改代码**
- 用户方向：
  - 上方默认是**红笔**；
  - 红笔左边 = **上一色**，右边 = **下一色**；
  - 四个角放常用功能：**橡皮、荧光笔、清屏**，再加一个；
  - 其他功能由我排进来。
- 基础：`调研-呼出盘-双层同心圆.md`（双圈几何/交互不变；本文只改内圈内容和外圈对应关系）

---

## 0. 结论

推荐内圈这样排：

```
                红笔
        撤销              橡皮
    上一色                  下一色
        清屏              荧光笔
                更多
```

- **上**：当前笔/当前色（默认红）；
- **左/右**：上一色 / 下一色（循环 `PenBand`）；
- **四个角**：橡皮（右上）、荧光笔（右下）、清屏（左下）、撤销（左上）；
- **下**：更多（其他功能都进它的外圈）；
- 这样右半圈是“写”（笔、橡皮、荧光笔、下一色），左半圈是“改”（撤销、清屏、上一色），语义清楚。

## 1. 内圈 8 格

| 位置 | 内容 | 点一下 | 外圈 |
|---|---|---|---|
| 北 | **红笔 / 当前笔** | 切到笔；显示当前颜色 | 8 个颜色 + 中央粗细 |
| 东北 | **橡皮** | 切橡皮；已是橡皮 → 整笔/面积切换 | 整笔/面积 + 5 档大小 |
| 东 | **下一色** | 切到笔 + 下一个颜色 | 无（不展开） |
| 东南 | **荧光笔** | 切荧光；已是荧光 → 下一色 | 5 个荧光色 + 中央粗细 |
| 南 | **更多** | 打开动作外圈 | 重做/框选/激光/截图/白板/穿透/翻页 |
| 西南 | **清屏** | 按住 0.8s 才执行 | 无 |
| 西 | **上一色** | 切到笔 + 上一个颜色 | 无 |
| 西北 | **撤销** | 撤销一步 | 无 |

### 为什么是这四个角

- **橡皮**：纠错回路，紧挨着笔；
- **荧光笔**：划重点，和橡皮同属“写”；
- **清屏**：课堂高频，但破坏性大，放左下、按住 0.8s；
- **撤销**：最高频的“改”，放左上；
- **框选/激光/重做**：频率低一档，进“更多”，不占四角。

## 2. 颜色怎么走

### 2.1 上一色 / 下一色

以 `PenBand` 顺序为准：

```
黑 → 红 → 蓝 → 绿 → 黄 → 橙 → 紫 → 白 → 黑 …
```

- 当前是红：左（西）= 黑，右（东）= 蓝；
- 当前是蓝：左 = 红，右 = 绿；
- 点“上一色/下一色”= **切到笔 + 换色**，不管当前是什么工具；
- 北格显示当前颜色（红笔/蓝笔……），左/右格显示相邻色的小色点 + 箭头。

### 2.2 精确选色

- 北格（笔）外圈仍然是 **8 个颜色**，可以直接选任意色；
- 左/右是“快速翻色”，外圈是“直接点色”，两者不冲突；
- 笔的外圈顺序：北=红（默认），东北=黑，东=蓝，东南=绿，南=黄，西南=橙，西=紫，西北=白。

## 3. 各工具的外圈

### 3.1 笔（北）

```
        红
   白         黑
 紫             蓝
   橙         绿
        黄
```

- 8 色 + 中央 5 档粗细；
- 从内圈“笔”继续往外划 = 红；
- 选颜色 = 切笔 + 设色。

### 3.2 橡皮（东北）

外圈跟着内圈方向旋转：**从橡皮继续往外划 = 面积擦**。

```
        空
   特粗         面积
 粗              整笔
   中          特细
        细
```

| 位置 | 内容 |
|---|---|
| 东北 | 面积擦（默认） |
| 东 | 整笔擦 |
| 东南 | 特细 |
| 南 | 细 |
| 西南 | 中 |
| 西 | 粗 |
| 西北 | 特粗 |
| 北 | 空 |

- 5 档大小对应 `EraserWidthGrades` / `PixelEraserWidthGrades`；
- 清屏不在这里，在左下角按住 0.8s。

### 3.3 荧光笔（东南）

```
        空
   橙          空
 粉              空
   青          黄
        绿
```

| 位置 | 内容 |
|---|---|
| 东南 | 荧光黄（默认） |
| 南 | 荧光绿 |
| 西南 | 荧光青 |
| 西 | 荧光粉 |
| 西北 | 荧光橙 |
| 其余 | 空 |

- 中央 3 档粗细；
- 选色 = 切荧光 + 设色。

### 3.4 更多（南）

```
        截图
   下一页        白板
 上一页          穿透
   激光          重做
        框选
```

| 位置 | 内容 |
|---|---|
| 南 | 框选（默认，往外的第一项） |
| 西南 | 激光 |
| 西 | 上一页 |
| 西北 | 下一页 |
| 北 | 截图 |
| 东北 | 白板 |
| 东 | 穿透 |
| 东南 | 重做 |

- 框选/激光/重做都从四角让位到这里；
- “更多”没有主动作，点一下就会把外圈留在屏幕上（粘滞），方便再点；
- 不适用动作灰/不响应；
- 清屏不在“更多”里（已在左下角）。

> 如果觉得“框选”比“重做”更需要，二者可以互换；这是表里一行的事。

## 4. 双圈判位不变

- 中心 0~34：读数/粗细；
- 内圈 40~68：上表 8 格；
- 间隙 68~78；
- 外圈 78~116：当前工具选项；
- 外圈按需展开：选笔/橡皮/荧光/更多才出现；撤销/清屏/上一色/下一色不展开；
- 内外圈滞回 64/82，避免边界抖动；
- 盘心夹取 + 外圈展开动画仍按 `调研-呼出盘-双层同心圆.md`。

## 5. 两种用法

**按住划**：

```
按住 → 内圈
划到北（笔）→ 外圈出颜色
继续往外划到红 → 松手 = 红笔
```

只想要笔：在内圈北松手，外圈不选。

**点两下**：

```
两指点一下 → 内圈粘滞
点北（笔）→ 切笔，外圈保留
点红 → 红笔；点中央 5 点 → 调粗细
点空白 → 关闭
```
