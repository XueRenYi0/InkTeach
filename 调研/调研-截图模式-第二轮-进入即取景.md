## 一、把两边的"节奏"逐步摆出来

### 1.1 微信（要模仿的那个）

| 步 | 屏幕上 | 鼠标 |
|---|---|---|
| ① 按 `Alt+A` / 点截图按钮 | **整屏立刻灰下来**（全屏遮罩），顶部/角落没有任何工具条，只有一行小提示 | **十字**（从这一瞬到结束一直是它） |
| ② 移动 | 灰着的屏幕 + 十字跟着走（没有任何框） | 十字 |
| ③ 按下拖 | 从按下点拉出一个框，框内变亮（挖洞）、框外还是灰的，框旁边有尺寸 | 十字 |
| ④ 松开 | 框还在，四周出现 8 个手柄；**框里可以拖整体**，手柄可以拖边/拖角 | 十字 / 手柄上是缩放箭头 |
| ⑤ 完成 | 双击框内、或点工具条上的 ✓；**Esc / 右键 = 退出** | — |

三个关键点，正好对上你的三句话：
- **进入就是取景**（①的灰）——不用先"按下"；
- **光标全程一个样**（十字，不消失、不换形状）——所以"从哪儿开始"永远看得见；
- **框的起点就是按下点**，框一拉出来起点就在框角上，不需要靠记忆。

### 1.2 我们 8.3.0（现状，按代码逐步）

| 步 | 屏幕上 | 鼠标 | 问题 |
|---|---|---|---|
| ① 点「截屏」格 / `Ctrl+S` | **什么都不变**（只有工具格亮起） | 系统光标被藏掉，自绘一个 **24×24 的角括号 + 中心小十字**（琥珀色，`DrawCaptureFrameCursor`） | ← **这就是"没有灰下来"**；也**这就是那个"比较难用的光标"** |
| ② 移动 | 同上 | 角括号跟着走 | 观感上"没进模式" |
| ③ 按下 | 这一下才冻结整屏、才铺遮罩、才出现框 | 角括号**消失**（`DrawnCursor`：`CaptureActive → None`），取而代之的是自绘细十字 + 准线 | ← **"光标就消失了，我不知道从哪开始"** |
| ④ 拖 | 遮罩 + 框 + 读数 + 准线 | 细十字 | （这一段其实还行） |
| ⑤ 松开 | 进"调整"（8 手柄 + ✓/✕） | 系统箭头（`CaptureAdjusting → Default`） | 光标又换了一次形状 |
| ⑥ Esc / 单击不拖 | **整段取消**，退回① | 角括号回来 | 误点一下就把模式退出去了 |

也就是说：**我们做了微信后半段（框 + 调整 + 手柄），但前半段（进入即灰、光标一致）是空的**；
鼠标在一条流程里换了 **四种** 样子（角括号 → 无 → 细十字 → 箭头），所以"不顺手"。

## 二、建议的新逻辑：四个状态（照着微信的节奏）

> 原则：**进入截图 = 已经在取景**；光标**全程一个样**；**不做任何"先选工具空等"的中间态**。

```
S0 空闲（不在截图）
   │  Ctrl+S / 点「截屏」格
   ▼
S1 取景就绪 armed                ← 微信的①
   · 整屏铺遮罩（还没有框，全灰）
   · 底下衬着"冻结帧"（见第三节：这就是待会儿要拍到的画面本身）
   · 顶部一行字：模式名 + 怎么操作 + 怎么退出
   · 右上角一颗「✕ 取消」（触摸屏没有 Esc/右键，得有颗能点的）
   · 鼠标：十字
   · 拖动 = 起框；单击 / 双击空白 = 什么也不做（**不再退出模式**）
   · Esc / 右键 / 点「✕」 = 退出截图，回到进来之前的工具
   ▼ 按下并拖出 > 最小尺寸
S2 拖框中 framing
   · 框 + 挖洞 + 读数（右下角）+ 准线
   · 鼠标：十字（不变）
   ▼ 松开
S3 调整中 adjust                ← 微信的④
   · 8 个手柄 + 框内读数 + 框下 [✓ 完成][✕ 取消]
   · 鼠标：十字；压在手柄上时换成系统的缩放箭头（↔ ↕ ⤡）
   · Enter / 双击框内 / 「✓」 = 落图；Esc / 右键 /「✕」/ 点框外 = 退出
   ▼ 确认
S4 落图：裁剪冻结帧 → 剪贴板 → 原位落 → 自动选中 → 工具切到框选、截图模式收场
   （工具格回到"框选"，遮罩和模态整个消失）
```

和现状的差别就四条（**全是行为，不动架构**）：
1. **遮罩从"按下时"提前到"进入时"**（S1 就有）；
2. **光标统一**：全程一个十字（下面第三节说用哪种）；
3. **单击不再退出**（只会回到 S1 继续等）；
4. **Esc 退出时回到"进来之前的工具"**（现在是留在截图工具上继续空等）。

## 三、三件更细的事

### 3.1 "只拍下层 → 隐藏界面截图"：合理，而且应该连行为一起补齐

**合理。** 理由：
- 用户看到的行为就是"**我们的批注软件不见了，底下是什么就拍什么**"——
  "隐藏界面截图"这个名字说的是**用户看到的现象**，"只拍下层"说的是**我们的实现分层**。
  名字应该跟着现象走（InkClass 那边也是叫"隐藏界面截图"，你 9-17 的原始需求就是这个叫法）。
- 现在这个名字是我 8.3.0 改的（B4"改名"），改得不理想，这轮改回去。

**行为上怎么"真的看不到我们的软件"**（这是"逻辑完善"的关键）：
现在（8.3.0）取景时能看到**灰掉的笔迹和白板**（框外那圈是实时画面压暗的），
只是**框里**（挖洞）换成干净的冻结帧。你的直觉是对的：既然叫"隐藏界面"，
**取景的这一整块屏幕上就不该再看到我们的墨**。改法很轻：

> **整块屏幕都用"冻结帧"当底**（不再只是洞里）——
> 隐藏界面模式：冻结帧 = 藏起我们整个覆盖层之后抓的那一张 → 你看到的就是**干净的 PPT/桌面**；
> 连批注拍模式：冻结帧 = 带板书的那一张 → 你看到的还是板书。
> 两种模式下，**你看到的 = 待会儿拍到的**，一模一样（所见即所得），框外只是被压暗。

顺带的收益：8.3.0 那种"框外实时、框里冻结"的错位感（PPT 在动时最明显）也一起没了。

**命名给三个选项**（段宽有限，得能放下；面板上带那格现在是两段 + 右端「粘贴图片」动作按钮）：

| 方案 | 隐藏界面那一档 | 带批注那一档 | 备注 |
|---|---|---|---|
| 甲（推荐） | `隐藏界面` | `连批注拍` | 4+4 字，现在段宽就放得下；说明写在顶部提示里 |
| 乙 | `隐藏界面截图` | `连批注截图` | 6+5 字，更完整，但段要变宽/字要变小，得先量 |
| 丙 | `隐藏界面截图` | `直接截取`（旧名） | 只改你点名的那一半 |

### 3.2 光标：全程一个十字（两种做法选一）

| 做法 | 长什么样 | 好处 | 代价 |
|---|---|---|---|
| **A（推荐，最像微信）** | **系统十字光标**（`IDC_CROSS`），**不再自绘、不再藏** | 老师一眼就认得；和微信一模一样；零维护 | 白底上略细；深色底上对比一般（Windows 原生就这样） |
| B | 我们自绘的"细十字 + 白垫"（8.3.0 拖框时那个），**全程都画、不消失** | 任何底色都醒目、可控 | 又回到"自绘光标"那条路（和系统光标二选一，不能叠加） |

- 8.3.0 那个 **24×24 角括号**（你叫"比较难用的光标"）**两种方案里都删掉**——
  它是"待机装饰"，微信没有这种东西。
- 调整阶段（S3）：压到手柄上换成系统的缩放箭头（`IDC_SIZEWE / SIZENS / SIZENWSE / SIZENESW`）——
  这是 Windows 截图工具的做法，认起来最快。不做也能用（保持十字）。
- 8.3.0 那两条**全屏准线**：建议**保留**（细、淡，只在拖框/调整时出现；它回答"我现在对齐到哪儿"，
  微信没有但没坏处）。如果你觉得多余，也可以去掉——这条一起拍。

### 3.3 冻结"哪一刻"：建议冻结在**进入截图那一刻**

要"进入即灰"且"隐藏界面真的看不到我们"，就必须在**进入模式的那一瞬**抓一张图存着
（藏起我们的窗口 → 抓 → 把窗口恢复成"只画遮罩和框"的样子）。之后拖框/调整/确认
全在这张图上做，屏幕一次都不再闪。这就是 Snipaste 的"冻结屏幕"模型。

| | 冻结在**进入**那一刻（推荐） | 冻结在**按下**那一刻（8.3.0） |
|---|---|---|
| 进入即灰 | ✅ 能（冻结帧就是 S1 的底） | ❌ S1 没内容可垫 |
| 隐藏界面取景时"看不到我们" | ✅（冻结帧本身就是干净的） | ❌（框外还是实时+压暗） |
| 闪 | 只有进入那一瞬的"藏窗口"（约 60ms），随后全程不闪 | 按下时闪一次 |
| 拍到的画面 | **进入那一刻**（你点按钮时看到的） | 按下那一刻 |
| 代价 | 一张整屏图约 20MB 内存（退出即放） | 同 |

> 代价说清楚：画面停在**你点按钮的那一刻**。你慢慢框 3 秒，拍到的还是 3 秒前那一张
> （PPT 动画会停在那一刻）。微信/Snipaste 都是这个口径；如果以后要"拍确认那一刻"，
> 那是另一个方案（实时取景 + 确认时现抓，会在确认时闪一下）。

## 四、你问的两件事：双击确认 / 进标注层

### 4.1 "双击确认"

就是微信的⑤：框好之后**在框里双击一下 = 完成**（等于替你按了 Enter / 点了「✓ 完成」）。
纯属顺手的小便利（微信、QQ、Snipaste 都有），**便宜、建议做**；不做也不影响主流程。

### 4.2 "截图后进标注层"（我上一轮说的 C 档，没做的那件）

说的是 **Windows 截图工具 / Snipaste / 微信截图工具条**那种做法：
框完不是马上落图，而是先把这块图放进一个**临时的标注层**，给你一条小工具条
（箭头 / 矩形 / 画笔 / 荧光笔 / 文字 / 马赛克），**在这张图上标完**再保存/复制/确认。
好处是"标注和这张图**长在一起**，是一张图"。

**我们的现状其实已经有一条替代路**（所以你多半不需要它）：
1. 截图落进画布（就是普通对象）；
2. 在它上面**直接画**（箭头、圈、字都行，工具就是平时那些）；
3. 要"一张合成好的图"时：**框选"图 + 你的标注"→ `Ctrl+C` / 导出选中**——
   `Ctrl+C` 会把这批对象**渲染成一张 transparent PNG** 同时进剪贴板，粘到微信/Word 就是一张图。

也就是说："标完再变成一张图"这条路我们**已经有了**，只是入口在"复制/导出"而不是"选框后立刻弹工具条"。
**建议：不做临时标注层**（那是一套独立编辑器，C 档 3 天+），真要用就走上头那条三步。
以后如果老师们普遍觉得"还得再框一次太麻烦"，再考虑"落图后自动把新图 + 后续笔画合并"这种轻量版。
