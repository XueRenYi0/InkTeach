# AI 作图计划：单解析式 → 多解析式 → 含参 → 圆锥/平面/立体

日期：2026-11-09
状态：**v1–v1.6 全部跑通（函数、多曲线、含参、圆锥曲线、平面/立体几何），
已做性能优化与截图验收。** v2（可拖参数 D2D FigureScene）为下一阶段。

---

## 0. 目标与边界

用户要求：先做简单的——给一个幂函数/指数函数/对数函数，AI 识别后用一个“AI 作图”功能，
根据解析式画出图；后面再支持两个/三个解析式（不同颜色）、含参、椭圆/双曲线/立体。

统一约束：

- **图形是普通对象**：当前 v1.x 仍插成现有 `StrokeKind.Image`，可选中/移动/缩放/删除/撤销/存档；
- **不新增**独立图形缓存、湿墨层、脏矩形、第二个透明墨迹窗口；
- 图形走现有 `CanvasTileCache`，橡皮擦/选中/撤销/存档语义与普通图片一致；
- AI 解析、采样、栅格化全部在后台线程；**手写路径零新增工作**；
- 坐标系规则：函数/圆锥曲线显示坐标轴+刻度+网格；平面/立体默认不显示坐标轴；
- 旧文档不做兼容（无真实用户）。

## 1. 总体流程

```
AI 面板输入自然语言 / 解析式
  → LooksLikePlotPrompt 分流
  → AiPlotClient.ParseAsync（真实 DeepSeek，OpenAI 兼容）
  → PlotSpec（functions / conic / plane / solid）
  → PlotRenderer.Render（Skia 离屏 1100×760）
  → StrokeKind.Image 插入画布
  → 选中/移动/缩放/删除/撤销/存档
```

## 2. 分阶段实现

### v1 单解析式（✅）

- `PlotExpression.cs`：递归下降解析器，只接受数学表达式，不执行代码；
  - `+ - * / ^`、括号、`x`、`e/pi`；
  - `sin/cos/tan/asin/acos/atan/sqrt/abs/exp/ln/log/log10`；
  - 支持 `²/³/×/÷/−` 等 Unicode 写法归一化；
- `AiPlotClient.cs`：模型只返回表达式/定义域/标题，不让模型给像素；
- `PlotRenderer.cs`：白色圆角卡片、坐标轴、箭头、主刻度、网格、标题；
- 曲线断段：非有限值、大跳变断线（tan/log 不会连出竖线）；
- 定义域由 AI 给，本地验证表达式失败直接报错，不画空图。

### v1.1 多解析式（✅）

- `PlotSpec.Series` 支持多条；`AiPlotClient` 解析 `functions[]`；
- 颜色表：黑、蓝、红、绿；每条曲线独立颜色；
- 右上角图例（色线 + 解析式），标签直接由 `expr` 生成，不信任模型 label；
- y 范围按所有曲线统一采样，避免曲线互相压扁。

### v1.2 存档/交互回归（✅）

- Image 对象选中/移动/缩放正常；
- 存档→读回：图片数量、尺寸一致；
- 擦除→删除成功；Ctrl+Z/Undo 恢复成功；
- 所有几何/圆锥结果同样是 Image，因此复用同一套回归。

### v1.3 性能优化（✅）

- `SKTypeface` 静态复用，去掉每次渲染的字体加载；
- 采样上限 1400 点；多曲线共享一次 y 范围扫描；
- 图例/参数行/标题在同一张 Skia 画布完成，不新增中间位图；
- 图片内存 1100×760 BGRA ≈ 3.2MB/张。

### v1.4 含参函数（✅ 静态版）

- `PlotExpression.Parse(expr, params)`：参数名在解析期绑定为常量；
- `PlotSpec.Params`：AI 输出 `params: {a:1,b:-2,c:1}` 默认值；
- 渲染时标题下显示“参数：a = -1，b = 4，c = -1”；
- 例：`y=a*x^2+b*x+c`，实测 AI 返回 3 个参数，首帧 3.9ms；
- **可拖参数/实时更新属于 v2**，本轮只做静态快照。

### v1.5 圆锥曲线（✅）

- `PlotConic`：`ellipse / hyperbola / parabola`，中心/顶点 `h,k`、`a,b`、抛物线开口方向；
- 本地参数化采样：
  - 椭圆 `(h+a cos t, k+b sin t)`；
  - 双曲线两支 `(h ± a cosh t, k + b sinh t)`，两支之间用断点；
  - 抛物线 `right/left/up/down` 四种开口；
- **等比例锁定**：椭圆不会被画成圆，抛物线不会被拉扁；曲线超出视窗时自动扩 x/y 范围；
- 额外绘制：焦点 F1/F2、准线（虚线）、双曲线渐近线（虚线）；
- AI 输出 `conic` 对象 + `domain` + `equation`，本地校验 `a/b > 0`。

### v1.6 平面/立体几何（✅）

- 直接复用 `FigureSpec` / `FigureRenderer`；
- 平面：`points`（2D）+ `segments` + `labels`；
- 立体：`points`（3D）+ `edges` + `labels`；
- 立体采用**斜二测投影**（x 向右、z 向上、y 向后上 45°、深度减半），
  避免正方体体对角线两端在屏幕上重合；
- 白底圆角卡片 + 标题；标签上下标（A₁）自动归一化成 A1，避免字体缺字；
- AI 只给点/线，本地负责投影、缩放、居中。

## 3. AI 输出协议

```json
{"kind":"functions","functions":[{"expr":"a*x^2+b*x+c"}],
 "params":{"a":1,"b":-2,"c":1},"domain":[-5,5],"title":"含参二次函数"}
```

```json
{"kind":"conic","conic":{"type":"ellipse","h":0,"k":0,"a":3,"b":2,
 "axis":"right","equation":"x^2/9+y^2/4=1"},"domain":[-6,6],"title":"椭圆"}
```

```json
{"kind":"plane","figure":{"kind":"geometry2d",
 "points":{"A":[0,0],"B":[4,0],"C":[0,3]},
 "segments":[["A","B"],["B","C"],["C","A"]],
 "labels":{"A":"A","B":"B","C":"C"}},"title":"直角三角形"}
```

```json
{"kind":"solid","figure":{"kind":"geometry3d",
 "points":{"A":[0,0,0],"B":[2,0,0],"C":[2,2,0],"D":[0,2,0],
 "A1":[0,0,2],"B1":[2,0,2],"C1":[2,2,2],"D1":[0,2,2]},
 "edges":[["A","B"],["B","C"],["C","D"],["D","A"],
 ["A1","B1"],["B1","C1"],["C1","D1"],["D1","A1"],
 ["A","A1"],["B","B1"],["C","C1"],["D","D1"]],
 "labels":{"A":"A","B":"B"}},"title":"正方体"}
```

## 4. 性能实测（2026-11-09，JIT）

| 项目 | 结果 |
|---|---|
| AI 解析（单函数） | 1.2–2.6s |
| AI 解析（多函数/圆锥） | 2.4–8.6s（模型波动） |
| 首次离屏画图 | 20–26ms（含 Skia/字体首次开销） |
| 单曲线热渲染（中位） | **2.2ms** |
| 3 曲线热渲染（中位） | **3.4ms** |
| 含参函数首帧 | 3.9ms |
| 椭圆首帧 | 4.4ms |
| 平面/立体首帧 | 5.4ms / 2.3ms |
| 图片内存 | 3.2MB/张（1100×760 BGRA） |
| 手写/UI 影响 | 0（后台线程；静态 Image 走现有 tile cache） |

结论：热路径稳定在 2–4ms，首次 20ms 级在后台线程完成；瓶颈是 AI 网络延迟，不是渲染。
没有新增图层/缓存系统，手写路径不变。
