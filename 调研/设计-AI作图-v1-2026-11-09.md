# AI 作图 v1：单解析式函数图

日期：2026-11-09
状态：v1 已落地（幂/指数/对数等单解析式）；后续多解析式、含参、圆锥、立体逐步扩展。

---

## 0. 目标与边界

用户要求：先做简单的——给一个幂函数/指数函数/对数函数，AI 识别后用一个“AI 作图”功能，
根据解析式画出图；后面再支持两个/三个解析式（不同颜色）、含参、椭圆/双曲线/立体。

v1 范围：

- **一个解析式**；
- 支持 `+ - * / ^`、括号、`x`、`e/pi`；
- 函数：sin/cos/tan/asin/acos/atan/sqrt/abs/exp/ln/log/log10；
- 定义域由 AI 给，可避开 log/sqrt 非法区间；
- 生成**静态函数图**（坐标轴 + 刻度 + 网格 + 曲线 + 标题），插入为现有 `Image` 对象；
- 可选中、移动、缩放、删除、撤销、存档；不进入实时图形/手写路径。

## 1. 实现

### 1.1 解析式

- `PlotExpression.cs`：小型递归下降解析器，只接受数学表达式，不执行代码；
- 不做隐式乘法（AI 输出 `2*x`，避免 `2x` 歧义）；
- 本地验证失败会报错，不画空图。

### 1.2 AI 解析

- `AiPlotClient.cs`：OpenAI 兼容 `/chat/completions`，让模型输出：
```json
{
  "functions": [{"expr":"ln(x)","label":"y=ln(x)"}],
  "domain": [0.01, 6],
  "title": "对数函数"
}
```
- 只取表达式/定义域，不让模型给像素；
- 1.5s 左右（DeepSeek flash 实测）。

### 1.3 画图

- `PlotRenderer.cs`：Skia 离屏画 1100×760 静态图；
  - 白色圆角卡片、坐标轴、箭头、主刻度、网格、标题；
  - y 范围按采样自动留边，最大 ±30，出界裁剪；
  - 曲线断段：非有限值/大跳变断线（tan/log 不会连出竖线）；
- 生成 `ImageData`，插成 `StrokeKind.Image`：
  - 复用现有图片对象：选中/移动/缩放/删除/撤销/存档全部现成；
  - 不新增对象类型、不新增 serializer。

### 1.4 UI 入口

- AI 面板的提示词包含“画/作图/图象/图像 + 函数/曲线”，或直接以 `y=` 开头 → 走 AI 作图；
- 否则仍走原来的 AI 出题（mock）；
- 异步：模型解析 + 离屏画图都在后台线程，完成后主线程只 `AddStroke`；
- 不阻塞 UI，不在笔迹路径上做任何工作。

## 2. 性能实测（2026-11-09）

| 项目 | 结果 |
|---|---|
| AI 解析 | 约 1.4–1.5s（DeepSeek flash） |
| 首次离屏画图 | 约 22–23ms（含字体/首次缓存） |
| 热渲染 | 约 **2.9–3.1ms/张** |
| 图片内存 | 1100×760 BGRA ≈ **3.2MB/张** |
| UI 影响 | 0（后台线程；完成才插对象） |
| 手写影响 | 0（静态 Image 对象，走现有 tile cache） |

结论：v1 的性能可以接受；瓶颈是 AI 1.5s，不是画图。热渲染 3ms，单张 3.2MB；
后续批量/多图需要控制张数和内存，但不用新图层/湿墨系统。
