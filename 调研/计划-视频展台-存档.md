## 0. 一句话

视频展台不是第二款软件，而是**同一个 exe 的第二个入口/第二套极简界面**：
桌面快捷方式直接进展台，主程序「更多」里也能进；共用摄像头、笔迹、设置、更新和隐私同意。

---

## 1. 用户场景

学校老师最常见的动作：

1. 双击「视频展台」；
2. 摄像头全屏，默认就是画笔；
3. 讲题、圈画、冻结、抓拍；
4. 点关闭/退出，直接走人。

全程不需要理解白板、文档、PPT、页码这些概念。

---

## 2. 形态：一个程序，两个入口

| 入口 | 行为 |
|---|---|
| 桌面「视频展台」快捷方式 | `InkTeach.exe --visualizer`，冷启动直接全屏摄像头 |
| 主程序「更多 → 视频展台」 | 同进程切到展台，退出回主界面 |

规则：

- 单实例：主程序已在运行时点展台快捷方式，**同进程切模式**，不弹“程序已运行”；
- 主程序在后台/托盘时，关闭展台 = 回主界面/托盘，不杀进程；
- 冷启动展台，关闭 = 退出程序（有未保存抓拍先提示）；
- 穿透 = 画面和墨迹全部隐藏，但摄像头不关、状态保留；退出穿透原样恢复；
- 更新重启后回到展台，不跳回完整版。

---

## 3. 展台内部状态

| 状态 | 说明 |
|---|---|
| 实时 | 摄像头全屏，笔可以直接写 |
| 冻结 | 当前帧定住，墨迹贴在这张纸上 |
| 抓拍画廊 | 多张冻结/抓拍页，可翻、可批注、可导出 |
| 穿透 | 全部隐藏，状态保留 |

关键规则：

- 冻结不是暂停视频，而是把当前帧变成“一页纸”；
- 解冻 = 回实时，旧的冻结页留在画廊；
- 建议“落笔自动冻结”（可关），避免手碰纸导致墨迹漂移；
- 实时批注的墨迹浮在屏幕上，纸一动就会错位——这是实时模式的天性。

---

## 4. 功能清单

### P0（第一版）

- 摄像头选择、热插拔、1080p30（4K 视设备而定）
- 全屏预览、适应/铺满、镜像、旋转 0/90/180/270
- 冻结/解冻（空格）、抓拍（F）
- 实时/冻结上批注：笔、荧光笔、橡皮、激光
- 滚轮缩放、拖动平移、一键复位
- 抓拍画廊：缩略图、翻页、删除、导出 PNG、插入白板
- 穿透隐藏/恢复；退出穿透回画笔
- 摄像头占用/拔掉/权限被拒的明确提示
- 快捷键：空格冻结、F 抓拍、R 旋转、+/- 缩放、Esc 退出

### P1

- 自动对焦/曝光/亮度（取决于摄像头 UVC 控制）
- 冻结帧一键美化：去阴影、白平衡、黑白、锐化
- 文档边缘检测 + 手动四点透视
- 双图对比
- 实时美化（GPU shader，1080p30 可行；CPU 跑不动）

### P2

- 画中画：展台小窗浮在 PPT/白板上
- 手机无线摄像头
- 录像/回放
- 聚光灯、幕布、计时器

## 5. 和完整版的关系

**共享**：摄像头采集、笔迹引擎、冻结/抓拍、美化管线、设置、隐私同意、更新器、单实例、托盘。

**不共享**：界面（极简工具条）、默认来源（直接摄像头）、退出行为（按入口区分）、热键（只保留展台需要的）。

抓拍图可以直接“插入白板/文档”，变成普通图片对象——这是展台和完整版之间的桥。

---

## 6. 技术路线（主要风险）

- 用 **Windows Media Foundation** 的 `IMFSourceReader` 抓 UVC 摄像头；系统自带，不增加安装包。
- 本仓库是 **NativeAOT，不能用内置 COM**（`PptComLate.cs` 已踩过），MF 的 COM 接口要像 PDFium 那样**手写 vtable 函数指针**——这是主要工作量。
- 画面用 D3D11 纹理上屏，只取最新帧、丢旧帧，目标延迟 <100ms。
- 1080p30 MJPG 走 USB2 也能跑；4K 要 USB3，需测带宽/延迟。
- 先做 3~5 天技术验证：枚举设备 → 打开 1080p30 → 解码 BGRA → 上屏 → AOT 发布 → 拔插/占用/权限。

## 8. 待拍板

1. 展台做独立来源（推荐），还是白板背景层？
2. “落笔自动冻结”默认开还是关？
3. 抓拍只存本次会话，还是自动落盘、下次还能打开？
4. 穿透时摄像头保持打开（快）还是释放（隐私）？
5. 第一版只支持 USB UVC，无线手机摄像头后置？
6. 4K 是否必须？如果教室展台是 4K，建议第一版就支持。

## 9. 和拍照美化的关系

先做展台，再做美化，顺序是对的：

- 展台给出稳定的 BGRA 帧（冻结/抓拍），是美化的第一个真实来源；
- 美化内核只认 BGRA，不关心来源，之后可复用到画布图片、扫描版 PDF 页；
- 展台先做“冻结后美化”，实时美化后置（GPU）；
- 数字 PDF 不需要美化，扫面版 PDF/图片页才需要。
