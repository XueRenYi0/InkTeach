# 设计：窗口白板界面与触摸/老年教师原则

日期：2026-11-10　　状态：**UI 原则稿，P0 前定；不改代码**

> 适用：窗口白板第一版；后续 PDF / 笔记 / 展台沿用同一套“底部操作、顶部少放”的原则。
> 目标：学校触摸大屏 + 鼠标 + 手写板都能用；年老教师也能看清、够得到、点得中。

---

## 〇、结论先行

1. **顶部只放系统标题栏 / 标题 / 状态，不放教学操作。**
   所有高频操作放**底部**；顶部最多放低频、非必需的入口（例如设置），够不到也不影响上课。
2. **底部一条主 dock：左边页码、中间工具、右边缩放、最右“更多”。**
   当前页、当前工具、缩放比例**永远可见**；放不下时只把低频工具收进“更多”，不缩小点击目标。
3. **触摸目标 ≥48 逻辑像素**（1.0 档），大档 60、特大档 72；
   现有界面档 0.8/0.9/1.0/1.15/1.3 **增加 1.5“特大”**，专给年老教师/大屏。
4. **图标复用现有桌面批注图标**：同一套 24×24 网格、同样的线条/圆角/颜色；
   窗口里只放大，不换风格。新增图标（页码/缩放/适应/图片/手）也按同一套画。
5. **不能只靠手势**：一指书写、两指平移/缩放、鼠标滚轮、空格/中键拖动都要有；
   再给一个可见的“手/移动”工具，让不会手势的老师也能拖画布。
6. **P0 先带一条假 dock 验证**（假按钮 + 页码 + 缩放 + 文本框 + 拖图），
   不等完整 UI；P0 通过后再做设置页和视觉细节。

## 一、顶部 / 底部怎么分工

```text
┌──────────────────────────────────────────────────────────┐
│ 系统标题栏：白板 · 文件名                        ─  □  ✕ │  ← 系统 chrome，不放教学按钮
├──────────────────────────────────────────────────────────┤
│                                                          │
│                      画布（当前页）                       │
│                                                          │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ ‹ 3/12 › │ 笔 荧光 橡皮 激光 手 │ 撤销 重做 │ 图片 更多 │ − 100% + 适应 │
└──────────────────────────────────────────────────────────┘
   ↑ 页码组            ↑ 工具组              ↑ 动作组        ↑ 缩放组
```

### 1.1 顶部规则

- 窗口模式：**系统标题栏**（最小化/最大化/关闭/贴靠/任务栏白拿）；
- 标题栏下**不再放应用工具条**；最多一条非交互状态（文件名/页码/保存状态），可关；
- **全屏模式**：像希沃那种“整块白板”，**隐藏系统标题栏**，画布铺满当前显示器；
  **底部 dock 保留**，顶部不放任何操作；
  - 进入：`F11`、底部“更多 → 全屏”、或一个显眼的大按钮；
  - 退出：`Esc`、`F11`、底部“更多 → 退出全屏”；不把“退出”只放在屏幕最右上角；
  - 记住进入前的窗口位置/大小，退出全屏原样恢复；
  - 多屏：全屏在**当前窗口所在显示器**；不跨屏铺满；
  - 全屏时任务栏行为按系统设置；不要盖住触摸键盘/系统弹窗；
  - 全屏默认**常显 dock**；用户自己开“贴边隐藏”才收；
- 顶部如果确实要放低频入口（设置/帮助），做成大图标 + 底部“更多”里也有同一个入口，
  不允许“只有顶部能到”。

#### 白板窗口的两种形态

| 形态 | 入口 | 外观 | 用途 |
|---|---|---|---|
| **独立文档窗口** | 桌面快捷方式 / `--whiteboard` | 系统标题栏、任务栏、可最小化/最大化 | 正式白板、保存/打开、和 PPT/PDF 并排 |
| **临时全屏白板** | 覆盖层“白板”按钮（性能达标后） | 无标题栏、无任务栏、铺满当前显示器；底部 dock 保留 | 按一下盖住 PPT，写完回 PPT |

临时全屏模式的硬要求：

- 按“白板”到可写 **≤300 ms**；退出回 PPT **≤150 ms**；
- `Esc` / “更多 → 退出白板 / 回 PPT” 都能退出；不能只靠右上角；
- 不弹文件对话框、不显示标题栏/任务栏、不创建新进程；
- 退出后恢复进入前的 PPT/覆盖层状态和窗口位置；
- 性能不达标就不替换旧覆盖层白板（门槛见 `设计-统一动作与更多面板-2026-11-10.md`）。

### 1.2 底部 dock 规则

| 区域 | 内容 | 为什么 |
|---|---|---|
| 左 | `‹ 页码 ›`（点页码出跳页面板） | 和现有 PPT/文档页码条一致，老师肌肉记忆 |
| 中 | 笔 / 荧光笔 / 橡皮 / 激光 / 手；撤销 / 重做；图片 / 更多 | 高频工具，站在屏幕前够得到 |
| 右 | `− 100% + 适应` | 缩放/适应整页，和页码分开 |
| 最右 | `更多 ⋯` | 图形/文本/选择/截图/设置/全屏/关闭 |

- **当前工具、当前页、缩放比例永远可见**；不能滚出视野；
- 放不下时按项目规矩：分组 → 滚动/分页 → 收进「更多」，**不缩小点击目标**；
- 色带/颜色/粗细：点笔/荧光后从 dock **上方**长出一条大色带（底部 sheet），不放顶部；
- 跳页：点页码，从 dock 上方弹页号网格（10 列、48×48），不放顶部；
- 设置：从“更多”进；设置页也是左侧分类 + 大行，不做小字密集表。

### 1.3 贴边 / 吸附 / 隐藏（复用现有桌面批注那套）

用户 2026-11-10 明确：**像桌面批注工具条一样长显，但可以贴边吸附；开了以后能吸进去，用时再弄出来。**

- 默认：底部居中、**常显**；“贴边隐藏”默认关；
- **可沿底部左右拖动，记住位置**（像桌面批注；只沿底部，不吸左右边，也不去顶部）；
- **第一版只吸附底部**（和现有桌面批注一致；左右吸附以后确认好做再加）；
- 打开“贴边隐藏”后：先做**桌面批注同款外观**（8px 细条/现有把手），
  但触摸命中区放大：外观 8px，实际点按区 **32～48px**（1.0 档 32，1.5 档 48）；
  - P0/P1 在真机大屏上试；不好抓再换成明显的 32/48 方形把手（带抓握点）；
  - 手指/笔点把手 → 展开；鼠标悬停 8px 也可展开（保留现有 hover intent）；
  - 用完后延迟 ~0.7～1s 再收（触摸不能刚松手就收，老师还要点下一格）；
- 复用现有 `FullUi` 的 `AutoHide` / `DockGap` / `SnapMs` / hover-intent 状态机，
  **不要新写一套贴边逻辑**；窗口模式把“屏幕底边”换成“窗口客户区底边”；
- 位置/隐藏开关跨重启记住；窗口缩放/换 DPI 后夹回客户区；
- 全屏：同一 dock；默认常显；用户自己开“贴边隐藏”才收。

### 1.4 色带：直接复用桌面批注那一套

用户 2026-11-10 明确：桌面批注有色带，窗口白板也要有，两边尽量统一。

- **不另做“窗口版色带”**：复用桌面批注的颜色、宽度档、高亮色/透明度、选中态、Tokens；
- 位置：从**底部 dock 向上**长出来（底部 sheet），不放顶部；
- 内容：
  - 笔：常用色 5～8 + 自定义色 + 粗细 3～4 档；
  - 荧光笔：颜色 + 透明度档；
  - 橡皮：大小档（如果桌面批注色带里有）；
- 行为：和桌面批注一致——选笔/荧光时出现，换橡皮/手时收起；
  点空白/换工具/再点当前工具按桌面批注的同一套规则处理，不另发明；
- 尺寸：1.0 档色块 ≥44×44，1.5 档 ≥60×60；色带整体可滚动/分页，不缩小点击目标；
- 色带不能把画布挤没：最多占底部 1/3；放不下时**自适应减色 + 分页/滚动**，不弹层；
- 图标与色块沿用现有 `FullUi` 的色带绘制/命中代码，窗口模式只换锚点（dock 上方）。

> 统一性优先：老师从桌面批注切到窗口白板，色带的位置、颜色、粗细、顺序应该“闭着眼也能点”。

### 1.5 已定：只用色带，否决“笔菜单/弹层”

**2026-11-10 用户拍板：不采用希沃式笔菜单/弹层路线，只保留色带。**

保留这段对比记录，避免以后反复：

| 维度 | 现有色带 | 希沃式笔菜单（弹层） |
|---|---|---|
| 换一次颜色 | **1 下**（直接点色块） | 2～3 下（开面板 → 点色 → 关/点画布） |
| 当前颜色/粗细 | **一直看得见** | 面板收起就看不见，要靠记忆 |
| 画布占用 | 展开时占 64～96px 高 | 收起时不占；展开时浮在画布上 |
| 选项数量 | 自适应 5～8 色 + 自定义；更多色用分页/滚动 | 12 色 + 图案一次看全 |
| 年老教师 | 色块常显、目标大、不用记“再点一次笔” | 要记住“点笔才弹”，面板可能被点没 |
| 与桌面批注统一 | **完全一致** | 新交互，老师要重新学 |
| 触摸误触/焦点 | 点色块即可；无弹层焦点问题 | 弹层要处理点外关闭、焦点、遮挡 |
| 实现成本 | **复用现有色带** | 新弹层 + 新状态机 |

**最终方案（单一路线）：**

- 点笔/荧光 → 从底部 dock 展开色带；换橡皮/手 → 收起；
- 色带内容：当前色 + 5～8 个常用/最近色 + 3 档粗细；自定义色沿用桌面批注现有入口；
- 放不下：按现有 `FullUi` 的 Nano/Mini/Compact/Full 自适应减色，再加**分页/左右翻页/横向滚动**；
- 1.5 档最多显示 5 色 + 3 档粗细，**不缩小色块**；其余颜色翻页，不弹层；
- “色带常开”开关与桌面批注共用：默认一致，老师自己决定是否常摊；
- **不做**“再点一次笔弹笔菜单”、不做完整色板弹层、不做第二套笔设置；
- 色带最大占底部 1/3；不能把画布挤没；翻页钮至少 48×48，放在色带两端。

> 一句话：**只有色带一条路；颜色多就翻页，不弹层。**

## 二、尺寸与老年教师

### 2.1 尺寸档

| 档位 | UiScale | 按钮 | 图标 | dock 高 | 适用 |
|---|---|---|---|---|---|
| 小 | 0.8 | 40 | 20 | 56 | 小笔记本、放得下更多 |
| 标准 | 1.0 | **48** | 24 | 64 | 默认 |
| 较大 | 1.15 | 54 | 27 | 72 | 普通触摸屏 |
| 大 | 1.3 | 60 | 30 | 80 | 年老教师/大屏 |
| **特大** | **1.5（新增）** | **72** | **36** | **96** | 学校大屏、年老教师 |

- 现有 `UiScale.cs:22` 是 0.8/0.9/1.0/1.15/1.3；**新增 1.5“特大”**，并保留 0.9；
- **窗口白板和桌面批注共用同一套 `UiScalePresets`**：不单独给窗口做一套；
  1.5 两边一起加、一起测；不合适就两边一起调，避免“窗口大、批注小”两套观感；
- 触摸最小 48（高于微软 40 的建议，学校大屏手指更粗）；
- 1.5 档必须在 **1280×720 逻辑屏**上实测：dock 放不下就把低频收“更多”，
  不允许把按钮缩到 48 以下；
- 图标用矢量路径，放大不糊；不要位图图标。

### 2.2 年老教师

- 默认不强制大档，但设置里第一项就是“界面大小”，带实时预览；
- **大/特大档默认显示文字标签**（笔/擦/撤销/图片/更多），图标下 12～14 号字；
  标准/较小档默认只显示图标，省空间；
- 高对比主题；正文 ≥16 逻辑像素；按钮文字 ≥16；
- **不做只靠悬停的操作**；触摸没有 hover，重要功能必须常显或长按有反馈；
- 破坏性操作（清空/删除/关闭未保存）二次确认，确认按钮要大；
- 撤销/重做常显；不要藏在手势里；
- 减少动画选项；系统关闭动画时直接跳终态；
- 错误提示用大字 + 一句话 + 下一步，不用小字日志。

## 三、输入方式（触摸 / 鼠标 / 手写板）

> **术语先定清楚：**
> - “**笔**”专指**触控笔 / 电磁笔 / 压感笔 / 手写板的笔**；
> - “手指 / 鼠标 / 触摸”是另一类。
> - 手写板不是“触摸板”：手写板的笔就是笔；板上的按键/滚轮可映射平移、橡皮。

| 输入 | 画布 | 按钮 | 平移/缩放 |
|---|---|---|---|
| **笔**（屏幕笔/手写板笔） | **永远写字/画图**，压感按现有引擎；即使选了“手”也写 | 笔尖点按 | 笔上的按键可映射橡皮/手（后续） |
| **手指** | **默认写字**（年老教师不用学模式） | 点按 | **两指平移/缩放**；选“手”工具后一指拖画布 |
| **鼠标** | 默认左键写；右键菜单 | 左键点 | 滚轮上下；`Ctrl+滚轮` 缩放；空格/中键拖动；选“手”后左键拖画布 |
| **手写板** | 板上的笔 = 笔，写字；压感 | 板上的按键可映射撤销/橡皮/手 | 板上的滚轮/按键可映射平移；不做专用 UI |
| **掌拒** | 笔靠近时手掌不画 | — | 复用现有 Touch/掌拒逻辑，窗口模式重测 |

规则：

- **笔永远写**：选了“手”也写；避免老师拿起笔却写不出字；
- **手指/鼠标在手模式下平移**；不选“手”时手指默认写、鼠标左键默认写；
- **两指平移/缩放始终可用**，不依赖当前工具；
- “手”是主工具组里的一个格；选中高亮；点笔/荧光/橡皮自动退出“手”；再点“手”可回到上一个工具；
- 不要求老师记住“几指”才能完成基本操作；基本写字/擦除/翻页/缩放都有可见按钮；
- 触摸按钮的命中区比视觉大 4～8px；按下有反馈；
- 长按 = 提示/更多，不把长按作为唯一入口；
- 鼠标 hover 才出现的按钮，在触摸下必须常显或长按可见。

## 五、设置清单（先列项，视觉后做）

### 5.1 界面

- 界面大小：小 / 标准 / 较大 / 大 / **特大**（实时预览）
- 主题：浅色 / 深色 / 高对比
- 显示文字标签：大/特大默认开；标准/较小默认关
- 减少动画
- 语言

### 5.2 白板

- 默认视图：适应宽度（推荐）/ 适应整页
- 最小缩放：适应整页（推荐）/ 25%
- 页尺寸：16:9（默认）/ 其他（后续）
- 板色 / 底纹（空白/横线/网格/点阵）
- 自动保存：开（默认）
- 图片插入最大尺寸：页宽 80%（默认）/ 原始尺寸 / 其他
- 全屏时隐藏 dock：关（默认；年老教师需要常显）
- 置顶：关（默认）
- 启动时最大化：关（默认）

### 5.3 输入

- 手指默认：书写（推荐）/ 移动
- 压感：开（默认）
- 掌拒灵敏度：标准 / 强
- 笔按键：橡皮 / 手 / 撤销（后续）

### 5.4 快捷键

- 查看/修改；默认沿用现有桌面批注快捷键；
- 触摸用户不依赖快捷键，但鼠标/手写板老师可用。

> 笔记/PDF/展台的设置等各自功能稳定后再加；第一版不混进白板设置页。

## 六、P0 要验证的 UI 项（带假 dock）

P0 不是“只画一条线”，要带这些假 UI：

- 系统标题栏 + 底部假 dock（48px 按钮）+ 页码组 + 缩放组；
- 画布页 + 笔迹 + 缩放/平移；
- 一个画布文本框（中文输入）；
- 拖一张图片进窗口（OLE drop 提示/落点）；
- 1.0 / 1.3 / **1.5** 三档 dock；1280×720 与 1920×1080 两种逻辑屏；
- 触摸/鼠标/笔三种输入（有真机就测，没有先用合成/鼠标）；
- 按钮不误画、画布不误触、灰色桌面点击有提示。

**P0 UI 通过标准：**

| 项 | 标准 |
|---|---|
| 可达性 | 所有课堂高频操作都在底部 dock；不要求去顶部 |
| 尺寸 | 1.0 档按钮 ≥48；1.5 档 ≥72；1280×720 下当前页/缩放/当前工具仍可见 |
| 溢出 | 1.5 档放不下时，低频进“更多”，不缩小按钮 |
| 输入 | 笔/手指/鼠标都能写；按钮不误画；两指平移/缩放可用 |
| 文字 | 画布文本框中文输入、候选窗不飘 |
| 拖图 | 从资源管理器拖入有高亮/落点，失败不崩 |
| 视觉 | 图标与现有批注一致；放大不糊；高对比可读 |

## 七、拍板与还要确认的细节

### 已拍板（2026-11-10 用户）

1. **底部 dock 布局**：页码左 / 工具中 / 缩放右。
2. **手指默认**：默认写字；两指平移/缩放。
3. **“手”工具**：放主工具组，触摸用户一眼可见。
4. **全屏 dock**：默认常显；可贴边吸附/隐藏，复用桌面批注那套“吸进去、用时再出来”。
5. **笔的语义**：屏幕触控笔/电磁笔/手写板的笔 = 永远写；手指/鼠标在“手”模式下才平移。
6. **吸附边**：第一版只做底部；左右吸附以后确认好做再加。
7. **隐藏把手**：先做桌面批注同款外观（8px），触摸命中区放大到 32～48px；
   真机不好抓再换明显把手。
8. **缩放档统一**：窗口白板和桌面批注共用同一套 `UiScalePresets`；新增 1.5 两边一起加、一起测。
9. **文字标签**：大/特大档默认开；标准/较小默认关。
10. **底栏位置**：可沿底部水平拖动，记住位置；只沿底部，不吸左右边。
11. **全屏**：隐藏系统标题栏、画布铺满当前显示器、底部 dock 保留；`Esc/F11/更多`退出，恢复窗口位置。
12. **色带**：直接复用桌面批注那一套；从底部 dock 向上展开，颜色/宽度/顺序/行为两边一致。
13. **笔菜单/弹层**：否决；只用色带。颜色多就自适应减色 + 分页/滚动，不弹第二层。

### 还要确认

1. **顶部状态**：不做 / 只显示文件名+页码（推荐后者，非交互）。
2. **1.5 档实测**：先在 1280×720 上试；不够再两边一起加到 1.6/1.8。
3. **隐藏把手实测**：桌面批注同款 8px 外观 + 32～48px 命中区，真机大屏试；不好抓再换明显把手。
