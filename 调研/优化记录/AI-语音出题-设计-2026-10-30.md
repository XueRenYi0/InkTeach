## 0. 一句话目标

老师点一下工具栏的 `AI` 格，打开一个轻面板；按住说话或直接打字，AI 生成题目，结果变成一张可折叠、可拖动、可擦除的**题卡**。

---

## 1. 第一版范围

### 做

- `AI` 工具格 + 全局快捷键
- 文字输入
- 按住说话 + 流式语音识别
- 默认参数：年级 / 题量 / 难度
- 调大模型出题
- 结构化题目 JSON
- 原生题卡
- 题干黑色、解析红色
- 答案默认折叠
- 拖动、变宽、折叠、删除、撤销、保存
- 对象橡皮擦整卡删除
- 失败提示与重试

### 不做

- 会员 / 支付 / 按量计费
- 服务端 AI 代理
- 视觉识题 / 截图解题
- 语音朗读
- 多轮聊天
- 账号系统
- 复杂公式编辑器
- WebView 题卡

## 2. 入口设计

### 2.1 展开工具条

新增一个独立的 `AI` 格：

```
… [收藏] [AI] [更多]
```

- 图标用 `AI` / `✦`，不要用麦克风图标；
- 它是“打开 AI 面板”的动作，不是画笔工具；
- 点击不改变当前笔；
- 主条放不下时进“更多”；
- 极简/未钉住时，“更多 → AI 出题”必须能到；
- 主条可见时，不在“更多”重复同一入口。

### 2.2 收起状态

**只保留一个悬浮球，不加第二个球。**

```
[ ● ]  单击 = 展开工具条
        全局快捷键 = 直接打开 AI 面板
```

- 悬浮球仍然是“展开工具条”，不改成 AI；
- 不做“长按球开 AI”：和拖动/展开冲突，且不可发现；
- 如果以后 AI 使用频率很高，再评估是否加卫星按钮，第一版不做。

### 2.3 全局快捷键

- 建议一个未占用的组合键，例如 `Ctrl+Alt+Shift+A`；
- 按一次打开 AI 面板，不直接录音；
- 面板打开后，麦克风按钮可直接按住说话；
- 快捷键可配置，第一版给默认值。

## 3. AI 面板

### 3.1 复用现有面板

- 复用现有面板的视觉语言：同圆角、同底色、同投影、同 DPI 缩放、同命中测试；
- 位置贴在 AI 格上方/旁边，不挡当前题目；
- 不是全屏模态；点面板外、`Esc`、再点 AI 格都关闭；
- 截图/吸管/穿透/放映时自动隐藏；
- 不引入 WebView，面板仍由现有 UI 层绘制。

### 3.2 面板布局

```
┌──────────────────────────────┐
│  AI 出题                 ✕   │
│                              │
│  [ 按住说话 ]                │  ← 主操作
│                              │
│  或输入要求，例如：           │
│  “给初二出三道二次函数题”      │
│  [________________________]  │
│                              │
│  年级 ▾   题量 ▾   难度 ▾     │
│                              │
│           [ 生成 ]           │
└──────────────────────────────┘
```

- 麦克风按钮要大，鼠标/笔/触摸都容易按；
- 文字输入框始终存在；
- 没有麦克风/权限被拒：麦克风置灰，文字输入自动聚焦；
- 参数标签有默认值，不强制每次确认；
- 语音/文字里明确说了“高三、五道、难一点”，以话里的为准；
- 没有说就用默认值/上次值。

### 3.3 状态机

| 状态 | 界面 | 可做什么 |
|---|---|---|
| Idle | 麦克风 + 输入框 + 参数 | 说话/打字/改参数 |
| Listening | 红点 + 波形 + 计时 | 松开结束、Esc 取消 |
| Transcribing | “识别中…” | 取消 |
| Generating | “正在出题…” + 取消 | 取消 |
| Error | 错误原因 + 重试 | 重试/改文字 |
| Done | 面板收起，题卡出现 | 拖卡/折叠/删除 |

## 4. 语音与文字输入

### 4.1 语音

- **按住说话**：按住麦克风开始，松开结束；不做常听、不做唤醒词。
- 最长 30 秒；最短 0.3 秒；`Esc` 取消。
- 流式 ASR：说话过程中实时显示部分文字。
- 松开后显示最终识别文字，并**自动生成**（不强制改错字）。
- 识别文字保留在面板里，提供“编辑”和“重说”：
  - 编辑：把文字放回输入框，改完再生成；
  - 重说：重新录音；
  - 生成的题卡不对，也可以回到面板改字重生成。
- 空识别/太短/明显没听清：不自动生成，提示“没听清，重说或直接输入”。
- 低置信度（如果 ASR 提供 confidence）：不自动发送，停在编辑状态。

### 4.2 关于“不需要改错字”

豆包/火山流式语音的通用中文识别已经不错，但数学口语仍有歧义：

- “x 的平方” vs “x 平方”
- “二分之一” vs “1/2”
- “角 ABC” vs “三角形 ABC”
- “负三的平方” vs “负三平方”

所以产品上**不强制改字**，但保留“编辑/重说”作为兜底：

- 默认自动发；
- 识别文字显示出来，老师一眼能看出明显错误；
- 生成结果不对时，点“重说”或“编辑”即可；
- 不要求每次确认，避免打断课堂节奏。

可选增强：在生成前用一个小提示让模型把口语数学术语规范化，不额外让老师操作。

### 4.3 文字

- 输入框始终可用；
- 回车发送，`Shift+Enter` 不需要（单行输入）；
- 没麦克风时默认聚焦输入框；
- 语音识别文字也会落到输入框，可继续编辑；
- 文字和语音共用同一套生成逻辑。

### 4.4 流式语音与模型

- 优先评估豆包/火山引擎流式语音识别；
- 大模型可用豆包或 OpenAI-compatible 接口；
- 第一版：**语音流式，题目 JSON 一次性返回**；
- 暂不做“边生成边改卡片”，避免结构化 JSON 解析复杂度；
- 面板显示“正在出题”，完成后一次性出卡。

## 5. 出题逻辑

### 5.1 默认参数

- 年级：设置里的默认年级，未设置则“初二”；
- 题量：3 道；
- 难度：中等；
- 答案：生成但默认折叠；
- 题型：根据老师的话推断；没说的话由模型按知识点选择。

### 5.2 提示词要求

模型必须返回结构化 JSON，不返回 Markdown 长文：

```json
{
  "title": "二次函数·中等",
  "grade": "初二",
  "topic": "二次函数",
  "difficulty": "中等",
  "questions": [
    {
      "stem": [
        { "type": "text", "text": "已知 " },
        { "type": "math", "latex": "x^2-3x+2=0", "plain": "x²-3x+2=0" },
        { "type": "text", "text": "，求两根。" }
      ],
      "options": [],
      "answer": [
        { "type": "math", "latex": "x_1=1,\\ x_2=2", "plain": "x₁=1，x₂=2" }
      ],
      "analysis": [
        { "type": "text", "text": "因式分解得 " },
        { "type": "math", "latex": "(x-1)(x-2)=0", "plain": "(x-1)(x-2)=0" }
      ],
      "knowledge": ["一元二次方程"],
      "difficulty": "中等"
    }
  ]
}
```

要求：

- 只输出 JSON；
- 公式只放在 `math` 段，`text` 段不出现 LaTeX；
- 每题必须有题干、答案、解析；
- 题量、难度、年级按请求；
- 不编造教材版本/考试来源；
- 答案和解析分开。

### 5.3 校验

- JSON 解析失败：重试一次；
- 缺字段/题量不对：重试一次；
- 仍失败：面板显示“生成格式不对，重试”；
- 不把模型原文直接塞进题卡。

## 6. 题卡

### 6.1 对象模型

`AiQuestionCard` 是文档对象，不是一张大截图，也不是 UI 浮窗：

- 所属页（PPT 页 / PDF 页 / 白板页）；
- 位置、宽度；
- 题目数据；
- 答案是否展开；
- 颜色/主题；
- 创建时间、模型、来源（语音/文字）；
- 参与撤销、保存、导出、翻页隔离。

### 6.2 样式

- 题干：黑色 `#1F2328`；
- 解析/答案：红色 `#C62828`；
- 卡片纸面：浅色半透明底，保证投影可读；
- 深色主题下仍用浅色纸面，避免黑/红在深色底上难读；
- 标题栏：知识点 · 难度 · 题量；
- 答案默认折叠；
- 字体：微软雅黑/系统中文；公式字体单独。

### 6.3 交互

- 拖动标题栏移动；
- 拖右边缘/右下角改宽，高度自动；
- 默认宽约 560 逻辑像素，最小 360，最大屏幕 80%；
- 最大高度 70% 屏幕，超出内部滚动；
- 点“显示答案”展开/折叠；
- 底部：换一批、复制、删除；
- 对象橡皮擦整卡删除；像素橡皮擦忽略题卡；
- 删除后一次撤销恢复整张卡；
- 卡片不挡当前题目，放在题目右侧或下方；
- 翻页时跟着页面隐藏/显示。

### 6.4 排版

- 文字用 DirectWrite `IDWriteTextLayout`；
- 公式第一版用 Unicode 线性写法；
- 后续公式图片作为 inline object，基线对齐；
- 变宽/字号变化时重建 Layout；
- 折叠只改 section 可见性，不重新请求模型；
- 拖动只移动缓存位图，不重排。

---

## 7. 公式

- 模型输出 LaTeX 只是中间格式；
- 第一版显示 `plain` 线性写法：`x²`、`√2`、`(1/2)`、`∠ABC`；
- 复杂公式（堆叠分式、积分、矩阵）第二版接 MicroTeX/KaTeX；
- 绝不把 `\frac{1}{2}` 这种源码显示给学生；
- 公式渲染失败时显示 plain 兜底，不显示 LaTeX；
- 缓存 key：`latex + 字号 + 颜色 + DPI`；
- 题干公式黑，解析公式红。

## 8. 架构

```
客户端
 ├─ AiOrchestrator
 │    ├─ ByokProvider（第一版）
 │    └─ HostedProvider（以后）
 ├─ SpeechService（流式 ASR）
 ├─ QuestionService（提示词/JSON/校验）
 ├─ AiQuestionCard（文档对象）
 ├─ CardLayout（DirectWrite + 公式）
 ├─ MathRenderer（V1 plain；V2 MicroTeX/KaTeX）
 ├─ SecretStore（DPAPI/凭据管理器）
 ├─ UsageMeter（本地统计）
 └─ Entitlement（第一版 Free；以后签名 License）
```

原则：

- AI 是可选功能，没 Key/没网不影响手写；
- 不把共享 API Key 放客户端；
- BYOK 用户的 Key 不明文落盘；
- 题卡数据不绑模型供应商；
- 公式渲染不绑 WebView；
- 会员/按量以后用签名 License + serverless，不买常驻服务器。

## 9. 异常与边界

- 没 Key：提示去设置；
- 麦克风权限拒绝：文字输入；
- ASR 超时/失败：保留文字框，重试；
- 识别为空/太短：提示重说；
- 模型超时/断网：面板错误 + 重试；
- JSON 不合格：自动重试一次；
- 重复点击生成：按钮置灰；
- 生成中取消：丢弃结果，不建卡；
- 公式缺失：plain 兜底；
- 卡片超出屏幕：夹进工作区；
- 翻页/截图/穿透：面板和题卡按规则隐藏；
- 多显示器/高 DPI：按现有 UI 缩放逻辑处理。

## 10. 隐私与安全

- 不常开麦克风；按住才录；
- 录音不落盘，识别完即释放；
- 只把识别文字/题目要求发模型，不发送整屏；
- 不发送学生姓名/名单；
- API Key 用 Windows 凭据管理器/DPAPI；
- AI 结果标“AI 生成，请老师核对”；
- 不自动执行模型返回的任何指令；
- 公式/题卡内容只作为数据，不执行代码。

### 文本框优化第二批（2026-10-30）

- 普通文本框默认**透明底**，直接融进白板/PPT；AI 题卡仍浅色纸面。
- 普通文本框默认**自动高度**（最小 120 逻辑像素）；拖上下/角后切成固定高度。
- 行距/内边距在排版层：正文约 1.55 倍行高、18 逻辑像素内边距。
- 操作条 `A− / A+` 调字号；普通文本框颜色可改；8 手柄改宽高、可撤销。
- 公式：`CSharpMath.SkiaSharp`（MIT）+ SkiaSharp 2.88.9；
  普通文本框里**整行** `$$...$$` / `\[...\]`、**行内** `$...$` / `\(...\)`
  都会渲染成透明公式图；跨行 `\[` / `\]`、开符号和公式同一行也能解析；
  `--mathtest` 42 个典型公式（分式、根号、矩阵、cases、aligned、`\boxed`、
  `\text`、`\dfrac`、`\overrightarrow`、Unicode 关系符、几何符号……）全部通过。
- `LatexCompat` 兼容层：大模型常见的 `\boxed`、`\dfrac`、`\tfrac`、
  `\textcolor`、`\cancel`、`\xrightarrow`、`\tag`、`\label`、`\hspace`、
  `\begin{align}` / `\begin{equation}`、`\\[2pt]` 等在这里统一翻译；
  `\overset` / `\underset` / `\stackrel` 保留主体（圆弧近似成上划线）；
  以后遇到新命令只加一张表，排版层和文本框不用改。
- 公式位图按 `(LaTeX, 字号, 颜色, 倍率)` 缓存（最多 128 条），拖手柄不再反复渲染。
- 公式比文本框还宽时等比缩到行宽，不超出卡片边界。
- 公式里混中文（`\text{当 }x>0\text{ 时}`）会拆成「文字 run + 公式 run」排在同一基线，
  不再画成方框；AI 题卡的题干/答案/解析也走同一套行内公式与 Markdown。
- Markdown 子集：`#` 标题、`**粗体**`、`*斜体*`、`-` 无序列表、`---` 分隔线；
  中文收尾标点不再孤零零掉到下一行行首；`2*3` 这类乘号不会被当成斜体标记。
- 文本框选中时，操作条下方放不下会**翻到框上方**，不再压住最后几行内容。
- 下一步：对齐/背景切换面板、公式内换行、完整 Markdown。

**渲染路线（2026-10-30 结论）**：不引 WebView 的前提下，`CSharpMath + LatexCompat`
是维护成本最低的方案——不支持的写法集中成一张命令表，不逐题适配；
今天 42 个常见写法全过。若以后要 100% LaTeX（复杂表格、交换图、排版宏包），
只能上 **WebView2 + 离线 KaTeX/MathJax**（本机离屏渲染成图，不需要服务器），
代价是多一个 WebView2 运行时、首次渲染慢、AOT/COM 复杂度，和现在"纯原生"的方向冲突。

**已知限制（后续处理）**：

- 文本框内容超出固定高度时先裁切，内部滚动/溢出菜单后续补；
- 行内公式的断行是字宽估算，遇到超长公式可能整体偏宽；
- 对齐/背景切换、复杂 Markdown（表格/图片/代码块）还没进操作条；
- 文本框编辑已记一步撤销（改宽高/字号/编辑各算一步）；编辑上限 20000 字；
- AI 题卡第一版只读，普通文本框可编辑；
- 主工具条 AI / 文本框格、`CellsVersion` 迁移放到 1B。
