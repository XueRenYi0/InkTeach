# 闭源发布流程（2026-11-11 起）

> 从 **9.7.0** 起：源码私有，只公开发布二进制。
> 9.6.0 及更早仍是 GPL-3.0，旧仓库保持公开并归档，老用户还能收到旧版更新。

## 一、一次性设置（在 GitHub / GitCode 网页上做）

### 1. 源码仓库转私有（或新建私有仓库）

- 打开 `https://github.com/XueRenYi0/InkTeach/settings`；
- 最下面 **Danger Zone → Change repository visibility → Make private**；
- 确认后，源码、Issues、旧 Release 都不再公开（**fork 不会消失**，这是 GitHub 的规则）。

> 想更干净：新建私有 `InkTeach-Source`，把本地仓库推过去；**旧仓库保持公开、只更新清单**。

### 2. 新建公开的“发布仓库”

- 新建 `https://github.com/new` → 名字 **`InkTeach-Releases`** → **Public** → 勾 README；
- 这个仓库**只放 `update.json` 和说明**，不要放 `src/`；
- Release 附件放 zip / Setup。

> GitHub 每个 Release 会自动带 “Source code (zip/tar.gz)”，那是**发布仓库自身**的快照
> （只有 README/update.json），不会带出 App 源码。

### 3. 旧仓库：保持公开，只同步清单

- **不要转私有，也不要 Archive**：9.6.0 及更早的客户端只认旧仓库的 `update.json`，
  私有/归档后就收不到更新了。
- 旧仓库的源码**冻结在 9.6**；以后每次发版只提交 **`update.json` 一个文件**，
  里面的 zip 地址指向新的发布仓库。
- 用脚本同步（旧仓库克隆到 `..\InkTeach-Legacy`）：

  ```powershell
  .\tools\sync-legacy-manifest.ps1 -RepoDir ..\InkTeach-Legacy
  ```

  脚本只 copy / commit / push `update.json`，不碰源码。

### 4. GitCode 国内镜像

- 新建公开仓库 `XueRenYI0/InkTeach-Releases`（或把原仓库转私有）；
- `tools\gitcode-release.ps1` 已改为**只上传附件、不推源码**；
- 令牌放在 `%USERPROFILE%\.gitcode-token`。

## 二、每次发版

```powershell
# 1) 打包（AOT + zip + Setup + update.json）
.\publish.ps1

# 2) 把清单提交到“发布仓库”（不是源码仓库）
#    假设发布仓库克隆在 ..\InkTeach-Releases
Copy-Item .\update.json ..\InkTeach-Releases\update.json -Force
git -C ..\InkTeach-Releases add update.json
git -C ..\InkTeach-Releases commit -m "release 9.7.0"
git -C ..\InkTeach-Releases push

# 2.5) **旧仓库只同步 update.json**（老客户端靠它看到新版本）
.\tools\sync-legacy-manifest.ps1 -RepoDir ..\InkTeach-Legacy

# 3) 上传 GitHub Release（附件）
gh release create v9.7.0 `
  .\dist\InkTeach-9.7.0-win-x64.zip `
  .\dist\InkTeach-Setup-9.7.0.exe `
  -R XueRenYi0/InkTeach-Releases `
  --title "InkTeach 9.7.0" --notes-file .\dist\release-notes-9.7.0.md

# 4) 国内镜像（只传附件）
.\tools\gitcode-release.ps1 -Version 9.7.0 -Notes "…"
```

## 三、已经改好的代码

| 位置 | 改动 |
|---|---|
| `LICENSE` | 换成专有 EULA（9.7.0 起）；9.6.0 及更早仍 GPL-3.0 |
| `README.md` / `README.en.md` | 许可说明、徽章改为 Proprietary |
| `src/InkEngine/Update.cs` | 更新清单地址改为 `InkTeach-Releases`（GitHub / GitCode / jsDelivr 共 5 条） |
| `publish.ps1` | `updateBase`、GitCode 镜像、jsDelivr purge 全部指向 `InkTeach-Releases` |
| `tools/gitcode-release.ps1` | **不再推源码**，只建 Release + 传附件 |

## 四、注意

1. **旧版本更新**：9.6.0 及更早读的是旧仓库的 `update.json`。旧仓库保持公开 + 归档，
   它们还能正常检查更新；新版本读 `InkTeach-Releases`。
2. **不要把源码推到发布仓库**；也不要在发布仓库里开 Actions 构建。
3. **第三方许可**：安装包里的 `THIRD-PARTY-NOTICES.md`、`pdfium-licenses/` 必须保留
   （MIT / BSD 要求），这和数据是否开源无关。
4. **GPL 代码检查**：`Ppt.cs` / `PptLink.cs` / `StrokeMotion.cs` 注释里写了“参考思路、
   未复制代码”。如果以后发现哪段确实抄了 GPL 项目，要么重写，要么那段保持 GPL。
5. 版本号：`src/InkTeach/InkTeach.csproj` 的 `<Version>` 是唯一来源，改这里即可。
