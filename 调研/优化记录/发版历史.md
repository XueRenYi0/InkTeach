## v8.9.3　v8.9.3 —— 输入路径与手感修复

发布：2026-10-07T08:33:39Z　**（保留）**

## 本版主要是**输入路径与手感**修复

| 修了什么 | 说明 |
|---|---|
| **快速画圆出折线** | 根因：圆上每顶点的转角会撞上固定的 35° 阈值 → 每个点都判成"角"。改成"**带符号转角 vs 局部趋势**"，阈值按真机转角分布定为 **80°** |
| **待机 45fps / 单核 5% 空转** | 根因：`IsAnimating` 那句"要帧"在"面板根本不会收"时也成立（开了贴边隐藏但指针还没碰过面板）。修后待机 **0fps / 1.6%** |
| **关掉 Windows Ink 时输入被系统合并** | 真机实测指针消息只有 60–79Hz，而 Raw Input 有 154–194Hz。**Raw Input 补点默认开** |
| **压感起笔的粗细不对** | 起笔那几个点在压力包到达之前只能拿兜底值："0.5"→开头鼓一个粗点、"0"→开头一段细线。**改成拿到真实压力后回填** |
| **压力是台阶（宽度一跳一跳）** | 一条指针消息只取一个压力值套给整批点。改成**把这一批取到的每个包的压力按位置摊到点上** |
| **命令行开关写在第一个位置会误进"自检模式"** | 那不是用户能知道的规矩。改成**结构性判据**：没有任何测试模式认领的参数，一律当正常启动 |

## 新增

- **Wintab**（关 ink 时的压力来源，实测 **16383 级** / 168Hz，对比 Windows Ink 的 1024 级）
