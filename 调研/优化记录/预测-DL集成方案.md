## 一、目标与边界

- 目标：在**不改现役路径**的前提下，加一个实验档预测（旗标 `--predict3` + 设置项），真机 A/B 后决定去留。
- 边界：
  - 默认关；关时逻辑与 9.0.5 完全一致（零行为变化）；
  - 不迁移 RTS、不动现有尾机制（限速/快收），只**替换预测源**；
  - 手感验收必须真机（桌面 + 手写板 + 学校大屏各一轮）。

## 二、组件设计

### 2.1 模型与推理（推荐：C# 手写前向，不用 ONNX）

- 模型：`runs/v4/model.pt`（GRU h=96、L=20、10 视界 4–40ms、34.5k 参数；τ 头本期不用）。
  - 参数总量小、结构简单（GRU + 10×(96→2) 线性头），**手写 C# 前向**：NativeAOT 友好、零依赖、无加载时间；
    ONNX Runtime 体积/初始化/裁剪都是负担，否掉。
- 导出：一次性脚本把权重导出为 C# 常量或嵌入二进制（`_ml-predict` 侧出）；推理单测对齐 Python（误差 <1e-3）。
- 成本预算（**P0 实测 2026-10-11**）：GRU 20 步 ≈ 0.6M MAC/点；C#（AVX2 双路 FMA）
  **≈86µs/点**（标量兜底 ~0.9ms）；批点展开下每帧 3~4 点 ≈ 0.35ms（60Hz 帧预算的 ~2%），
  预分配状态、零 GC；金标对拍 max|Δ| = 7.4e-6（`tools/dl-probe`，255 条真数据向量）。

### 2.2 特征管线对齐（把两次踩坑固化进代码）

- **dt0 固定 5ms**（训练口径）；跨采样率由 dt 通道承担（DT 实测 4.2–5.2ms/点）。
- S（归一化尺度）：**在线估计**——滚动窗口（~2s）内步长中位值，clamp 到 [0.5, 6]px；启动 warmup 用默认 2px。
- 8 维特征/步：`[dx/S, dy/S, dt/5, sp, f/fscale, f_ok, a_n, tr_n]`（公式与 `_ml-predict/code/inkdata.py` 逐字一致）。
- **批点重定标**（新增组件）：同毫秒一批 k 个点 → 按 r 前向填充（r 默认 4.7ms，可配）再喂预测器；
  **只影响"喂给预测器"的时间轴，不改存储/绘制/回放坐标**。批内点的空间位置原样保留。

### 2.3 控制器

- 预测位移 = μ(光子滞后) × γ；γ=0.9（保守）为默认，旗标可调（`--predict3g`）。
- 光子滞后：用现有帧延迟测量（Present→上屏 1 帧）；无测量时按 60Hz=16.7ms 保守值。
- 显示尾：沿用现有尾机制，仅替换"源位移"；急转门暂沿用（后续可按 τ 头升级）。

### 2.4 旗标与设置

- 命令行：`--predict3`（本次运行开）、`--predict3g <0..1>`；
- 设置页：「墨迹预测」现有开关旁边加实验档（或档位：关 / B4（默认）/ 新模型（实验））——UI 方案随 P1 出图再定；
- 黑匣子头部扩展注释：`#predict3 0/1 gamma ..`（v1 格式允许 `#` 行，向后兼容）。

### 2.5 风控与回退

- 全部推理包 try/catch：任何异常 → 关闭 predict3 并回 B4/关，日志留痕（规矩三：失败当没有）；
- 特征/输出 NaN 检查；S 异常时回退默认值；
- 性能看门狗：单点推理 >0.5ms 连续 100 次 → 自动降级。

## 三、分期与验收

| 期 | 内容 | 验收 |
|---|---|---|
| P0 | 模型导出 + C# 推理模块 + 单测（对 Python 逐点对齐 <1e-3） | 单测通过；**不碰引擎** |
| P1 | 引擎接入（特征管线/批点重定标/控制器）+ 旗标 + 自检 | `--replayinput` 回放两份真机数据，指标与离线台一致；touchtest 全绿 |
| P2 | 真机 A/B（桌面写、手写板写、学校大屏） | 用户手感验收（滞后/甩/跳三项） |
| P3 | 打磨（S 估计、γ 定档、文档） | 发版流程（交接单六步） |

## 四、风险清单

1. 在线 S 估计抖动（写小字/大字切换）→ warmup + 慢时常数（2s 窗）+ clamp；
2. 蓝牙手写板（WH851）报点率偏低（实测 ≈5.2ms/点、批均 2.6 点）→ 重定标 r 按设备自适应（用批间隔/k 在线估）；
3. 文档/滚动画布坐标与屏幕坐标缩放不同 → 预测在画布坐标内做（与墨迹同空间），显示偏移换算走现有屏幕映射；
4. 少数设备输入不批量（逐点直达）→ 重定标器"空转"，无副作用。
