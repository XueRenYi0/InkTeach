# 调研：呼出盘（轮盘）现状与优化建议

- 日期：2026-10-25
- 状态：**只调研，不改代码**
- 关联：`调研-呼出盘-扇面与比例.md`、`计划-呼出盘-视觉改版.md`、`调研-触摸手势-滑动书写与轮盘呼出.md`

---

## 0. 结论速览

1. **底子很好，不要推倒重来。** 现在是 8 个 45° 扇格、V-a 排序、主条同款图标、marking-menu（按住→划→松手）、触屏两指长按/轻点、穿透里也能呼出。这些都已经验收过，行为不要动。
2. **最该先修的不是“加功能”，是 5 个体验缺口**：
   - 靠近屏幕边缘时盘会被裁掉；
   - 盘可能开在手掌底下，被手挡住；
   - 两指长按 500ms 期间没有任何反馈，老师以为没按上；
   - 两指触发没有最小间距，鬼点/两指太近可能误开；
   - 没有开关，单指书写模式下完全呼不出。
3. **功能上最大的缺口是“固定 8 格、不能换”**：没有撤销、没有清空、只有 3 个颜色，想加一个就得挤掉一个。
   最合理的解法不是硬塞，而是 **槽位数据化 + 3 个预设**（经典 / 课堂 / 编辑），编辑器后置。
4. **不建议第一步就做双环/自动场景切换。** 8 格 + 预设 + 长按子菜单已经能覆盖绝大多数需求；双环会让误选和实现复杂度都上一个台阶。
5. **推荐顺序**：
   - P0（约 1 周）：边缘夹取、长按进度、两指最小间距、开关、粘滞提示；
   - P1（约 1~2 周）：槽位数据化 + 3 预设、中央状态读数、首次/粘滞标签、出入场动画；
   - P2（约 2~4 周）：长按扇区子菜单（橡皮清空 / 更多颜色）、单指模式入口、两指轻点可选撤销；
   - P3：可视化编辑器（有数据模型之后 3~5 天）。

### 1.4 判位规则

- 死区 24 逻辑像素；锁定距离 36；跨扇区滞回 9°；
- 指针划回中心 = 取消；松在死区 = 取消；
- 触屏两指长按后如果**完全没动**就松手 = 粘滞保留 5s，可抬手再点；
- 触屏两指点按 = 直接进入粘滞。

出处：`Engine.cs:15592-15627`、`15477-15501`。

## 2. 体验缺口（按优先级）

### 2.1 盘会开出屏幕（P0，确定是 bug）

`OpenRadialPaletteFromTouch` 直接把盘心设成两指中点，**没有任何屏幕边界夹取**：

```csharp
RadialCenterX = x;
RadialCenterY = y;
```

在屏幕左/右/下边缘两指长按时，盘和下方提示条会被裁掉；下方提示条还会跑到屏幕外。
出处：`Engine.cs:15414-15433`；`Overlay.cs:5774-5789`。

**建议**：

- 盘心夹到 `[屏幕边 + R + 12, 屏幕边 - R - 12]`；
- 如果夹取导致盘心离手指中点超过约 16px，**自动进入粘滞模式**，提示“点选工具”，避免“盘挪了、方向却按手指算”的错位；
- 盘在屏幕下半部时，提示条改到盘上方。

### 2.2 盘可能开在手掌底下（P0）

两指中点在屏幕下半部时，盘正好在手掌/手腕附近，老师自己看不见。现在的粘滞模式能救，但没有任何提示。

**建议**：

- 盘心 Y 落在屏幕下方 30% 时，整体上移约 `0.5R`，并进入粘滞模式；
- 粘滞时中央读数写“点选工具”，并在盘下/盘上显示“点空白取消”。

### 2.3 两指长按 500ms 没有反馈（P0）

从两指落下到盘出现，至少 500ms（长按）+ 120ms（出盘延迟），合计 620ms；期间屏幕上什么都没有，老师很容易以为没按上而松手。

**建议**：

- 在两指中点画一个 **500ms 进度环**（或两指连线的中点小圆），随按住时间填充；
- 移动超过 8px 就取消并淡出；
- 进度满 → 盘立即出现（120ms 延迟可以保留，但此时已有反馈）。

### 2.4 两指触发没有最小间距（P0，误触风险）

`Touch.Tick` 只检查触点数量、是否移动、路径是否 ≤8px，**没有检查两指之间的距离**；两指太近、鬼点、或一根手指被报成两个点时，也可能满足条件。

**建议**：

- 两指间距至少 **40~48 逻辑像素**；
- 两指落下时间差 ≤200ms（避免一根手指先放着、第二根很久后才加入）；
- 不满足时静默不触发，不要弹提示。

出处：`Touch.cs:257-265`、`279-288`。

### 2.5 没有开关，单指模式完全没有入口（P0/P1）

- 两指轻点/长按是硬编码开启，没有设置项；误触的用户只能忍着。
- 单指书写模式把整个触摸层关掉，轮盘也跟着没了；这类用户只能记 4 个键的全局快捷键。

**建议**：

- 触摸设置里加“**两指呼出轮盘**”开关（默认开）；可分别控制轻点/长按，或一个总开关；
- 单指模式提供**独立入口**，不依赖画布手势：
  - 首选：**长按浮动小球 500ms** 呼出（鼠标/触屏都能用，不占主条）；
  - 备选：允许“两指长按只呼出轮盘”，但不启用翻页/擦除/选择；
  - 不做：主条再加一个“轮盘”按钮（破坏极简）。

### 2.6 固定 8 格，没有撤销/清空，只有 3 个颜色（P1，功能主缺口）

- 现在 8 格是写死的；`RadialSectorNames`、`RadialSectorIsColor`、`CommitRadialPalette`、`RadialHintFor`、`DrawRadialIcon` 五处都按 0..7 写死。
- 没有撤销、重做、清空、截图、白板、穿透、PPT 翻页。
- 颜色只有黑/红/蓝，主条色带其实有 8 色 + 自定义。

**不建议直接改默认排序**：V-a 是 2026-09-30 拍过板的，老师已经形成肌肉记忆。更好的做法是：

- **槽位数据化**（表驱动），默认仍是经典 8 格；
- 增加 **3 个预设**，让用户自己选，不强制改默认。

### 2.7 隐藏语义不容易发现（P1）

- “已经是笔 → 换下一色”“橡皮 → 整笔/面积”“框选 → 矩形/套索”都是重复选择才出现；
- 只有选中后盘下那一行提示会解释，新用户第一次不知道。

**建议**：

- 中央读数在**没选中时**显示当前状态，而不是笼统的“工具”：
  - “红笔”“面积擦”“荧光笔（黄）”“框选（矩形）”“激光”；
- 粘滞模式下，扇区外圈显示一次短标签（或首次使用显示 3 次后淡出）；
- 保留现在的“盘下一行提示”，不要加常显大段文字。

### 2.8 没有出入场/悬停动效（P2）

现在盘是“啪”一下出现/消失，扇区切换也是直接跳。文档里已经把它列为下一轮：淡入淡出、80ms 悬停过渡、按下轻微缩放。

**建议**：

- 120ms 淡入 + 从 0.92 缩放到 1；关闭 80ms 淡出；
- 扇区选中 80ms 过渡（填充/描边），图标 filled；
- 按下时选中扇区 0.98 缩放；
- 尊重系统“显示动画”开关（`ClientAreaAnimationOn`），关掉就直给。

### 2.9 其他边界

- **Windows Copilot+ 笔记本**：系统“两指长按”可能弹 Click to Do，和我们的两指长按冲突；学校红外大屏一般不是 Copilot+，但老师自己的笔记本可能中招。设置页/帮助里要写清楚。
- **`--radialshow` 抓屏**：本机出图是全黑（DirectComposition 层抓不到）。这是自检工具的问题，不是产品问题；可视化核对目前只能靠设计稿/实机。以后可加离屏渲染出图。

## 3. 功能优化方案

### 3.1 方案 A：槽位数据化 + 3 个预设（推荐先做）

把 8 个格子从“五处 switch”改成一张表：

```csharp
sealed record RadialSlot(
    RadialSlotKind Kind,   // Tool / Color / Action
    KeyAction Action,      // 工具或动作
    int PaletteIndex,      // 颜色槽用
    string Name,           // 中央读数 / 提示
    string Icon);          // 工具图标
```

默认表 = 现在的经典 8 格。设置里只加一个下拉：

```
呼出盘布局：经典 / 课堂 / 编辑
```

| 预设 | 8 格（北起顺时针） | 说明 |
|---|---|---|
| **经典** | 笔 · 黑 · 红 · 蓝 · 橡皮 · 框选 · 荧光笔 · 激光 | 保持现状，老用户不变 |
| **课堂** | 笔 · 黑 · 红 · 蓝 · 橡皮 · **撤销** · 荧光笔 · 激光 | 用撤销替掉框选；框选回主条 |
| **编辑** | 笔 · 红 · 橡皮 · **框选** · **撤销** · **重做** · **清空** · 激光 | 整理/改错为主；清空放角落，仍需按住确认 |

- 只做“预设”，不做每格自定义；先验证老师到底想换哪一格。
- 预设切换只影响轮盘，不影响 `Ctrl+P/I/L/E/M` 硬键位。
- 以后要做编辑器，再把表落到 `settings.json` 的 `ui.radial`，加一个 8 行下拉的简单页面即可（3~5 天），不需要拖拽盘。

**工作量**：数据化 3~5 天 + 预设/设置 2~3 天，约 **1~1.5 周**。

### 3.2 方案 B：长按扇区出子菜单（P2，解决“8 格不够”）

不增加主环格数，在扇区上做“二级动作”：

| 扇区 | 长按 500ms 后 |
|---|---|
| 橡皮 | 整笔擦 / 面积擦 / **清空当前页** |
| 颜色 | 黑 / 红 / 蓝 / 绿 / 黄 / 自定义 |
| 框选 | 矩形 / 套索 / 全选 |
| 笔 | 下一色 / 颜色面板 |

交互：划到扇区后停住 500ms → 主环淡出、子环/小条出现 → 划向子项松手；中途松手 = 普通动作；划回中心 = 取消。

**优点**：不加格子，解决“清空”和“更多颜色”。
**缺点**：多一层时间维度，容易和“犹豫”混淆；需要明显的进度环和“松手执行普通动作”的兜底。
**建议**：先只做“橡皮 → 清空”和“颜色 → 更多颜色”两个，观察使用率再扩。

### 3.3 方案 C：两指轻点 = 撤销（可选，需拍板）

现在两指轻点 = 打开粘滞轮盘。撤销是课堂高频动作，GoodNotes 等产品用两指轻点撤销。

- 如果改成撤销：轮盘仍有“两指长按”，不影响呼出；但快速开盘点选的习惯要改。
- 建议做成设置项：**两指轻点 = 打开轮盘 / 撤销 / 无**，默认保持“打开轮盘”。

### 3.4 方案 D：双环 / 场景自动切换（不建议现在做）

- 双环：外圈工具、内圈动作（撤销/重做/清空/截图），盘半径至少 120~140，遮挡更大，误选更多。
- 自动场景：PPT 时自动换成翻页盘、文档时换成翻页+清空盘——肌肉记忆会乱，且老师不一定在对应模式。
- 结论：**8 格 + 预设 + 子菜单**足够；双环等到有明确数据说“8 格不够”再做。

## 4. 建议的落地顺序

### P0：体验修复（约 1 周）

1. 盘心屏幕夹取 + 边缘自动粘滞 + 提示条上下翻转；
2. 两指长按 500ms 进度环；
3. 两指最小间距/落指时间差；
4. “两指呼出轮盘”开关；
5. 粘滞模式提示“点选工具 / 点空白取消”，超时从 5s 放宽到 8~10s（可选）。

### P1：功能与可读性（约 1~2 周）

6. 槽位数据化 + 经典/课堂/编辑 3 预设；
7. 中央读数显示当前工具/颜色/橡皮形态；
8. 首次使用或粘滞模式显示短标签（3 次后淡出）；
9. 出入场/悬停/按下动画（尊重系统动画开关）。

### P2：深度入口（约 2~4 周）

10. 长按橡皮扇区 = 清空当前页（带 0.8s 确认或二级菜单）；
11. 长按颜色扇区 = 更多颜色；
12. 单指模式：长按浮动小球呼出轮盘；
13. 两指轻点 = 撤销（设置项，默认关）。

### P3：编辑器

14. 设置页 8 行下拉 + `ui.radial` 落盘；不做拖拽盘。

## 5. 工作量与风险

| 项 | 估时 | 风险 |
|---|---|---|
| P0 体验修复 | 3~5 天 | 边缘夹取后判位要重新测；粘滞模式要测真机 |
| 槽位数据化 + 预设 | 5~8 天 | 五处 switch 改表，容易漏提示/图标 |
| 中央读数 + 标签 + 动画 | 3~5 天 | 标签可能显乱；动画要遵守系统开关 |
| 长按子菜单 | 1~2 周 | 时间维度与 marking-menu 交互冲突，需真机调 |
| 单指模式小球长按 | 2~3 天 | 与小球拖动/点按的阈值要调 |
| 双环/自动场景 | 2~3 周 | 不建议先做 |

## 6. 需要拍板

1. **功能缺口**：先加“撤销”还是“清空”？还是只做预设，让用户自己选？
2. **单指模式**：要不要“长按浮动小球”呼出轮盘？（我建议要，这是单指模式唯一的无键盘入口）
3. **两指轻点**：保持“打开轮盘”，还是提供“撤销”选项？
4. **标签**：永远不显示 / 只在粘滞模式显示 / 首次 3 次显示？
5. **预设**：经典 / 课堂 / 编辑 三个够不够？要不要 PPT 预设？
6. **边缘策略**：夹取后自动粘滞，还是只夹取、仍按手指方向判？
7. **超时**：保持 5s，还是粘滞模式放宽到 8~10s？
