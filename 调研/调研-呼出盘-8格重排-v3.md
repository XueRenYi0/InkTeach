# 调研：呼出盘 8 格重排 v3（红笔居中 + 四角常用）

- 日期：2026-10-25
- 状态：**已实现**（2026-10-25；`--radialtest` 待最后统一跑）
- 用户方向：
  - 现在“笔”占了 4 格（笔 / 黑 / 红 / 蓝），太多；
  - 北 = **红笔，颜色始终不变**；
  - 东 / 西 = **下一色 / 上一色**；
  - 中央圆盘 = **显示当前笔颜色的圆圈**；
  - 其余热点：橡皮、清屏、荧光笔、框选，由我排布。
- 基础：`调研-呼出盘-双层同心圆.md` 的双圈方案**不做**；本版只改现有单环 8 格的内容。

## 0. 结论

推荐这一版：

```
              红笔
        撤销          荧光笔
    上一色              下一色
        清屏          框选
              橡皮
```

- **笔从 4 格降到 3 格**（北红笔 + 东下一色 + 西上一色）；
- **十字轴**：上写（红笔）、下擦（橡皮）、左退色、右进色；
- **上半 = 写**（红笔、荧光笔）；**下半 = 处理墨迹**（橡皮、清屏、框选）；
- **左上 = 撤销**（通用“回退”位）；**左下 = 清屏**（危险动作，角落 + 按住 0.8s）；
- 中央不再放文字，改成**当前颜色的圆**；
- 激光、重做、更多不上盘，回主条 / 快捷键。

## 1. 8 格明细

| 扇区 | 位置 | 内容 | 点一下 / 划到松手 | 已经是它时 |
|---|---|---|---|---|
| 0 | 北 | **红笔** | 切到笔 + 红色（永远是红） | 保持红笔，不循环换色 |
| 1 | 东北 | **荧光笔** | 切荧光笔 | 换下一个荧光色 |
| 2 | 东 | **下一色** | 切到笔 + 下一个颜色 | — |
| 3 | 东南 | **框选** | 切框选 | 矩形 ⇄ 套索 |
| 4 | 南 | **橡皮** | 切橡皮（默认面积擦） | 面积擦 ⇄ 整笔擦 |
| 5 | 西南 | **清屏** | 按住 0.8s 清空当前页 | — |
| 6 | 西 | **上一色** | 切到笔 + 上一个颜色 | — |
| 7 | 西北 | **撤销** | 撤销一步 | — |

### 为什么这么排

1. **上下轴 = 写 / 擦**：红笔和橡皮是课堂一进一出的两个最高频动作，放在最顺手的正上和正下。
2. **左右轴 = 翻色**：符合“右进左退”的直觉；而且按现有 `PenBand` 顺序，红的左边正好是黑、右边正好是蓝——最常用的三色形成 1 步三角。
3. **上半 = 写**：红笔 + 荧光笔，都是“往上加墨”。
4. **下半 = 处理**：橡皮 + 框选 + 清屏，都是“对已有墨迹动手”。
5. **左上 = 撤销**：和浏览器/绘图软件一致，形成肌肉记忆。
6. **左下 = 清屏**：破坏性最大，放角落、离笔最远，再加 0.8s 长按，三重保险。
7. **框选放右下**：右手向下偏右最顺，且和橡皮相邻（擦一块 ⇄ 选一块）。

## 2. 中央：空心色环 + 当前功能图标

2026-10-25 二次拍板：中央不再是实心色圆，改成**空心色环 + 20px 功能图标**。

| 项 | 设计 |
|---|---|
| 色环 | 外径 23.5、内沿 19、线宽 4.5；底环比彩环宽 2px（白笔/浅色也有轮廓） |
| 色带过渡 | 色环外 3 圈同色淡晕（alpha 0.12 / 0.06 / 0.04，半径 27.5 / 31.5 / 35.5），把“色环 → 盘面”的硬边化开 |
| 中央底 | **和未选中扇格同色（Hover）**，不再露出盘底 Panel——深色主题下那圈“透明黑”就是它 |
| 色环颜色 | 当前落笔颜色；划到东/西（翻色）时预览目标色；划到北（红笔）时固定红；荧光笔用荧光色 |
| 中心图标 | 20px regular；**没划到扇区 = 当前实际工具；划到扇区 = 该扇区图标（实时预览）** |
| 橡皮 / 框选 | 当前工具是橡皮/框选时，色环显示“上次笔色”，45% 透明 |
| 文字 | **中央不放文字**；功能名走盘下那行提示 |

为什么用图标不用汉字：

- 色环内径只有约 38px，两个字最多 14~15px，投影上笔画会糊；一个字能 20px，但“荧/擦/选”需要二次理解；
- 主条、面板、轮盘外圈都是 Fluent 图标，中央用汉字会风格断裂；
- 图标靠形状记忆，熟练后不用读字。

“中央和外圈图标重复”不是问题：中央 20px regular 是“当前状态”，外圈 24px、选中 filled 是“可选菜单”，位置/大小/形态三层区分。

- 判位不变：中央死区仍是 24 逻辑像素，色环外径 23.5，整个环都在死区里；
- 圆盘半径、扇格、图标环、缝、投影全部不变（R96 / R40 / R68 / 2°）。

## 3. 上一色 / 下一色

### 3.1 顺序

直接沿用 `InkPalette.PenBand`（不动主条色带）：

```
黑 → 红 → 蓝 → 绿 → 黄 → 橙 → 紫 → 白 → 黑 …
```

- 当前红：西（上一色）= **黑**，东（下一色）= **蓝**；
- 当前蓝：西 = 红，东 = 绿；
- 当前黑：西 = 白，东 = 红。

> 红的两边正好是黑和蓝，这是 `PenBand` 现有顺序的巧合，也是最好的结果——最常用的三色都在 1 步内。

### 3.2 西 / 东格显示什么

不画固定箭头，画**“将要变成的那支笔”**：

- 西格 = 上一色的彩笔图标 + 左下小箭头；
- 东格 = 下一色的彩笔图标 + 右下小箭头；
- 当前色变化时，两格的颜色实时跟着变。

这样一眼能看出“往左是黑、往右是蓝”，不用记顺序。

### 3.3 边界

- 当前色不在 `PenBand`（主条自定义色）：上一色从白开始、下一色从黑开始；
- 当前工具不是笔：点上一色/下一色 = **切到笔 + 换色**（和现在的颜色格一致）；
- 荧光笔不共用这条轴：荧光笔的颜色仍在“点荧光笔扇区循环”，以后要扩再说。

## 4. 清屏：按住 0.8 秒

清屏是唯一带破坏性的扇区，不能“划到松手就清”：

```
划到“清屏” → 停住
  ↓
扇格内画 0.8s 进度环
  ↓
满了 → 自动执行（只清当前页）→ 盘关闭
未满松手 → 不执行，盘下提示“按住 0.8 秒清空”
```

- 语义和橡皮带里的“清空”完全一致：**只清当前页**（白板当前屏 / PPT 当前页 / 文档当前页）；
- 整份清空仍然只在翻页条菜单里；
- 0.8s 和现有橡皮带保持一致，不另造一个时长；
- 进度环画在西南扇格内沿，红色，满了闪一下再执行。

## 5. 被挤出的功能

| 功能 | 去处 | 理由 |
|---|---|---|
| 激光笔 | 主条 / `Ctrl+L` | 讲题指屏可用手指或笔尖替代；轮盘 8 格更值钱 |
| 重做 | 主条 / `Ctrl+Y` | 频率远低于撤销 |

| 更多（截图/白板/穿透/翻页/全选） | 主条 / 快捷键 | 不做外圈，轮盘只保留 8 个高频直达 |

> 如果老师强烈要求激光留在盘里：把“框选”（东南）换成激光，框选回主条。这是一行数据的事，先按撤销 + 框选做。
