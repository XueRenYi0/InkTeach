# InkTeach 短视频 / 公众号宣传操作单

> 目标不是"把 60 个功能讲全"，而是让一位老师在 **15 秒内**看懂：
> **"上课讲 PPT，不用切白板，直接在 PPT 上写。"**
> 所有视频都围绕这一条，功能只作为证据出现。

## 一、先定一条主线

**一句话卖点**：InkTeach 是一层透明批注层，PPT / WPS / PDF / 图片上都能直接写，写完点一下把鼠标还给原软件。

**三条最强的画面**（按"外行一眼看懂"排序）：

1. PPT 放映中直接写 + 圈重点，不切软件。
2. 手写一个歪圆，停 0.4 秒变规整圆；拖图形自动对齐。
3. 激光笔指重点 / PDF 试卷上批注。

> 不要用"22 种图形""Direct2D 增量渲染"做开头。这些放在中段或公众号文章里。

## 二、抖音：30–40 秒竖屏

### 规格

- 1080×1920，9:16，30/60fps；成片 25–40 秒。
- 前 2 秒必须出现"PPT 上直接写"的画面，不要放 Logo 动画。
- 全程大字幕；口播可有可无，但有真人声更可信。
- 结尾 3 秒只留一句 CTA + 软件名，不放长网址。

### 30 秒分镜（可直接照拍）

| 时间 | 画面 | 口播 / 字幕 |
|---|---|---|
| 0–3s | PPT 放映画面，笔直接落在幻灯片上画圈 | "上课讲 PPT，最烦的是切来切去？" |
| 3–7s | 点一下穿透，鼠标回到 PPT；再按全局键拉回批注 | "这层透明的板，直接盖在 PPT 上。" |
| 7–12s | 手写歪圆 → 停住 → 变规整圆 → 拖动 | "手写一个圆，停 0.4 秒，它自己变规整。" |
| 12–17s | 再画一个矩形，拖到另一个图形旁自动对齐 | "拖图形会自动对齐，不用靠眼估。" |
| 17–22s | PDF 试卷翻页 + 批注；或激光笔圈重点 | "PDF、图片、试卷，也能一页一页批。" |
| 22–27s | 呼出盘：按住全局键，划向笔/激光/橡皮 | "工具不用找，按住一个键，划一下。" |
| 27–32s | 回到 PPT 完整画面 + 软件名/官网 | "开源免费，Windows 10/11，搜 InkTeach。" |

### 标题 / 封面

标题优先用"老师的痛点"，不要用产品名开头：

- "上课讲 PPT，别再切白板了"
- "PPT 上直接写，写完鼠标还能还给 PPT"
- "一个歪圆，停 0.4 秒自己变圆"
- "试卷 PDF 也能直接批注了"
- "开源免费的课堂批注工具，Windows 就能用"

封面：左半边 PPT、右半边手写批注，中间大字 **"PPT 上直接写"**；右下角小字 `InkTeach · 开源免费`。

- 标签：`#教师 #PPT #课堂互动 #教学工具 #开源软件 #Windows技巧`，不要堆无关大标签。
- 发布时间先测：工作日 19:00–21:30，或早上 6:30–8:00；连续发 2 周再判断。

### 第一周发什么（5 条）

1. 30 秒主片：PPT 上直接写（最重要，置顶）。
2. 15 秒单点：歪圆停 0.4 秒变圆。
3. 20 秒单点：PPT 放映中圈重点 + 激光笔。
4. 25 秒单点：PDF 试卷批注 + 翻页。
5. 20 秒单点：对象吸附 / 拖图形自动对齐。

## 三、微信公众号：60–90 秒 + 图文

公众号不是"把抖音视频搬过去"，而是让老师**看完就会装、会用**。

### 文章结构

1. **标题**：`上课讲 PPT，别再切白板了：一层透明批注，直接写在幻灯片上`
2. **开头 100 字**：描述痛点（切白板、找不到笔、写完还要切回去）。
3. **15 秒 GIF/视频**：直接放主片，前三秒就是 PPT 上写。
4. **三个使用场景**：
   - PPT 放映：圈重点、写推导、激光笔。
   - 试卷/PDF：一页一页批注，翻页不丢。
   - 网课/会议：任意软件上写，写完把鼠标还回去。
5. **怎么装**：安装包 / 绿色版二选一，Windows 10/11，不需要装 .NET。
6. **更新说明**：9.2.1 激光笔去光晕、修残影；9.2.0 对象吸附。
7. **结尾**：开源 GPL-3.0；官网/GitHub/GitCode；"阅读原文"放官网。

### 视频号

- 用抖音同一版竖屏主片，标题改成更适合微信的：`PPT 上直接写板书，不用切软件`.
- 视频号简介放"开源免费 / Windows"，不要放外链。
- 公众号文章插入视频号卡片；文章末尾放官网二维码。

## 四、录制设置（一次录好，抖音/公众号都能用）

- OBS / Windows 游戏栏，1920×1080 或 2560×1440，60fps；关闭通知、微信、QQ、桌面图标。
- 准备一份干净的 16:9 PPT：白底、大标题、留出右侧空白给批注。
- 先录 16:9 母版，再在剪映里做 9:16：画面放大到主要操作区，顶部放标题、底部放字幕；不要硬裁掉工具带。
- 录音用手机/耳麦都行，离嘴 15–20cm；环境安静比设备重要。
- 每个动作拍 2 遍：一遍正常速度，一遍慢一点给特写；剪辑时用 1.0–1.25 倍速。
- BGM 用剪映曲库中可商用/无版权风险的曲子，音量压到人声的 15–20%。

## 五、剪辑与封面

- 剪映：9:16 项目；字幕用"关键词大字"，不要整段小字。
- 每个功能点 4–6 秒，超过 8 秒必须切镜头/放大。
- 转场只用硬切/轻微缩放，别用花哨转场。
- 封面三行以内：`PPT 上直接写` / `不用切白板` / `开源免费`。
- 片尾统一：软件名 + "Windows 10/11 · 免装 .NET" + 官网。

## 六、看什么数据

抖音重点看：**3 秒留存、5 秒留存、平均播放时长、收藏/转发、评论"怎么下载"的数量**。
公众号重点看：**打开率、读完率、视频播放、阅读原文点击、后台回复关键词**。
先连续发 6–8 条再判断方向；不要一条数据不好就改定位。

## 七、合规与边界

- 不展示学生姓名、人脸、成绩等个人信息；演示用虚拟姓名/空白试卷。
- 不写"提分神器""全网最强""替代 PowerPoint"等绝对化/误导表述。
- 不把开源软件说成"免费无限制"：GPL-3.0，商用/闭源嵌入需看许可证或联系作者。
- 抖音视频内不放长外链/二维码；公众号"阅读原文"放官网，二维码放文末。
- 不使用的字体/音乐/素材要有商用授权；PPT 模板用自制或明确可商用的。
