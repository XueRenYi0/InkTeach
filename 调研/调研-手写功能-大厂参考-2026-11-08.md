# 调研：Apple / Google / 平板手写功能里，哪些对 InkTeach 最有帮助

日期：2026-11-08
状态：**只做调研，不改代码**

---

## 一、结论先行

按“对课堂批注的直接帮助 / 实现成本 / 风险”排序，最值得做的 8 件事：

1. **手写公式识别 → 可编辑公式 → 函数图像 + 参数滑杆**（Apple Math Notes / OneNote Math Assistant / GoodNotes Math Assist）
2. **图形条“常用在外、长尾在内”**：外侧 6–8 个常用图形，`⋯` 进完整图形库；默认显示“常用”而不是“全部”（Apple Freeform / GoodNotes Elements）
3. **涂划删除（scratch-out）**：笔不换工具，涂掉就删；可撤销（Apple Notes / OneNote / GoodNotes）
4. **画完停住自动变标准图形**（OneNote Draw and Hold / GoodNotes Draw and Hold；我们已有“停顿成型”，可统一）
5. **手写拉直 / 整理**：拉直基线、均分字距、修字形（Apple Smart Script / Samsung Handwriting Help）
6. **手写转文字 / 手写搜索**：选中转文字、整页搜索（Apple / GoodNotes / Notability / Samsung）
7. **选中内容存成“元素/贴纸”再复用**（GoodNotes Elements / Notability Stickers；我们已有收藏，可统一语义）
8. **数学解题步骤 / 分步讲解**（OneNote Math Assistant / GoodNotes AI / Samsung Math Solver）——价值高，但准确性和课堂节奏风险最大，放后面。

> 一句话：**先做“不改变老师书写习惯”的增强（图形条、涂划删除、拉直、手写搜索），再做“公式→图像”这种高价值但高风险的数学能力。**

## 二、调研范围

看的是 2026-11 时点各产品公开支持文档和官方发布说明，重点看“手写 + 教学”而不是通用笔记：

| 产品 | 重点看什么 |
|---|---|
| Apple Notes（iPadOS 18/26） | Smart Script、Math Notes、手写搜索、Smart Selection、涂划删除 |

## 三、各家真正值得看的功能

### 3.1 Apple Notes：Smart Script + Math Notes

**Smart Script（iPadOS 18）**

- 手写实时平滑、拉直；
- 手写拼写检查，错误用蓝点标出，改正后仍保持本人笔迹风格；
- 选中手写后可 **Refine（整理）/ Straighten（拉直）**；
- 可以“插入空格 / 划线删除 / 把打好的文字粘贴成手写”；
- 手写段落会 reflow（重排）；
- 涂划并按住 = 删除手写；
- Smart Selection：双击选词、三击选句，和文字一样操作。

**Math Notes（Notes / Calculator）**

- 手写或输入表达式，写完等号立即出结果；
- 变量：`x=10`，后续表达式/图像跟着更新；
- 方程可插入 **2D/3D 函数图像**；
- 多个方程可以叠加在同一张图上；
- 图上可缩放、平移、改大小；
- 参数可以用 Apple Pencil 悬停出现 scrubber 左右调，图像实时更新；
- Math Notes 自动同步到 Notes 的 Math Notes 文件夹。

**对我们的启发**

- “写完函数 → 识别 → 出图”不是单纯 OCR，而是 **公式对象 + 图像对象 + 参数对象** 三件套；
- 识别一定要有“确认/修正”步骤，不能静默算错；
- 参数滑杆比“重新输入公式”更适合课堂演示。

### 3.2 Apple Freeform：图形建议 + Content Hub

- 点“添加图形”先给 **suggestions（建议）**，不是一上来铺几百个；
- 点 **Browse Content Hub** 才进完整图形库，按分类浏览、可搜索；
- 最近插入的图形会进入 suggestions，可 **Reset Suggestions** 清空；
- 图形可以改形状、拆分/合并、连接线、做流程图；
- 手写可以 **Snap to Shape**（画完自动变标准形状）；
- 手写文字可搜索、选中、复制、拉直、翻译；
- Freeform 也支持手写数学的 Math Results。

**对我们的启发**

- 这就是用户说的“常用在外、长尾收进 `⋯`”的成熟做法；
- 关键不是“藏起来”，而是 **建议 + 完整库 + 搜索 + 最近使用** 四件套；
- 图形多不是问题，首屏铺满才是问题。

### 3.3 Microsoft OneNote：Math Assistant + Ink Gestures

- **Ink to Math**：手写公式转成可编辑公式；
- **Math Assistant**：
  - 解方程、展开/因式分解、求导/积分、验证；
  - **Graph in 2D / Graph Both Sides in 2D / Graph Inequality**；
  - 参数 `a/b` 用 +/- 调整，图像实时变；
  - 显示零点、截距、极值等 key features；
  - 提供分步解法（多种方法）。
- **Ink to Shape / Draw and Hold**：画完停住，变标准图形，可继续拖动改大小/旋转；
- **Scratch-out**：用笔涂划掉墨迹即删除，可撤销；
- **Ink to Text Pen**：划掉删字、划线选字、插入/覆盖、拆词/合词；
- 多击选墨：词 → 行 → 段 → 整页；
- Ink Replay：回放整页书写过程。

**对我们的启发**

- “涂划删除 + 停住变图形”是最不影响书写流的两条手势；
- 数学助手的分步解法对课堂很有价值，但必须允许老师先确认识别结果；
- Key features（零点/极值）比单纯画图更适合讲题。

### 3.4 GoodNotes：Math Assist + Shape Tool + Elements

- **Math Assist**：
  - 手写带等号的公式，识别后 **蓝色发光**；
  - 点开发光区域选择解法，答案以手写形式出现；
  - 变量可改，结果实时更新；
  - 可编辑识别结果的 **LaTeX**；
  - 支持二次/三次/四次方程、方程组、三角、极限、微分、积分等（不支持矩阵、微分方程、几何、不等式）。
- **Math Conversion**：手写公式转排版公式 / LaTeX / 图片；
- **Shape Tool / AutoShape**：预定义图形 + 手绘自动修正；画完停住可调大小角度；
- **Elements**：把常用图形、公式、手写、文本框、图表存成集合，跨笔记复用。

**对我们的启发**

- Math Assist 的“蓝色发光 + 点开菜单”是很轻的入口，不打断书写；
- 识别后直接显示 LaTeX 修正入口，比“重新写一遍”友好；
- Elements 和我们“收藏”很接近，可以统一成“元素/收藏”一套心智。

### 3.5 Notability：数学转换 + 手写搜索

- 选中手写 → Convert → Text / Math；
- 数学公式转成高分辨率可缩放图像，保留原颜色；
- 转换后可以编辑底层 LaTeX；
- 支持手写搜索、分组墨迹、把一组墨迹存成贴纸；
- 支持多种手写识别语言（含简体中文）。

**对我们的启发**

- “转换后仍可编辑 LaTeX”是底线；
- 收藏/贴纸可以复用我们已有的收藏面板，不必另造一套。

### 3.6 Samsung Notes：Handwriting Help + Math Solver

- **Handwriting Help**：
  - 拉直、字母对齐、均匀字距、修正字形；
  - 可开关，支持笔模式，不支持荧光笔模式。
- **Convert to text**：手写转文字，可复制/添加。
- **Math Solver**：
  - 写等式并以等号结尾，Galaxy AI 即时解；
  - 设备端运行、不需要联网，但要登录 Samsung 账户；
  - 识别不清会算错，官方明确提示要自行核对。
- 选中可移动/缩放/旋转/置前/置后。

**对我们的启发**

- “整理手写”最好做成 **可选、可预览、可撤销**，不要默认改老师笔迹；
- 数学识别要明确“可能识别错”，提供修正入口。

### 3.7 Google Keep：基础绘图，不是高级参考

- 画笔、马克笔、荧光笔、橡皮、选择；
- 可调颜色/粗细；
- 可在图片上画；
- 新手写笔记格式在演进，但公开能力仍以简单绘图为主；
- 没有看到 Apple/OneNote 级别的公式识别、函数图像、参数滑杆、手写整理。

**结论**

- Google Keep 可参考“工具简单、入口少”，**不适合**作为数学/手写增强的主要参考；
- Google 系更值得看的是系统级手写输入（Gboard/Android 手写），但那是输入法层，不是课堂批注层。

## 四、InkTeach 现在已经有什么

避免重复造轮子，先对齐现状：

| 能力 | 现状 |
|---|---|
| 图形识别 | 有“停顿成型”（`DwellShape`），可把一笔变成标准图形，可撤销回手绘 |
| 图形库 | 39 张卡，分“全部 / 常用 / 曲线 / 立体”，有横向/竖向面板、缩放、滚动 |
| 选择/移动/缩放/旋转 | 已有完整选择手势、操作条、层级/颜色/字号/锁定/复制/删除 |
| 文本/公式渲染 | 文本框支持 LaTeX 公式渲染（MathImage），AI 题卡支持公式行 |
| 手写识别 | 有 AI 手写 OCR / 识别到文本框（`HandwritingOptimize` / `OcrClient`） |
| 收藏 | 有收藏/分类/回收站/拖拽插入，接近 GoodNotes Elements |
| 课堂 | 白板、PPT/文档批注、回放、计时/点名、激光、截图 |
| 输入 | 页面输入 `TextInputService`，画布文本框 RichEdit |

**主要缺口**

1. 没有“选中手写 → 识别为公式 → 可编辑 LaTeX”的完整动作；
2. 没有函数图像对象（2D/3D）、参数滑杆、多图叠加；
3. 图形库默认“全部”39 张，首屏太长，没有“最近使用/使用频率”；
4. 没有涂划删除、手写拉直/整理、手写搜索；
5. 收藏和“元素/贴纸”语义没有打通。

## 五、最值得做的功能（按优先级）

### P0：图形条“常用在外、长尾在内”（1–2 周）

**参考**：Apple Freeform 的 suggestions + Content Hub；GoodNotes Elements。

**做法**

- 主图形条只放 **6–8 个常用图形**（建议：直线、矩形、圆/椭圆、三角形、箭头、坐标系、收藏的图形）；最后固定一个 `⋯`。
- `⋯` 打开完整图形库，保留现有“全部 / 常用 / 曲线 / 立体”，后续加“物理”等分类。
- 完整库顶部增加 **最近使用** / **常用** 两行；长按可“钉到外侧”。
- 默认分类从“全部”改为“常用”；“全部”只在完整库里出现。
- 外侧图形数量固定，不因为新增图形变长；新增图形先进入完整库，常用后再上外侧。

**为什么先做**

- 直接解决“图形条太长”的体感；
- 不碰数学识别，风险低；
- 数据结构已经现成（`ShapeCatalog` / `ShapeCategoryInfo`），主要是入口和排序。

**验收**

- 39 张卡全部可达；
- 外侧条长度固定；
- 最近使用会更新；
- 新增“物理”分类不影响外侧条长度。

---

### P0/P1：手写公式 → 公式对象 → 函数图像 + 参数滑杆（2–4 周）

**参考**：Apple Math Notes、OneNote Math Assistant、GoodNotes Math Assist。

**推荐流程**

1. 选中手写公式 → 操作条出现 **“识别为公式”**（不是自动弹窗，避免误识别）；
2. 识别后显示 **确认/修正**：
   - 显示识别出的 LaTeX；
   - 可逐符号修正（参考 OneNote “Fix it”）；
   - 可编辑完整 LaTeX（参考 GoodNotes / Notability）；
3. 确认后生成 **公式对象**（不是图片）：
   - 可选中、移动、缩放、改色；
   - 双击可回到 LaTeX 编辑；
4. 公式对象上出现 **“画图”**：
   - 解析 `y = f(x)`，生成 2D 图像对象；
   - 支持多公式叠加；
   - 参数（a/b/k…）出现滑杆，拖动实时更新；
   - 显示零点/截距/极值等 key features（可后做）。
5. 图像对象可移动/缩放/导出，不进画布墨迹层，避免被橡皮误擦。

**关键取舍**

- **不自动把每个等号都识别**：老师写的内容不全是给机器算的；必须“选中 → 识别”。
- **不静默算错**：识别结果必须可见、可改。
- **离线优先还是云优先**：Apple/Samsung 走设备端；OneNote/GoodNotes 走云/AI。我们已有云 OCR，建议：
  - 默认云识别（能力更强）；
  - 提供“仅本地/不联网”开关；
  - 识别结果不自动上传，除非用户点“识别”。
- **2D 先做，3D 后做**：3D 图像的交互/性能/课堂价值都更复杂。

**验收**

- 手写 `y=x^2`、`y=ax+b`、`sin(x)` 可识别、可修正、可出图；
- 参数滑杆拖动，图像实时变化；
- 一步撤销回到原手写；
- 断网时给出明确提示，不偷偷失败。

---

### P1：涂划删除（1 周内）

**参考**：Apple Notes、OneNote、GoodNotes（Scribble to Erase）。

**做法**

- 笔工具下，快速画锯齿/圈状涂划覆盖墨迹 → 删除被覆盖部分；
- 删除后 1 步撤销可恢复“墨迹 + 涂划”；
- 只在“覆盖足够多”时触发，避免正常连笔误删；
- 可设置里关闭；
- 荧光笔/激光不触发（参考 Samsung 的 Handwriting Help 不支持荧光笔）。

**风险**

- 误触发是最大问题；建议先做“涂划后停 150–200ms 再删”，给老师反应时间，或只删完全被覆盖的笔画。

---

### P1：手写拉直 / 整理（1–2 周）

**参考**：Apple Smart Script（Refine/Straighten）、Samsung Handwriting Help。

**做法**

- 选中手写 → “整理”：
  - 拉直基线；
  - 均匀字距；
  - 可选“修字形”（更激进，默认关）；
- 先预览，确认后才替换；一步撤销回原手写；
- 不改变笔迹颜色/粗细/风格，只改位置和角度。

**为什么**

- 课堂板书经常越写越斜；
- 比“识别成文字”更保留老师个人风格；
- 风险可控，适合先做。

---

### P1/P2：手写搜索 / 转文字（2–3 周）

**参考**：Apple Notes/Freeform、GoodNotes、Notability、Samsung。

**做法**

- 选中手写 → “转为文字”（保留原手写，复制文字到剪贴板/文本框）；
- 整页/整本手写搜索：
  - 先做当前页/当前板书；
  - 再做历史板书索引；
- 中文优先，英文/公式后续；
- 识别失败给出“无法识别”，不要瞎猜。

**风险**

- 大量手写索引的内存/耗时；
- 中文连笔识别准确率；
- 隐私（是否上传）。

---

### P2：元素 / 贴纸（复用现有收藏）

**参考**：GoodNotes Elements、Notability Stickers、Apple Freeform。

**做法**

- 把“收藏”明确成“元素库”：
  - 选中墨迹/公式/图像/文本框 → 收藏；
  - 分类、最近使用、拖到画布；
- 常用元素可以钉到图形条外侧（和图形共用同一套“常用在外”规则）；
- 不新造第二套“贴纸”概念。

---

### P2：数学分步解题（4 周+，谨慎）

**参考**：OneNote Math Assistant、GoodNotes AI、Samsung Math Solver。

**价值**

- 讲题时能直接展示“怎么解”；
- 对教师备课/学生自学都强。

**风险**

- 识别错 → 解法全错；
- 不同教材/方法不一致；
- 课堂节奏：老师可能只想看结果，不想看长步骤；
- 依赖云 AI/费用/隐私。

**建议**

- 只做“可选入口”，默认不自动弹；
- 先做“结果 + 关键特征”，分步解法后置；
- 必须显示“AI 生成，请核对”。

## 六、不建议照搬的功能

| 功能 | 为什么不做/后做 |
|---|---|
| Freeform 无限画布 + 多人协作 | 我们是课堂批注/白板，不是通用协作白板；协作会带来账号/同步/权限大工程 |
| Apple 的“粘贴文字变手写” | 课堂价值低，且需要个人笔迹模型；先不做 |
| 手写拼写检查 | 中文课堂价值有限，英文/公式场景少；后置 |
| 每写一个等号就自动算 | 会打断书写、误识别；必须“选中 → 识别” |
| 3D 函数图像 | 交互/性能/课堂使用频率都低；2D 稳定后再评估 |
| Google Keep 式简单绘图 | 我们已有更完整的工具，不需要降级 |
| 把所有图形都放在外侧 | 正是当前问题；用“常用 + 更多”解决 |

## 七、框架层建议（不写代码，只定接口）

如果这些功能要做，建议不要继续往 `FullUi` / `Engine` 里硬编码，而是按现有“薄管理层”扩展：

1. **`SelectionAction` 注册表**
   - 选中后在操作条/`⋯`里显示哪些动作：识别公式、整理、转文字、收藏、画图；
   - 新功能只注册动作，不改选择条布局；
   - 操作条按宽度决定显示几个，其余进 `⋯`（和图形条同一规则）。

2. **`MathObject` 模型**
   - 字段：LaTeX、原始手写引用、识别置信度、图像参数；
   - 渲染与模型分离：公式渲染、图像绘制、参数滑杆各自独立；
   - 这样 2D/3D、多公式叠加都能复用。

3. **`InkGesture` 路由**
   - 涂划删除、画完停住、圈选、划线选字都作为“手势候选”；
   - 先收集，再判定，最后可撤销；
   - 避免每个手势写一套 `if`。

4. **`ShapeCatalog` 数据化扩展**
   - 分类、常用、最近、钉住、使用计数；
   - 外侧条只读“常用/钉住”；
   - 新增“物理”只是加数据，不需要改绘制/命中。

5. **`HandwritingRecognition` 服务**
   - 本地/云可切换；
   - 统一的“识别 → 确认 → 修正 → 生成对象”流程；
   - 不要每个功能各接一套 OCR。

6. **脏区/浮层复用**
   - 公式图像、参数面板、图形库都是浮层，继续用 `OverlayLayerManager` / `FloatingDirtyPad`；
   - 不再出现“拖动留虚影”这类问题。

## 八、建议的分阶段路线

| 阶段 | 内容 | 预估 | 风险 |
|---|---|---|---|
| 1 | 图形条常用 6–8 个 + `⋯` 完整库；默认“常用”；最近使用 | 1–2 周 | 低 |
| 2 | 涂划删除 + 拉直/整理（预览 + 撤销） | 1–2 周 | 中 |
| 3 | 手写公式识别 → LaTeX 修正 → 公式对象 | 2–3 周 | 中高 |
| 4 | 2D 函数图像 + 参数滑杆 + 多图叠加 | 2–3 周 | 高 |
| 5 | 手写搜索 / 转文字 / 元素库统一 | 2–3 周 | 中 |
| 6 | 分步解题 / 3D 图像 / 音频同步 | 后续 | 高 |

**建议先做 1 + 2**：不依赖 AI、风险低、立刻改善课堂手感；数学图像单独立项，不要和图形条混在一起做。
