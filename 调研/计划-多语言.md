# 多语言（i18n）目标与架构（2026-11-13）

> 目标：让 InkTeach 能面向国际用户，**安装器可选语言、软件内可设语言**；
> 用户看得到的文案走统一语言表；日志/自检/代码注释不翻译。
>
> 本文件是长期目标，不是一次性清单。新文案先走 `Loc`，不要再把中文硬编码进
> 几万行的 `FullUi.cs` / `Engine.cs` 里。

---

## 一、目标语言（冻结：10 个，不再新增）

> 用户 2026-11-13 定：**就这 10 个，不再扩语言**；后续只完善这 10 个的覆盖与质量。
> 加语言是产品决策，不是技术顺手；没有明确需求不要再往 `All` 里加。

| 代码 | 语言 | 说明 |
|---|---|---|
| `zh-CN` | 简体中文 | 源语言，直接返回源文 |
| `en` | English | 回退语言，必须最完整 |
| `ja` | 日本語 | `Yu Gothic UI` / `ja-JP` |
| `ko` | 한국어 | `Malgun Gothic` |
| `de` | Deutsch | |
| `fr` | Français | |
| `es` | Español | |
| `pt-BR` | Português (Brasil) | |
| `ru` | Русский | |
| `it` | Italiano | |

**范围外（本目标不做）：**

- 阿拉伯语、希伯来语等 **RTL**、泰语/印地语等复杂文字、繁体中文、其他小语种。
- 不是“永远不做”，是**不在这一轮目标内**；以后要做单独立项，不要顺手加进 `Loc.All`。

## 二、代码结构（模块化，避免继续堆大文件）

```
src/InkLocalization/                 ← 独立工程，引擎/界面/宿主共用
  InkLocalization.csproj
  Loc.cs                             ← 唯一语言入口：Tr / T / FontFamily / LocaleName / 语言列表
  Locales/
    en/core.json                     ← 按语言分目录
    en/help.json                     ← 以后按领域拆，加载器自动合并
    en/dialogs.json
    ja/core.json
    de/core.json
    ...
```

- 所有 JSON 都是 `EmbeddedResource`，**不用 resx / satellite assemblies / 反射**：
  当前默认 NativeAOT 单 exe，satellite 资源在单文件/AOT 下要额外验证；
  `Assembly.GetManifestResourceStream` + `JsonDocument` 更稳。
- 每条文案的结构：
  ```json
  { "strings": { "中文源文": "Translation" } }
  ```
- 用**中文源文当 key**（gettext 风格）的理由：
  - 现有 UI 是中文硬编码，迁移时只需在绘制入口查表，不用先给几千条文案起名；
  - 翻译文件直接看到源文，译者/AI 不用来回跳代码；
  - 中文源文一改，旧翻译自然失效并回退，不会把错译文挂到新文案上。
- 如果要语义 key，后续可在 JSON 增加 `keys` 段，`Loc.T` 的调用方式不变。

### 文字入口

- `InkUi/Widgets.cs`：`Text` / `TextLeftMiddle` / `Measure` / `LineHeight` 统一过 `Loc.Tr`，
  字体用 `Loc.FontFamily`，locale 用 `Loc.LocaleName`，行高样本用 `Loc.SampleText`。
  **UI 自绘文案只需要走 Widgets，不需要逐条改调用点。**
- `InkEngine/Overlay.cs`：Toast、Tooltip、UI 文字格式走 `Loc.Tr` / `Loc.FontFamily`；
  用户内容（文本框、图片、AI 卡正文）不翻译。
- `InkEngine/ToolNames.cs`：工具名出口统一 `Loc.Tr`。
- 文件对话框过滤器：`Export.cs` / `ImageFile.cs` 改成运行时 `Loc.Tr`，不再用中文 const。
- 引擎 `MessageBox` / 更新 / 隐私 / 错误提示：逐步改成 `Loc.T`；这是下一阶段。

## 三、语言选择与安装器

### 软件内

- `ui.lang` 存于 `%APPDATA%\InkTeach\settings.json` 的 `[ui]` 段：
  `system` / `en` / `zh-CN` / `ja` / …。
- 设置 → 常规 → **语言**：**下拉选择**（参考 WinUI 3 ComboBox flyout），11 项 =
  “跟随系统” + 10 种语言；当前项打勾，点外面只收起。选中只落 `ui.lang`，
  底部「重启以应用」才调用 `Restart()`；因为文字格式、布局、帮助页、系统对话框
  都按启动语言建，所以不做进程内热切换。
- 命令行：`--lang system|en|zh-CN|ja|ko|de|fr|es|pt-BR|ru|it`，本次运行覆盖设置，
  用于截图/自检/对照。
- 优先级：`--lang` > `ui.lang` > 安装器 `install-language.txt` > Windows UI 语言 > English。

### 安装器（Inno Setup）

- `[Languages]` 已有中文/英文，新增日/韩/德/法/西/巴葡/俄/意（官方 `.isl`）。
- `ShowLanguageDialog=yes`：安装时显式选择；`UsePreviousLanguage=no` 不沿用上一次。
- 安装完成写 `%APPDATA%\InkTeach\install-language.txt`（`ActiveLanguage`），
  App 首次启动读取；之后 `ui.lang` 优先。
- `[Icons] Comment` / `VersionInfoDescription` 改成中性 `InkTeach`，不再让英文安装器显示中文。
- 语言文件授权/来源写进 `THIRD-PARTY-NOTICES.md`。

## 四、翻译范围（先定边界）

**必翻（Tier A）**

- 主工具条 tooltip / 色带 / 图形带 / 收藏 / 更多 / 设置 / 帮助。
- 文件对话框标题与过滤器、保存/打开/导出/备份/恢复。
- 更新提示、隐私同意、首次引导、错误/Toast（用户可见的）。
- 安装器全部文案。

**可后补（Tier B）**

- HUD / 性能面板 / 触摸诊断等开发向浮层。
- 详细帮助的长段落（先英文回退，再逐语言审校）。
- 引擎侧操作条/PPT 条/计时/点名的细节文案。

**不翻（Tier C）**

- 控制台日志、`SelfTests/**`、遥测字段、代码注释、AI prompt、用户自己的板书/PDF/图片文字。
- 文件名/扩展名（`.inkb` 等）不翻译。

## 五、验收与维护

1. **缺失审计**：`INKTEACH_LOC_AUDIT=1` + `--lang xx` 运行/截图，退出时打印
   `LOC-MISSING`；补完 JSON 即可，不改代码。
2. **截图矩阵**：每种语言 × 界面缩放 0.8/1.0/1.3 × 窄/中/宽 × 125%/150%/200% DPI；
   用 `--panelshow` 出图检查溢出/截断。
3. **伪语言**：后续加 `qps`（把文案换成更长的重音串）提前暴露英文/德文长词溢出。
4. **安装器**：`ISCC` 编译通过；静默 `/LANG=...` 与正常安装各验一次。
5. **AOT**：发布前用 `publish.ps1` 的 AOT 单 exe 验一次，确认嵌入式 JSON 被包含。
