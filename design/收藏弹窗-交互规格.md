# 收藏弹窗 · 交互规格 v1

> 定稿：2026-10-26。界面见 `收藏弹窗-最终版-响应式.html`。
> 本文是实现的唯一依据；与 `AGENTS.md` 第 8/9/11 节冲突时，以本文第 12 节的"变更清单"为准。

---

## 0. 四条总原则

1. **面板常驻，不抢焦点**：点画布、换工具都不关。
2. **一次点击做一件事**：不做"点一下看情况"的双义操作。
3. **手势不重叠**：同一个起点只能有一种含义（见 §13 冲突表）。
4. **危险操作两段确认**：删除类第一次只改文案，不动数据。

---

## 1. 打开与关闭

| 动作 | 结果 |
|---|---|
| 点主条「收藏」格 | 打开；再点一次关闭 |
| 未钉住 / 极简态 → 「更多 → 收藏」 | 打开（同一套布局，不产生第二套） |
| `✕`（右上角，横竖位置恒定） | 关闭 |
| `Esc` | 按 §9 逐层退出，最后一步关闭 |
| 点画布、换工具 | **不关** |
| 打开「更多 / 说明 / 截图 / PPT 放映」 | 暂时隐藏（不销毁），退出后恢复 |
| 点卡片进入"拿起"态 | **不关**（保持常驻） |

---

## 2. 面板本身：移动与缩放

| 操作 | 起点 | 结果 |
|---|---|---|
| 移动 | 抓手（左竖条 5×20）；**或面板任意 12px 内边距环**（卡片以外全算） | 整条跟着走 |
| 缩放 | 右下角 18×18 手柄 | 宽高同时变 |
| 重置尺寸 | **双击抓手** | 回到默认（8 列 × 3 行） |

- 拖动时整条降到 **85% 不透明**，松手回弹。
- 松手后位置**夹在屏幕内**（永不丢出屏幕），不吸附边（沿用 2026-09-30 的"拖到哪停哪"）。
- **尺寸只停整数格**：宽度 = `24 + 列数×84 + (列数-1)×8`，高度同理。绝不出现半列/半行。
- 拖动过程中只画"最近的有效轮廓"，松手才落位。
- **不再有"横排 / 竖排"两个形态**，也没有方向自动判定。一个面板，只有宽高两个数。

**最小 / 默认 / 最大**

| | 列数 | 行数 | 尺寸 |
|---|---|---|---|
| 最小 | 3 | 1 | 292 × 144 |
| 默认 | 8 | 3 | 752 × 352 |
| 最大 | 12 | 4 | 1136 × 460 |

## 3. 顶栏（28px，随宽度变形）

| 条件 | 形态 |
|---|---|
| 宽 ≥ 440 且行数 ≥ 2 | **分类页签** ＋ `＋` ＋ 右侧动作 |
| 宽 < 440，或行数 = 1 | **「分类 ▾」下拉** ＋ 右侧动作 |
| 行数 = 1 | 顶栏压到 **20px**（页签即便放得下也换下拉） |

**右侧动作区（从右往左）**：`✕` ｜ `☑` ｜ `🗑 N`（仅回收站非空时存在）

| 元素 | 单击 | 二次交互 |
|---|---|---|
| 分类页签 | 切到该分类 | **再点当前页签** → 弹小菜单：重命名 / 删除该分类 |
| `分类 ▾` 下拉 | 弹分类列表浮层（当前项高亮） | 点浮层外关闭 |
| `＋` | 原地变输入框，回车保存、Esc 取消 | —— |
| `☑` | 进整理模式 | —— |
| `✕` | 关面板 | —— |
| `🗑 N` | 进回收站视图 | —— |

- 页签**不显示数量**；只有回收站的 `N` 显示（红色角标）。
- 分类多到放不下：页签横向滚动，`＋` 始终可见，右侧动作区固定不动。
- 空分类照常显示（不能因为空就消失，否则刚建完会"跳没"）。

## 4. 卡片

- 尺寸固定 **84×92**，圆角 10。**不显示标题、不显示勾选框、不显示红 ✕**。
- 悬停（笔停）时：边框变主色 + 右上角浮出 18px 小 `⋯` + 1.5s 后浮出名字提示条。

### 4.1 单击 = 拿起（不是直接插入）

| 步骤 | 行为 |
|---|---|
| 1. 单击卡片 | 进入 **pending** 态：状态栏「已选中「X」：点画布放置，Esc 取消」；面板**保持打开** |
| 2. 点画布 | 图形按落点插入；**一步撤销**；面板不关 |
| 3. `Esc` | 取消 pending，什么都不插入 |

- 勾了 3 张时点其中任意一张 → pending 是**那 3 张一起**。
- pending 期间再点别的卡片 → 换掉 pending 内容（不叠加）。

### 4.2 按住拖动（> 4px 才算拖）

| 落点 | 结果 |
|---|---|
| 分类页签上 | 整组移到该分类，**排最前**；提示「已移动到「图形」（3 项，排最前）」 |
| 两张卡之间 | 插入到该位置，拖动时画一条 2px 竖线指示；落盘记住顺序 |
| 面板外画布 | 直接插入到落点，落点处画半透明预览框；**一步撤销**；面板不关 |
| 其他 | 取消，状态栏「已取消拖动」 |

- 拖的是**已勾选的组** → 整组走。
- 拖的是**未勾选的单张** → 先清空其他勾选，只动这一张。

## 5. 整理模式（点 `☑` 进入）

顶栏原地换成操作条（**高度不变，不推挤卡片**）：
`已选 N` ｜ `全选` ｜ …… ｜ `移动到 ▾` ｜ `删除` ｜ `取消`

| 操作 | 行为 |
|---|---|
| 点卡片 | 勾选 / 取消（**点整张卡，不用戳小圆圈**） |
| **划线选** | 按住一张卡横/竖划过去，经过的连续卡片按同一起手状态处理 |
| 起手状态决定方向 | 从**未选**起手 = 一路全选；从**已选**起手 = 一路全取消 |
| `全选` | 勾选当前分类当前页全部 |
| `移动到 ▾` | 弹分类列表浮层，选一个 → 整组移过去 |
| `删除` | 两段确认（第一下文案变「再点一次」）→ 整组进回收站 |
| `取消` / `Esc` | 退出整理模式，清空勾选 |

**整理模式下禁用拖动排序**：划线是拖、排序也是拖，同一手势不能两义。要排序先退出整理。

勾选语义（沿用 `AGENTS.md` 第 103 条）：勾了 3 张，点/拖其中任意一张都按 3 张走。

## 6. 回收站

| 项 | 行为 |
|---|---|
| 入口 | 顶栏 `🗑 N`，**仅在 N > 0 时出现** |
| 视图 | 顶栏换：`‹ 返回收藏` ｜ 回收站 N ｜ …… ｜ `清空` |
| 卡片外观 | 虚线边框 + 60% 不透明，缩略图转灰 |
| 点卡片 | **直接还原**到原分类（不用再找按钮） |
| `清空` | 两段确认 → 永久删除 |
| 空态 | 「回收站是空的」；此时 `🗑` 从顶栏消失 |
| 返回 | `‹ 返回收藏` 或 `Esc` |

删除路径统一：卡片 → 回收站 → 清空才真删。整理模式里的"删除"也是进回收站。

## 7. 单卡 `⋯` 菜单（悬停浮出）

| 项 | 行为 |
|---|---|
| 重命名 | 卡片下方原地变输入框 |
| 移动到… | 弹分类列表 |
| 删除 | 两段确认 → 回收站 |

## 8. 滚动

- 卡片超出可视区 → **滚轮滚动**（取消分页）。
- 右侧浮出 **2px 细滚动条**，1.5s 不操作自动淡出。
- 滚轮在面板上滚 = 滚卡片区；在分类页签上横向滚 = 滚页签。
- 滚动位置不记忆（每次打开回到顶部，看最新）。

## 9. 键盘

| 键 | 顺序 |
|---|---|
| `Esc` | 有浮层 → 关浮层；整理态 → 退出整理；回收站 → 返回；pending → 取消；都没有 → 关面板 |
| `Delete` | 整理态：删除所选（两段确认）；否则无效 |
| `Ctrl + A` | 整理态：全选 |

## 11. 边界情况

| 情况 | 处理 |
|---|---|
| 空分类 | 卡区居中两行文案：「这个分类还是空的」/「选中画布对象 → 操作条「收藏」存进来」 |
| 收藏整体为空 | 「收藏还是空的」+ 同样的引导 |
| 删掉当前分类 | 自动切到「全部」，内容移到「未分类」 |
| 当前页最后一张被删 | 回到上一页，不留在空页 |
| pending 时关面板 | 先取消 pending，再关 |
| 拖动中被 Esc | 中断拖动，回到原位（不落盘） |
| 面板被拖到只剩 1 行 | 顶栏自动压到 20px（不用用户管） |

## 13. 手势冲突表（实现时照这个判优先级）

同一个按下起点，只能命中一条：

| 起点 | 判定顺序 | 归属 |
|---|---|---|
| 面板 12px 内边距环 | 1 | 移动面板 |
| 右下 18×18 角 | 1 | 缩放面板 |
| 顶栏空白（页签之间） | 1 | 移动面板 |
| 抓手 | 1（双击则重置尺寸） | 移动面板 |
| 卡片 | 1. 未动就抬手 → 单击／勾选<br>2. 移动 >4px → 拖动<br>3. 整理态 + 移动 → **划线选**（不排序） | 卡片 |
| 卡片小 `⋯` | 1 | 单卡菜单（不触发拖动） |
| 分类页签 | 1 | 切换分类 |

**兜底原则**：面板空白处永远优先当"拖动手柄"，卡片永远优先当"内容"。所以框选做不了——面板内没有空白起手区（见对话记录 2026-10-26）。
