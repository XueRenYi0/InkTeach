# InkTeach · Annotation transparente pour la classe Windows

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md) | [Italiano](README.it.md)

**InkTeach est une couche d'annotation transparente pour Windows : écrivez directement sur PPT / WPS / PDF / images / n'importe quelle application.** Le fichier en dessous reste intact. Stylo, surligneur, pointeur laser, captures d'écran, formes par pause, 41 cartes de formes mathématiques, alignement d'objets, favoris, minuteur et tirage au sort — avec **10 langues d'interface**.

- Windows 10 / 11 x64, sans .NET.

## Langue

**Paramètres → Général → Langue**, choisissez l'une des 10 langues puis redémarrez. En ligne de commande : `--lang fr`.
