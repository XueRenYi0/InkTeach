# InkTeach · Windows 수업용 투명 주석

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md) | [Italiano](README.it.md)

**InkTeach는 PPT / WPS / PDF / 이미지 / 모든 앱 위에 바로 필기할 수 있는 Windows용 투명 주석 레이어입니다.** 아래 파일은 변경되지 않습니다. 펜, 형광펜, 레이저 포인터, 스크린샷, 멈추면 도형, 수학 도형 카드 41장, 개체 스냅, 즐겨찾기, 타이머, 랜덤 호출을 지원하며 **UI는 10개 언어**입니다.

## 다운로드 (9.8.0)

- 설치 파일: [GitHub Releases](https://github.com/XueRenYi0/InkTeach-Releases/releases/latest) ｜ [GitCode 미러](https://gitcode.com/XueRenYI0/InkTeach-Releases/releases)
- 포터블 zip: [GitHub Releases](https://github.com/XueRenYi0/InkTeach-Releases/releases/latest)
- Windows 10 / 11 x64, .NET 설치가 필요 없습니다.

## 언어

**설정 → 일반 → 언어**에서 10개 언어 중 하나를 고른 뒤 재시작하세요. 명령줄에서는 `--lang ko`도 사용할 수 있습니다.
