# InkTeach · Anotación transparente para el aula de Windows

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [Русский](README.ru.md) | [Italiano](README.it.md)

**InkTeach es una capa transparente de anotación para Windows: escribe directamente sobre PPT / WPS / PDF / imágenes / cualquier aplicación.** El archivo de abajo no se modifica. Lápiz, resaltador, puntero láser, capturas de pantalla, formas al pausar, 41 tarjetas de formas matemáticas, imán de objetos, favoritos, temporizador y sorteo, con **10 idiomas de interfaz**.

- ZIP portátil: [GitHub Releases](https://github.com/XueRenYi0/InkTeach-Releases/releases/latest)
- Windows 10 / 11 x64, sin .NET.

## Idioma

**Ajustes → General → Idioma**, elige uno de los 10 idiomas y reinicia. En la línea de comandos: `--lang es`.
